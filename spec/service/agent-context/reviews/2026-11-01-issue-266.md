# #266 중복 파생 접기의 지연 삼중자 생성

## 원인과 변경

- foldSimilarDerived가 같은 키의 비교 상대 유무와 본문 완전 일치를 확인하기 전에 모든 파생의 삼중자 집합을 만들었다. 같은 키에서 본문이 다른 후보를 처음 비교할 때만 대표와 후보의 집합을 만들도록 바꿨다. 대표의 집합은 slice 원소에 보관하고 후보의 집합도 해당 후보의 비교에서 재사용한다.
- 본문이 완전히 같으면 기존과 같이 유사도 1로 판정하며 집합 생성·자카드 계산을 생략한다. 접기 키·순위 우선 대표 선택·접힌 수·결과 순서·임계값·입력 후보 불변은 유지한다. 공개 API·DB·구성 변경은 없다.
- [검색 설계](../sdd/search.md#작업-컨텍스트-흐름-조회)·[시험 설계](../sdd/testing.md)와 [측정 근거](../reference.md#266-중복-파생-접기의-지연-삼중자-생성)를 갱신했다. 기존 요구사항·개발 계획·DOX 소유권과 구조는 유지했다.

## 할당 비교

Go 1.27.3·darwin/arm64·Apple M4 Pro, 파생 후보 64개·본문 8,000문자·임계값 0.9를 사용했다. 준비 비용을 제외한 함수 한 번의 B/op·allocs/op이며 각각 200ms씩 5회 측정한 중앙값이다. 기준 구현은 555aba1의 search.go다. 서로 다른 유사 본문 표본은 마지막 문자를 문장부호로 교체하여 길이를 유지했고, 기준 소스는 Go overlay로 적용하여 같은 표본으로 다시 비교했다.

```sh
go test -run '^$' -bench '^BenchmarkFoldSimilarDerived$' \
  -benchmem -benchtime=200ms -count=5 ./internal/search
```

| 표본 | 변경 전 B/op | 변경 후 B/op | 변경 전 allocs/op | 변경 후 allocs/op |
|---|---:|---:|---:|---:|
| 서로 다른 접기 키 64개 | 66,226,013 | 33,096 | 517,386 | 266 |
| 같은 키·완전히 같은 본문 | 66,214,828 | 21,776 | 517,315 | 194 |
| 같은 키·서로 다른 유사 본문 | 66,214,851 | 66,204,000 | 517,316 | 517,315 |

비교할 상대가 없거나 완전히 같은 본문에서는 본문 길이에 따른 집합 할당이 사라졌다. 실제 본문 비교가 필요한 표본은 약 66.2MB로 유지됐다. 이 합성 함수 표본의 할당 결과를 실제 서버 응답 지연 개선률로 확대하지 않는다.

## 회귀·검증

- 새 할당 회귀를 변경 전 구현에서 실행해 단독 키 표본은 짧은 본문 458회·긴 본문 517,386회, 완전 일치 표본은 386회·517,312회로 실패하는 것을 확인했다. 변경 후에는 두 표본 모두 긴 본문 때문에 할당 횟수가 늘지 않았다.
- 여러 대표에 대한 지연 초기화·재사용과 대표 ID·folded_count·순서·입력 불변 시험은 변경 전후 모두 통과했다. 기존 근거/종류/상태별 그룹·임계값 경계·원천/사건·전체 흐름 회귀도 유지했다.
- `go test -race -json -count=1 ./internal/search`: 하위 사례 포함 347건 통과, 실패·건너뜀 0건.
- `.env`의 TEST_DATABASE_URL·TEST_DATABASE_REQUIRED=1을 사용한 `go test -race -json -count=1 -run '^Test(MCP07RealFlowPartialBudgetAndIsolation|MCPQueryEmbeddingDeadlineReturnsPartialFlow)$' ./cmd/server`: 2건 통과, 실패·건너뜀 0건. 시험별 격리 DB에서 실제 흐름·부분 채널 실패·예산 절단·그래프 격리·취소/연결 반환을 확인했고 자신이 만든 DB만 정리했다.
- check-go.sh의 전체 build·vet·gofmt·govulncheck, 독립 코드 리뷰와 변경 문서 링크·내부 앵커·git diff --check가 통과했다.

전체 저장소 시험·운영 데이터 부하·외부 호스트 인수·배포는 수행하지 않았다. 기존 사용자 `.env.example`·IDE 설정 변경은 포함하지 않는다.
