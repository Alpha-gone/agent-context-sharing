# 검색 품질 본 측정

## 목적과 통제 조건

- 측정일: 2026-09-20
- 목적: 비그래프 기준선, 국소 그래프 확장, 자동 전역 전환과 색인 대상 구성을 같은 조건에서 비교하고 기본 운영 구성을 판정한다.
- 공통 조건: 문자 예산 4,000, 채널별 후보 상한 50, 최대 4홉, 홉 노드 상한 200, 의미 유사도 하한 0.50, 질의별 3회 반복
- 임베딩: `bge-m3:vector:1024`
- 판정: 같은 질의의 단계별 평균 차이와 95% 신뢰구간을 사용한다. 신뢰구간이 0을 포함하지 않을 때 유의한 차이로 본다.

## 그래프 단계 비교

`all_layers`에서 기준선과 전역 단계를 비교했다. MuSiQue의 사실·연상 지표는 모든 단계에서 같았다. 사건 세트도 사실 재현율·순위 품질과 연상 재현율이 같았고, 연상 순위 역수의 `-0.002 ± 0.00413`은 유의하지 않았다.

| 세트 | 지표 | `baseline` | `global` | 단계 평균 지연 |
|------|------|-----------:|---------:|-----------------:|
| MuSiQue 사실 | 재현율 / 순위 역수 | 0.929 / 0.561 | 0.929 / 0.561 | 26.306초 → 28.955초 |
| MuSiQue 연상 | 재현율 / 순위 역수 | 0.303 / 0.345 | 0.303 / 0.345 | 위와 같음 |
| 사건 사실 | 재현율 / 순위 역수 | 1.000 / 0.900 | 1.000 / 0.900 | 11.483초 → 16.267초 |
| 사건 연상 | 재현율 / 순위 역수 | 0.040 / 0.010 | 0.040 / 0.008 | 위와 같음 |
| 자동 전역 | 재현율 / 순위 역수 | 0.980 / 0.510 | 1.000 / 1.000 | 3.740초 → 5.529초 |

자동 전역 세트에서 기준선 대비 전역 단계의 재현율은 `0.020 ± 0.01899`, 순위 역수는 `0.490 ± 0.05728` 높았다. 두 차이는 유의했다. 정답 1건당 문자 수는 `24.56 ± 25.60`만큼 적었으나 신뢰구간이 0을 포함했다.

국소 참조·사건 관계 확장은 이 조건에서 유의한 품질 개선을 만들지 못했고, 사건 세트의 단계 평균 지연을 약 42% 늘렸다. 반면 자동 전역은 전역 질의의 품질을 유의하게 개선했다.

## 색인 대상 비교

`all_layers`에서 `without_source`로 바꾸면 MuSiQue의 사실 재현율은 `-0.714 ± 0.119`, 순위 역수는 `-0.467 ± 0.073`, 연상 재현율은 `-0.292 ± 0.058`, 순위 역수는 `-0.315 ± 0.076` 낮아졌다. 모두 유의한 손실이다.

사건 세트의 사실 재현율은 같았지만 순위 역수가 `0.900`에서 `0.273`으로 낮아졌고 차이 `-0.627 ± 0.070`은 유의했다. 자동 전역 세트의 전역 단계는 재현율 1.000을 유지했으나 순위 역수가 `1.000`에서 `0.507`로 낮아졌다. 예산 효율 개선보다 순위 품질 손실이 명확하므로 원천 포함 색인을 유지한다.

## 판정

- `INDEX_TARGET_LAYERS=all_layers`를 유지한다.
- 국소 그래프 확장은 기본 구성에서 제외하고 `SEARCH_GRAPH_STAGE=baseline`을 사용한다.
- 자동 전역 전환은 국소 그래프 단계와 분리하여 `SEARCH_GLOBAL_FALLBACK_ENABLED=true`로 사용한다. 관련 국소 후보가 없을 때만 전역 요약에서 `derived_from`을 확장한다.
- 문자 예산, 후보 상한, 홉 수와 홉 노드 상한은 공개·자체 세트 사이의 상충이 있어 현재 값을 유지한다.

이 측정은 정적 데이터셋의 검색 품질 판정이다. 온라인 갱신·재생·전이·복구·망각·상충 해소의 지속 평가와 컨텍스트 조회 유무에 따른 업무 효과 비교는 별도 후속 평가로 남긴다.
