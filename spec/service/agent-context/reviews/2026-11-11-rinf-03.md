# RINF-03 후보 검색·판정 입력 검증

## 범위

같은 그래프의 활성 사건을 의미·키워드·구성원·규칙·대화 채널에서 읽고 순위 역수 합으로 결합한다. 확정·폐기된 정체성과 동일 대상 판·후보 판·프로필로 이미 판정한 쌍은 제외한다. 후보와 문자 예산을 적용하고 사건 본문 발췌만 지역 별칭과 구분된 데이터 영역으로 내보낸다. 채널별 기여와 사건 식별자·판은 서버 내부에 남긴다.

대상 색인이 대기 중이면 같은 작업 세대와 리스를 조건으로 실패 횟수를 소모하지 않고 작업을 미룬다. 대기 기한이 지났거나 색인이 실패하면 의미 채널을 생략한다. 정규화된 지문에는 모델·프롬프트·스키마·채널·문자 예산·임베딩 모델·색인 대기·시간 인접 설정과 생성 매개변수를 포함한다.

## 검증

- Go 1.27.3 `go build ./...`, `go vet ./...`, `gofmt -l .` 통과.
- `go test -count=1 ./internal/relinfer`와 `go test -race -count=1 ./internal/relinfer` 통과.
- 필수 합성 DB에서 후보 검색과 색인 대기 리스의 선별 시험 통과. 최근 1,000건 밖 의미 후보, 그래프 경계, 기존 판정·확정 정체성, 색인 대기·실패, 이전 리스와 재시도 횟수 보존을 확인했다.
- 필수 합성 DB에서 `TEST_DATABASE_REQUIRED=1 go test -count=1 -p 1 -timeout=20m ./internal/relinfer ./internal/store` 전체 시험 통과. 추론 회차 0.251초, 저장소 1,189.513초였다. 실제 실행에는 상세 진행을 확인하기 위해 `-v`를 추가했다.

판정 어댑터·결과 검증 및 반영은 RINF-04, 실행기 조립과 분야 통합 인수는 RINF-05에 남는다. 실제 제공자 호출과 운영 DB 변경은 수행하지 않았다.
