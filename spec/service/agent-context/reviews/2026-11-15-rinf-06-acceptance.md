## 독립 표본과 모델 품질

기존 탐색 표본과 겹치지 않는 합성 의미 쌍 400개를 준비했다. `relates_to`·`part_of` 각각 양성 100개와 음성 100개이며 포함 관계 양성 방향은 각각 50개다. 작성자와 다른 검토자가 모델 응답을 보기 전에 400개 전체의 정답·시간·구성원·독립 시나리오를 확인하고 입력과 정답 checksum을 고정했다. 본문에는 유도 지시, 인과 보류, 시간 우연 진단도 포함했다. 공통 문장 틀과 distractor 틀의 반복은 공개하며 일반 업무 분포를 대표한다고 주장하지 않는다.

Gemini 문서 임베딩 1,200개를 실제 생성하고 격리 DB의 다섯 채널에서 후보를 읽었다. 실제 `BuildInput`의 400개 입력·별칭·후보 판·프로필 지문을 고정한 뒤 각 10회, 총 **4,000회** 호출했다. 입력 ID와 관계 정답은 분리했으며 정답은 제공자에게 보내지 않았다. 같은 입력의 반복을 독립 표본 수로 더하지 않는다.

두 유형 모두 매 회차의 사전 합격선을 통과했다. 각 유형의 10회 합산 TP/FP/FN은 999/0/1이며, 회차별 최소 재현율은 99%, 단측 95% Wilson 하한의 최솟값은 약 97.3398%다. 예측 행 단위 하한과 보수적인 사례 단위 하한을 모두 적용했다. 유도 지시에 의한 잘못된 반영은 0건이었다. 출력·근거 위반으로 서버가 차단한 판정은 오관계 반영으로 세지 않고 별도 실패/미검출로 남겼다. `causes`는 음성 진단과 전체 흐름의 두 양성 과업을 별도로 보고하며 자동 확정하지 않는다.

프로필 지문은 `04131576c443ad21c5aa3d72a8f54db7b3a5fe730ab11a9a4dfaa51b7b473c79`다. 모델 `gpt-6-luna`, 프롬프트 판 2, 스키마 판 1, 다섯 채널·후보 8·대상 2,000자·후보 800자·전체 9,000자·색인 대기 1분·시간 인접 1시간, `max_output_tokens=1536`, `service_tier=default`를 고정했다. 실제 서버 어댑터가 두 생성 매개변수와 지문을 대조하며, 지정하지 않은 기존 배포 조립의 요청·지문은 유지한다.

## 후보 검색

실제 400개 스냅숏에서 양성 정답 쌍의 합집합 포함률은 두 유형 모두 100%였다. 양성 200개 중 기대 유형 자격으로 검색된 수는 의미·키워드 각각 200, 구성원·규칙 각각 100, 대화 20이다. 의미 채널은 모든 무관 후보도 반환했다. 단독·공동 채널 반환을 기록했으며 중복 후보를 독립 성능 기여로 더하지 않는다. 이는 작은 합성 그래프의 후보 검색 인수이며 대규모 그래프의 일반 재현율이나 지연 인수가 아니다.

## 전체 흐름과 최종 활성화 판단

새 합성 과업 여섯 개를 조건별 10회, 총 **120회** 실행했다. 실제 모델의 함수 도구 선택과 저장소 조회·관계 연산을 쓰는 에이전트 기준선과 실제 작업자의 후보 준비·판정·검증·`apply` 경로를 같은 모델·초기 그래프·유형 범위로 비교했다. 매 조건은 별도 DB를 생성·마이그레이션하고 전체 그래프를 실제 임베딩·색인했으며 후속 질의 임베딩·의미 검색·확정 1홉 검색과 관계 정답 대조까지 수행했다. 자신이 만든 DB는 시험 뒤 정리했다. 일반 MCP 호스트의 상호운용 인수는 아니다.

전체 과업 성공은 기준선 **41/60**, 서버 **58/60**이었다. 서버 평균은 더 높았지만 `estuary` 과업은 기준선 10/10, 서버 9/10으로 과업별 품질 비악화 조건을 충족하지 못했다. 실패 회차도 분모와 비용에 포함했다. 성공 회차만의 지표는 보조 결과로 따로 기록했다.

사전 고정한 자원 배분 시나리오의 전체 비용 합은 기준선 $0.0422913862, 서버 $0.0344238957로 서버 평균이 약 18.60% 낮았다. 반복을 먼저 과업별로 평균한 여섯 대응 차이의 평균은 -$0.0001311248/과업, Student t 95% 구간은 [-$0.0001808203, -$0.0000814293]이다. **비용 차이는 음수지만 과업별 품질 비악화 조건이 실패했으므로 비용 대비 품질 개선이나 운영 활성화를 채택하지 않는다.** 결과의 `negative_qualification`은 이 종합 판정을 뜻하며 판정 표본의 품질 합격을 취소하거나 모델 자체를 교체한다는 뜻이 아니다.

## 누적 예산과 총비용 경계

새 측정의 실제 응답 사용량에 고정 공개 단가를 적용한 제공자 금액은 품질 $1.0070285, 임베딩 $0.007837, 전체 흐름 $0.0460539로 합계 **$1.0609194**다. 이전 탐색의 보수 환산 상한 $0.0231057까지 포함한 누적 상한은 **$1.0840251**로 승인된 $10 이내다. 새 호출의 미확인 사용량은 0건이며 이전 탐색은 과거 상한으로 남겨 누적 실제 청구액으로 바꾸지 않는다.

전체 흐름은 준비·재시도·후속 검색까지의 제공자 토큰과 캐시 읽기·30분/12시간 쓰기를 구분해 계산했다. 로컬 계산·메모리·저장은 실행 전에 고정한 예약 자원 단가와 전체 벽시계·실측 DB 바이트를 적용한 배분 추정치다. 실제 전기료·클라우드 청구서의 확인으로 표현하지 않는다. 두 조건의 전체 비용 합 $0.0767152820에는 제공자 금액 $0.0460539와 이 배분 추정치가 모두 포함된다. 요약 모델은 호출하지 않았으므로 요약 비용은 적용 대상이 아니다.

## 재검증과 코드 검증

네트워크 없이 다음 명령으로 동결 입력·정답·코드·결과 해시, 프로필 일치, 표본/과업 수, 비용과 판정을 재검증한다.

```sh
python3 spec/service/agent-context/reviews/rinf-06-acceptance/finish_bundle.py --verify spec/service/agent-context/reviews/rinf-06-acceptance/bundle
```

오프라인 집계 재현은 `analyze_acceptance.py --flow .../flow-run-2/flow.jsonl --output-dir <새 경로>`를 사용한다. `bundle`은 `relation_acceptance_bundle_v1`이며 일반 `cmd/eval` trial manifest 형식으로 가장하지 않는다. 표준 다섯 파일과 실제 입력 원장의 checksum을 묶고 별도 검증기가 재계산한다. 제공자를 재호출하면 모델의 비결정성으로 숫자가 달라질 수 있으므로 기존 결과를 덮어쓰지 않는다.

실제 DB 준비·4,000개 서버 출력 검증·120개 흐름 측정과 비용/통계 자체 시험을 통과했다. Go 1.27.3의 전체 build·vet·gofmt, 평가·관계 추론·임베딩 모듈 회귀와 관계 추론 race 검사를 수행했다. 최종 문서·소스 검증 결과는 완료 기록과 함께 유지한다. 독립 최종 검토는 해시·표본 수·비용 산식·통계와 비채택 근거를 재계산하여 남은 중요 결함이 없음을 확인했다.

검토에서 확인한 기존 CLI의 ‘유의한 성공률 악화도 보류로 덮어씀’은 수정했다. 비채택 결과는 보존하며 전용 관계 인수 근거와 연결되지 않은 일반 업무 trace는 자동 채택하지 않는다. 초기 전체 흐름 run1은 manifest 직렬화 오류로 API 호출 전에 실패했고, 비유료 회귀로 수정한 run2만 인수에 사용했다.
