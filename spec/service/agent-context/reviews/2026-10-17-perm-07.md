## 별도 후속 사항

2026-10-24 [고아 간선 조회 수정·재검증](2026-10-24-dangling-edge-index.md)으로 아래 조회 인덱스 후속 사항을 해결했다. 1만 건 실패를 먼저 재현한 뒤 방향별 조회·범위 정점 재사용으로 수정했고 관련 116건이 필수 DB·race 조건에서 통과했다. 아래 내용은 최초 인수 당시의 관찰과 제외 범위를 보존한다.

- `internal/store/query_indexes_integration_test.go:148`, `TestQueryIndexPlansIntegration/10000`: 고아 간선 보충 조회가 주변부 밖 전체 간선을 스캔한다는 기존 기대값 검사 실패. 실행 계획에서 ContextScans 20040·EdgeScans 20010이 관측됐다. 이번 변경은 SQL·인덱스를 바꾸지 않으며 해당 실패는 수정하지 않았다. DATA-05/검색 분야 후속 검토와 최종 인수에서 다시 확인해야 한다. 이 시험과 `TestQueryRelationalIndexPlansIntegration`·`TestHopHubQueryPlansIntegration`은 권한 인수 통과 수에서 제외했다.
- 실제 MCP 도구·Bearer/OAuth·브라우저 제출/키보드/보조 기술·운영 배포는 미실행이다. 업무 행렬의 등급 검사 통과를 전체 전송 인수로 확장하지 않는다.
