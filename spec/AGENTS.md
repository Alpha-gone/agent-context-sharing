# 명세 문서 영역

## 목적

- `spec/`은 이 저장소의 지속적인 명세 문서와 공통 용어 정리집을 보관한다.

## 소유권

- 루트 `AGENTS.md`가 저장소 공통 계약과 `spec/` 경계를 소유한다.
- 이 문서는 `spec/` 하위 문서의 로컬 작업 계약을 소유한다.

## 로컬 계약

- 작업 간 용어는 `DICTIONARY.md`에서 먼저 확인한다.
- 새 용어, 변경된 정의 또는 표기 규칙이 생기면 `DICTIONARY.md`를 갱신한다.
- 서비스별로 지속적인 문서 경계가 필요해질 때만 하위 폴더와 해당 폴더의 `AGENTS.md`를 만든다.
- 하위 `AGENTS.md`를 만들거나 변경하면 이 문서의 Child DOX Index도 함께 갱신한다.

## 작업 지침

- 명세를 수정하기 전에 루트 `AGENTS.md`와 이 문서를 모두 읽는다.
- 서비스 동작, 계약 또는 용어가 확정되지 않은 경우 추측하여 명세화하지 않는다.
- 문서는 한국어로 작성하고, 코드와 기술 식별자는 원문 표기를 유지한다.

## 검증

- Markdown 제목 구조와 표 형식이 올바른지 확인한다.
- 용어 정리집의 서비스 용어와 기획 용어가 섞이지 않았는지 확인한다.

## Child DOX Index

- `service/AGENTS.md`: 서비스 색인, 서비스별 요구사항 명세·상세 설계와 인가 경계를 포함한 하위 DOX의 공통 작업 계약을 정의한다.
