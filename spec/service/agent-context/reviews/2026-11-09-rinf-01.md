# RINF-01 관계 추론 저장 기반 검증

## 범위와 결과

관계 출처·확정 주체의 조건부 검증과 기존 관계의 에이전트 해석, 관리 기록 판정 주체, 추론 회차·판정의 트랜잭션 저장과 교차 검증, 불변식 감사 및 018 마이그레이션을 구현했다. RINF-01을 완료한다. 작업 등록·작업자·실제 판정과 모델 비교는 RINF-02 이후 범위다.

## 홉 질의 계획 실패

기존 코드와 독립 합성 DB에서 오래된 통계의 양방향 허브 표본이 간선 40,067행을 읽어 기존 상한 1,000행을 초과했다. 실제 계획은 후보마다 `graph_id` 인덱스를 사용하고 끝점을 필터로 적용했다. 두 끝점을 하위 질의에서 먼저 제한한 뒤 그래프·상태를 검사하도록 수정했다. 같은 재현 조건에서 간선 접근은 67행이었고 오래된 통계·갱신된 통계의 양방향·역방향 및 상한 2·10 표본과 전체 본문 기준선 비교가 통과했다. 이 수치는 정점 접근량의 상한이나 운영 성능 보장이 아니다.

## 검증

- Go 1.27.3: `go build ./...`, `go vet ./...`, `gofmt -l .` 통과.
- 별도 합성 PostgreSQL/AGE DB에서 001~018 적용과 반복 적용 무변경 확인. 기존 관계·관리 기록 및 적용 이력 보존은 마이그레이션·저장소 시험에서 대조했다.
- `TEST_DATABASE_REQUIRED=1 go test -count=1 -p 1 ./internal/model ./internal/store ./internal/migrate`: 세 패키지 통과. 저장소 394.271초, 마이그레이션 6.920초.
- 이전 전체 저장소 시험에서는 홉 계획 시험이 실패했다. 변경 전 `HEAD`에서도 동일하게 재현했으며, 수정 후 위 패키지 전체 시험에서 통과했다.
- 실제 제공자 호출·모델 품질·운영 DB 적용은 수행하지 않았다. 시험 컨테이너는 검증 후 정리했다.
