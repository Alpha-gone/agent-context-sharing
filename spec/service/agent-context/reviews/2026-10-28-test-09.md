## 첫 전체 실행의 발견 사항과 수정

첫 실행의 cmd/eval에서 등록 직후 attempts=0·실패 사유 없음인 작업이 전부 미래 대기로 판정되면서 비교·일관성·지속 평가가 연속 실패했다. 등록은 애플리케이션 time.Now(), 확보·리스·재시도·준비 검사는 DB 시각을 사용하고 있었다. 등록·재등록을 DB statement_timestamp()로 통일하고 등록 시험의 시각 하한도 DB에서 얻도록 바꿨다. 별도 회귀 시험은 실제 DB 명령 시각을 검사하며 새 등록·upsert 뒤 즉시 확보·결과 저장까지 검증한다. 기존 구현으로 되돌렸을 때 같은 시험이 DB 시계 검사에서 실패하고 수정본에서는 통과함을 확인했다.

TestDatabaseHandleStaysInStore는 cmd/eval의 comparison.go·unit_comparison.go·embedding_comparison.go가 pgx를 직접 사용하는 경계 위반을 찾았다. 벡터 저장량과 후보 코사인 점수 조회를 store의 그래프·모델 범위 API로 옮겼다. 실행기는 연결 대신 값을 받으며 원인 오류·거리/UUID 순서·정상 보고서 형식을 유지한다. 새 격리 DB 시험은 vector/halfvec 각각 hot/cold 합산·없는 모델·타 그래프/옛 모델 후보 제외·타 그래프 기준 벡터 제외·UUID 동률 순서를 대조한다.

수정 후 필수 DB/race 집중 회귀 21건(최상위 6건)이 실패·건너뜀 없이 통과했다. 원시는 /private/tmp/acs-test09-focused.json이며 기존 시계 구현의 재현은 acs-test09-clock-before-fix.log다. 공통 build·vet·gofmt도 통과했다(acs-test09-static-after-fix.log). 첫 전체 실패를 최종 연속 성공 회차에 포함하지 않으며 전체 실행을 마친 뒤 동일 접속 정보로 두 성공 회차를 새로 수행한다.

첫 전체 시도는 950.053초에 종료됐다. 하위 사례 포함 6,354건 통과·46건 실패·2건 전용 스크립트 대기이며 최상위 1,119건 통과·24건 실패·2건 대기다. 기준 계정·정상 서명 키·스키마 이력의 지문은 실행 전후 같았다. 이 실패는 cmd/eval·cmd/server·internal/store에 있었고 다른 패키지에서 실패는 없었다.

공유 DB에 정상 활성 키를 둔 상태에서 고유 인덱스 경합 시험이 자기 활성 키를 추가하려고 실패했다. 이 혼합 시험도 기존 시험별 임시 DB 도우미로 격리했다. 실행 계획 시험도 다른 시험의 누적 데이터·통계와 분리했으며, 격리 후에도 1만 노드의 고아 간선 보충 조회가 전체 간선을 스캔하는 실제 회귀를 확인했다. 같은 스냅숏의 정점 조회에서 물리 식별자를 함께 얻고 해당 끝점 범위를 조인 전에 제한했다. 값은 DB가 반환한 정수만 사용하며 사용자 문자열을 SQL로 합치지 않는다. 1천·1만 노드의 기존 결과·인덱스·실제 스캔량 기준과 고유 경합 검사는 조건 완화 없이 통과했다(acs-test09-focused-index.json).

최소 연결 풀 혼합 시험은 작업 goroutine이 취소보다 늦게 시작한 재생 요청의 초기 ctx.Err() 반환에서 지정 취소 원인을 잃는 경합도 발견했다. ExecuteWrite·replayWrite 시작 경로에 기존 취소 원인 보존 도우미를 적용했다. 시작 전 취소 단위 회귀와 실제 풀 혼합 시험은 통과했다(acs-test09-focused-resource.json). 고아 간선 검출·불변식·감사 정리의 추가 회귀와 최종 전체 두 회차는 별도로 집계한다.

고아 간선의 직접 도우미 시험도 제품과 같이 실제 정점 스냅숏을 먼저 읽도록 준비를 맞췄다. 최종 불변식·감사·취소/최소 풀 회귀는 46건(최상위 15건), 실행 계획·고유 경합은 8건(최상위 2건)이 각각 실패·건너뜀 없이 통과했다. 집중 회귀끼리 겹치는 사례가 있으므로 단순 합을 고유 통과 수로 보고하지 않는다.

- [TEST-08 최종 지원](2026-10-27-test-08-completion.md)의 Codex CLI 0.160.1 exec·파일 자격·MCP 2026-07-28 범위를 유지한다. 새 전체 실행도 선정 CLI를 필수 지정했다. 실제 1시간 자연 만료는 2026-10-27의 3,603.120초 시험 근거를 보존하며 이번에 재실행했다고 표시하지 않는다. keyring·TUI·앱/IDE·다른 CLI 판 지원을 추정하지 않는다.
