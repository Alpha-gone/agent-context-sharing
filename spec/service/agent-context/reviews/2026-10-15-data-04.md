## 구현과 검토

- 단일 store와 비공개 DB 핸들을 유지했다. 정점 변환의 graph_id 검사와 함께 참조·관계·홉 간선의 실제 start_id/end_id, 끝점 UUID·그래프·계층을 공통 검사한다. 사건 관계의 from/to 속성도 실제 끝점과 대조한다.
- 참조 조회는 요청 그래프의 시작 정점으로 범위를 제한한다. 간선·도착 정점의 다른 graph_id를 조건으로 숨기지 않고 검사하여 오류로 돌려준다. 참조 중복과 잘못된 끝점 계층을 차단한다. 검사에는 본문 대신 최소 끝점 메타데이터를 받아 홉의 본문 적재 범위를 유지한다.
- 단건·묶음·화면 목록·활성 사건·홉의 참조 조립을 정합화했다. DERIVED_FROM·HAS_MEMBER와 함께 SUPERSEDES를 읽고 기수성을 검증하여 대체 참조가 읽기·쓰기·갱신 응답에서 유실되지 않게 했다.
- 새 파생의 근거와 사건 구성원은 존재·같은 그래프·원천/파생·활성 상태를 쓰기 안에서 확인한다. 대체 대상은 모델의 같은 종류·요약 범위 계약을 적용한다. 원천·파생의 불변 속성 변경은 기존 모델 검증을 저장 경계에서 유지한다. 과거에 삭제된 근거를 읽는 동작은 유지한다.
- 계층 밖 property, 관계의 추가 version/시간 유효성 property와 누락된 파생 필수 불리언을 거부한다. 관계 상태·종류와 홉 방향·유형 필터를 닫힌 값으로 검사하며, 홉 시작 모델의 graph_id는 스냅숏 사용 여부와 무관하게 검사한다.
- 의미 검색은 임베딩과 정점의 graph_id를 조회와 응답에서 대조한다. 자동 유사 사건 후보에도 정점 그래프 조건을 적용했다. 현재 모델과 같은 그래프 컨텍스트가 없는 벡터는 검색에서 배제한다.
- 검토 중 홉의 빈 방향을 새 입력 검사에서 거부한 회귀를 기존 StoreIntegration이 탐지했다. 기존 양방향 의미를 복구한 뒤 최종 범위를 재검증했다. 시험 DB의 최초 실행 구성은 허용되지 않은 색인 계층 문자열로 DDL 전에 거부됐으며 all_layers로 수정해 정식 적용했다.

## 환경과 검증 결과

- Go 1.27.1, darwin/arm64. Docker 프로젝트 data04-db, 새 볼륨·loopback 동적 포트, 합성 계정·그래프만 사용했다. 실제 .env·운영 DB·기존 볼륨은 사용하지 않았다.
- 저장소 Dockerfile의 고정 AGE tag/digest와 pgvector 패키지로 이미지를 준비했다. 실제 PostgreSQL 18.6 / AGE 1.8.0 / pgvector 0.8.6 / Linux aarch64를 확인했다.
- 빈 DB에 정식 001·009·010 마이그레이션을 적용했다. 외부 임베딩 API 대신 결정적인 로컬 처리기 대역을 사용했다.
- DATA-04 및 영향받은 store·서버 경계 모듈·하위 시험 **133건 통과, 실패 0, 건너뜀 0**, race 통과. 최상위 시험 40개와 하위 시험 93개이며 store 124건·cmd/server 9건이다.
- 상대 그래프 단건·묶음·홉 입력, 검색·화면 반환 범위, 조작된 필터·커서, 잘못된 간선 그래프·끝점 그래프·계층·중복·실제 관계 정체성·저장 property·필수 속성 누락을 검증했다.
- 활성/삭제 참조와 사건 구성원, 다른 종류의 대체 거부, 원천·파생 불변 속성, 정상 대체 참조 보존을 검증했다. 거부한 참조 쓰기는 정점·색인 작업을 남기지 않으며 그래프 메타데이터도 보존한다.
- 임베딩/정점 그래프 불일치·고아 벡터·옛 모델 배제, 최소 풀·스냅숏, 100개 근거·1000개 구성원 홉 참조, 사건 관계 경합·순환·폐기와 패키지 우회 금지를 관련 회귀로 확인했다. 시험 종료 시 연결·예약 회복을 직접 대조했다.
- check-go.sh의 의존성 검증·전체 build·vet·gofmt와 git diff --check 통과.

## 완료 판정과 남은 범위

- DATA-04의 저장 경계 구현·해당 모듈 시험을 완료했다. 다음은 DATA-05의 인덱스·통계와 실행 계획 검증이다.
- DATA-06의 공통 감사 규칙 신규 검증, DATA-07/08의 벡터·계층 이동 전체 인수, DATA-10의 저장 전체 인수와 MCP/웹 전송·전체 연산 권한 인수는 후속 작업이다. 선택한 모듈 시험을 전체 저장소·분야별 통합 통과로 표시하지 않는다. 운영 적용·실제 호스트·외부 API·amd64 runtime은 미실행이다.
- DOX pass: 패키지 소유권·저장 구조·의존·작업 흐름·용어·요구사항·설계 계약은 유지하므로 DOX 색인·SRS·SDD·용어집과 기존 SQL은 갱신하지 않았다. 구현과 신규 시험·완료 근거·진행 기록만 갱신했다. RLS는 추가하지 않았다.
- 시험 프로젝트의 컨테이너·이미지·볼륨·네트워크를 정리하고 프로젝트 label 기준 잔여 자원 0을 확인했다. 사용자 Compose·IDE 변경을 보존했다. 커밋·푸시는 수행하지 않았다.
