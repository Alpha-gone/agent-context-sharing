# 용어 정리집

## 서비스 용어

| 단어                    | 정의                                                                                                                        | 비고                                                                                                                                                                           |
|-------------------------|-----------------------------------------------------------------------------------------------------------------------------|--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| AI 에이전트 제텔카스텐  | AI 에이전트가 이후 작업에서 다시 활용할 수 있도록 지식과 작업 맥락을 지속적으로 축적하고 연결하는 시스템이다.               | 서비스의 궁극적인 목표이며 컨텍스트 단위는 「컨텍스트 모델」이, 연결·축적·재활용 원칙과 충족 기준은 「제텔카스텐 운영 모델」이 정의한다.                                       |
| 검색 채널               | 서로 다른 방식으로 후보를 찾는 검색 경로이며 순위를 채널별로 독립 산정한다.                                                 | 의미 유사도·키워드·시간 필터는 서로 의존하지 않는 진입 채널이고, 그래프 경로는 진입 채널이 찾은 노드를 입력으로 받는 확장 채널이다. 채널별 기여와 실패 원인을 분리해 측정한다. |
| 계정                    | 작업자를 식별하는 단위이자 인증 주체이며 컨텍스트 보관 정책의 판정 대상이 되는 서비스 이용 주체다.                          | 식별자는 UUIDv7을 사용한다. 컨텍스트 그래프 단위로 권한 등급을 부여하며 부여·회수는 웹 페이지에서 수행한다.                                                                    |
| 계정 플랜               | 계정에 적용되는 서비스 이용 조건과 데이터 보관 정책의 묶음이다.                                                             | 명세는 플랜이 정할 수 있는 열한 항목과 기본값만 확정하고 플랜 이름과 구체 값은 운영 구성으로 둔다. 세부는 `SRS.md`의 「계정 플랜」이 정의한다.                                 |
| 공유 컨텍스트 그래프    | 여러 작업자가 권한 범위 안에서 공동으로 접근해 컨텍스트와 관계를 기여·조회·활용하는 하나의 그래프다.                        | 권한은 계정과 그래프의 조합에 등급으로 부여하며 부여·회수는 그래프 소유자가 웹 페이지에서 수행한다.                                                                            |
| 관계 확정               | 제안된 후보나 에이전트가 판단한 사건 관계를 `confirmed` 상태로 만드는 관리 연산이다.                                        | `relation_confirm`으로 수행하며 확정된 관계만 홉 탐색과 작업 컨텍스트 흐름에서 따라간다.                                                                                       |
| 관계 후보 제안          | 시스템이 사건 사이에 성립할 수 있는 관계를 추천하는 동작이다.                                                               | 시간 인접, 구성원 부분집합과 임베딩 유사도를 신호로 쓰며 `causes`는 자동 제안하지 않는다. 제안만으로는 관계가 생기지 않고 `relation_confirm`으로 확정해야 한다.                |
| 국소 그래프 보기        | 현재 선택한 컨텍스트를 중심으로 지정된 홉 거리 안의 컨텍스트와 관계를 표시하는 시각화 방식이다.                             | 탐색 깊이는 「계정 플랜」의 최대 홉 수까지 조절한다.                                                                                                                           |
| 권한 등급               | 계정이 컨텍스트 그래프에 대해 수행할 수 있는 연산의 범위를 나타내는 구분이다.                                               | 소유자, 편집자, 열람자를 사용하며 등급별 허용 연산과 부여·회수 절차는 `SRS.md`의 「격리와 권한 요구사항」이 정의한다.                                                          |
| 근거 무효 표시          | 파생의 근거가 폐기되거나 대체되었음을 알리는 표지다.                                                                        | 표시만으로 파생을 폐기하지 않으며 재생성·폐기·유지는 관리 연산으로 판단한다.                                                                                                   |
| 근거 상태               | 파생 컨텍스트가 관찰·경험·의견 중 어느 성격인지 나타내는 분류다.                                                            | `observation`, `experience`, `opinion` 세 값이며 생성 후 불변이고 `opinion`은 신뢰 상태를 함께 갖는다. 세부는 `SRS.md`의 「근거 상태」가 정의한다.                             |
| 기대 버전               | 수정 요청에 포함해 현재 판 번호와 비교하는 값이다.                                                                          | 값이 다르면 수정을 적용하지 않고 충돌로 거부한다.                                                                                                                              |
| 낙관적 잠금             | 잠금을 미리 획득하지 않고 수정 시점에 판 번호를 비교해 충돌을 탐지하는 동시성 제어 방식이다.                                | 명시적 잠금 연산을 제공하지 않으며 재시도는 호출자의 책임이다.                                                                                                                 |
| 마지막 활동 시각        | 컨텍스트 그래프에 컨텍스트가 마지막으로 추가되거나 수정된 시점이다.                                                         | 시스템이 갱신하며 그래프 목록의 기본 정렬 키로 사용한다.                                                                                                                       |
| 만료 파생               | `valid_to`가 현재 시각보다 이전인 파생 컨텍스트다.                                                                          | 기본 검색에서 제외하되 시간 필터, 홉 범위 조회와 직접 조회에서는 반환한다.                                                                                                     |
| 미색인 컨텍스트         | 저장되었으나 임베딩 색인이 아직 생성되지 않은 컨텍스트다.                                                                   | 의미 유사도 채널에서만 빠지며 응답에 표시하지 않고 관측 지표로 드러낸다.                                                                                                       |
| 복구                    | 폐기된 컨텍스트를 다시 사용 가능한 상태로 되돌리는 관리 연산이다.                                                           | 폐기한 채널로 제한하며 웹에서 삭제된 컨텍스트는 연산으로 복구하지 않는다.                                                                                                      |
| 부분 검색 결과          | 일부 검색 채널이 실패했을 때 성공한 채널의 결과만 담아 반환하는 응답이다.                                                   | 오류가 아니며 실패한 채널을 함께 알린다. 모든 채널이 실패하면 오류로 처리한다.                                                                                                 |
| 비전 충족 판정          | 제텔카스텐 비전을 충족했는지 세 비기능 요구사항으로 가르는 판정이다.                                                        | 접근의 유효성·품질 유지·실제 효용을 각각 그래프 효과 비교, 지속 평가, 업무 효과 평가로 판정하며 모두 만족하지 못하면 그래프 접근을 재검토한다.                                 |
| 비지속 요청-응답        | MCP 클라이언트의 각 요청을 지속 연결이나 프로토콜 세션 상태에 의존하지 않고 독립적으로 처리하고 응답하는 상호작용 방식이다. | 사용자 표현인 `단발성 연결`을 명세에서 정규화한 용어다.                                                                                                                        |
| 사건 관계               | 두 사건 컨텍스트를 잇는 시간·인과·부분·의미 연결이다.                                                                       | `precedes`, `causes`, `part_of`, `relates_to` 네 종이며 방향과 순환·시간 제약은 `SRS.md`의 「사건 모델」이 정의한다.                                                           |
| 사건 컨텍스트           | 하나의 상호작용이나 경험에서 함께 해석해야 하는 정보를 묶은 컨텍스트 단위다.                                                | 하나의 작업 목표를 공유하고 시간적으로 이어지는 상호작용을 묶으며 경계는 에이전트가 판단한다. 세부는 `SRS.md`의 「사건 모델」이 정의한다.                                      |
| 상충 표시               | 같은 대상에 상반된 파생이 있음을 신뢰 상태로 알리는 표지다.                                                                 | `disputed` 값으로 표시하며 상충 상대는 관리 연산 기록의 판단 입력에 남긴다. 표시된 파생을 검색에서 자동으로 제외하지 않는다.                                                   |
| 소유권 이전             | 그래프 소유자가 다른 계정에 소유자 등급을 부여해 작업 단위를 넘기는 절차다.                                                 | 작업 인계에 해당하며 그래프에는 소유자가 최소 하나 유지된다.                                                                                                                   |
| 소프트 삭제             | 데이터를 영구 제거하지 않고 사용자 접근 대상에서 제외하는 삭제 방식이다.                                                    | 사용자 직접 삭제와 계정 접근 소멸 후 자동 삭제에 적용하며 영구 삭제는 수행하지 않는다.                                                                                         |
| 순위 역수 합            | 채널별 순위의 역수를 더해 검색 결과를 하나의 순위로 합치는 결합 방식이다.                                                   | 채널별 점수를 정규화하거나 가중치를 두지 않으며 실패한 채널은 통합에서 뺀다.                                                                                                   |
| 시간 유효성             | 컨텍스트나 관계가 사실로 간주되는 시점 또는 기간과 대체 여부를 나타내는 특성이다.                                           | 파생 컨텍스트의 유효 시점은 에이전트가 명시하며 대체는 만료를 일으키지 않는다. 관계의 시간 유효성은 후속 기획에서 정의한다.                                                    |
| 신뢰 상태               | 의견 성격의 파생을 근거가 얼마나 뒷받침하는지 나타내는 상태다.                                                              | `supported`, `uncertain`, `disputed` 세 값이며 에이전트가 명시하고 시스템은 계산하지 않는다.                                                                                   |
| 업무 연속성             | 작업자와 에이전트가 이전 상호작용과 공유된 관련 컨텍스트를 활용해 작업 상태와 흐름을 이어가는 특성이다.                     | 평가 시나리오, 지표와 합격 기준은 후속 기획에서 정의한다.                                                                                                                      |
| 에이전트 컨텍스트       | 에이전트가 작업을 해석하거나 이어가기 위해 사용하는 정보 단위와 그 관계를 통칭한다.                                         | 최소 단위와 필수 속성은 후속 기획에서 정의한다.                                                                                                                                |
| 연상 검색               | 시작 컨텍스트에서 그래프 관계를 따라 관련 정보를 찾는 검색 방식이다.                                                        | 그래프 경로 채널이 담당하며 다른 채널이 찾은 노드에서 출발해 「홉 범위 조회」 규칙을 따른다.                                                                                   |
| 오류 코드               | 연산이 실패한 이유를 나타내는 구조화된 식별 값이다.                                                                         | 호출자가 재시도 가능 여부를 판단하는 근거이며 코드 목록은 `SRS.md`의 「MCP 연산 매핑」이, 상황별 매핑은 「예외와 오류 처리」가 정의한다.                                       |
| 요약 범위               | 요약 파생이 다루는 대상의 넓이를 구분하는 값이다.                                                                           | 국소 요약과 전역 요약을 구분하며 `SRS.md`의 「파생 정책」이 정의한다.                                                                                                          |
| 운영자 복구             | 유예 기간 만료로 자동 소프트 삭제된 컨텍스트 그래프를 서비스 운영자가 되살리는 절차다.                                      | 소유자였던 계정의 명시적 요청이 있을 때만 수행하고 컨텍스트 내용을 열람하지 않으며 감사 기록에 남긴다.                                                                         |
| 원천 출처 구분          | 원천 컨텍스트가 사용자 발화, 에이전트 응답, 외부 내용 중 어디에서 왔는지 나타내는 값이다.                                   | `user_utterance`, `agent_output`, `external_content` 세 값이며 생성 후 불변이고 순위를 바꾸지 않고 응답에 표시한다.                                                            |
| 원천 컨텍스트           | 에이전트 상호작용이나 외부 입력에서 수집해 출처와 함께 보존하는 원본 정보다.                                                | 최소 단위는 하나의 발화 또는 턴이며 생성 후 불변이다. 본문 형식과 보존 기간은 미정이다.                                                                                        |
| 웹 감사 기록            | 권한·팀 관리와 웹 삭제·복구 같은 웹 관리 행위를 남기는 기록이다.                                                            | 컨텍스트 관리 연산 기록과 대상이 달라 별도로 두며 감사 화면에서 함께 보여준다.                                                                                                 |
| 유예 기간               | 마지막 접근 가능 계정이 사라진 뒤 자동 소프트 삭제를 보류하는 30일의 기간이다.                                              | 기간 안에 접근 가능한 계정이 다시 연결되면 예정된 소프트 삭제를 취소한다.                                                                                                      |
| 이용 한도               | 계정 플랜이 정하는 조회·응답 크기와 자원 사용의 상한이다.                                                                   | 최대 홉 수, 홉 조회 결과 노드 수, 목록 페이지 크기, 컨텍스트 예산, 그래프 수와 저장량을 포함하며 초과 시 `limit_exceeded`로 거부한다.                                          |
| 인가 서버               | 계정의 인가를 받아 접근 토큰을 발급하는 서버다.                                                                             | OAuth 2.1 Authorization Code with PKCE를 사용하며 MCP 리소스 서버와 함께 배치하거나 분리 배치할 수 있다.                                                                       |
| 임베딩                  | 컨텍스트 본문을 의미 유사도 검색에 쓰기 위해 벡터로 표현한 검색 색인이다.                                                   | 시스템이 비동기로 생성하며 컨텍스트가 아니므로 `context_id`를 부여하지 않는다. 하나의 그래프에서는 같은 모델과 차원을 쓰고 모델을 바꾸면 전체를 재색인한다.                    |
| 작업 컨텍스트 흐름      | 현재 작업 컨텍스트를 기준으로 조회한 관련 컨텍스트와 연결을 담은 기계 판독형 응답이다.                                      | 컨텍스트·참조·관계와 검색 메타데이터로 구성하며 경로를 미리 펼치지 않는다. 세부는 `SRS.md`의 「응답 구성」이 정의한다.                                                         |
| 작업자                  | 공유 컨텍스트 그래프에 접근해 컨텍스트를 기여·조회·활용하며 공동 업무를 수행하는 협업 주체다.                               | 계정 단위로 식별하며 인간 사용자는 계정을 사용하는 사람의 역할이다. 팀은 작업자가 아니라 계정을 묶는 권한 그룹으로 다룬다.                                                     |

| 전체 그래프 보기        | 하나의 컨텍스트 그래프 전체를 한 범위에서 표시하는 시각화 방식이다.                                                         | 격리 단위를 넘지 않으며 전역 요약 파생을 함께 보여준다.                                                                                                                        |
| 절단 표시               | 결과가 이용 한도나 컨텍스트 예산을 넘어 일부만 반환했음을 알리는 응답 정보다.                                               | 홉 조회는 잘린 홉 경계를, 흐름 조회는 예산과 제외한 수를 함께 전달해 호출자가 조건을 좁혀 다시 요청할 수 있게 한다.                                                            |
| 접근 가능한 계정        | 특정 컨텍스트 그래프에 소유자·편집자·열람자 중 유효한 등급을 가진 계정이다.                                                 | 하나 이상 존재하면 기본 무기한 보관하며 마지막 계정이 사라지면 30일 유예 기간을 시작한다.                                                                                      |
| 접근 계층               | 그래프 데이터에 닿는 모든 질의를 통과시키는 단일 계층이다.                                                                  | `graph_id`를 필수 인자로 받고 반환 전 모든 정점과 간선의 `graph_id`를 요청 값과 대조한다.                                                                                      |
| 접근 토큰               | 인증된 MCP 클라이언트가 보호된 MCP 요청을 수행할 권한을 증명하기 위해 사용하는 단기 Bearer 자격 증명이다.                   | 계정을 대표하는 서명된 JWT이며 유효기간은 발급 또는 갱신 시점부터 1시간이고 클라이언트 프로세스 메모리에 보관한다.                                                             |
| 중복 파생 접기          | 같은 근거와 종류를 가진 유사한 파생을 응답에서 대표 하나로 합치는 동작이다.                                                 | 저장된 파생을 지우지 않고 전달 시점에만 정리하며 접힌 수를 응답에 알린다.                                                                                                      |
| 진입 채널               | 다른 채널에 의존하지 않고 현재 작업 컨텍스트에서 직접 후보를 찾는 검색 채널이다.                                            | 의미 유사도, 키워드와 시간 필터 셋이며 실행 방식은 배포 구성이 정하고 기본은 병렬이다.                                                                                         |
| 최대 연속 사용 기간     | 한 번의 인가로 접근 토큰을 갱신하며 이어 쓸 수 있는 전체 기간이다.                                                          | 최초 인증 시점부터 12시간이며 초과하면 갱신하지 않고 재인증을 요구한다.                                                                                                        |
| 컨텍스트 계층           | 컨텍스트를 원천, 파생, 사건으로 구분하는 구조 구분이다.                                                                     | 계층별 필수 속성과 불변·가변 규칙은 `SRS.md`의 「컨텍스트 모델」이 정의한다.                                                                                                   |
| 컨텍스트 관계           | 두 컨텍스트 또는 컨텍스트와 관련 주체 사이의 연결이다.                                                                      | 필수 참조와 사건 관계를 포함하며 각각 edge label로 저장한다. 관계에는 버전과 시간 유효성을 두지 않는다.                                                                        |
| 컨텍스트 관리           | 에이전트 컨텍스트의 저장, 조회, 관계와 수명주기를 다루는 기능 범주다.                                                       | 구체적인 관리 동작은 미정이다.                                                                                                                                                 |
| 컨텍스트 관리 연산      | 컨텍스트의 추가, 갱신, 대체, 폐기 또는 유지를 판단하고 적용하는 명시적 동작이다.                                            | 추가·갱신·대체·폐기·유지를 사용하며 에이전트가 판단해 자율 실행한다. 연산 종류와 기록 항목은 `SRS.md`의 「컨텍스트 관리 연산 요구사항」이 정의한다.                            |
| 컨텍스트 관리 연산 기록 | 관리 연산의 판단 입력, 실행 주체와 적용 결과를 남긴 감사 기록이다.                                                          | 적용된 연산과 거부된 연산을 모두 남기며 대상 컨텍스트가 소프트 삭제되어도 보존한다. 보존 기간과 저장 형식은 후속 기획에서 정의한다.                                            |
| 컨텍스트 그래프         | 컨텍스트 노드와 그 관계를 하나의 선택·관리 단위로 구성한 그래프다.                                                          | AI 에이전트 제텔카스텐을 구현하기 위한 현재의 핵심 접근 방식이며 격리 단위이자 작업자가 작업하는 단위다. 단일 AGE 그래프 안에서 `graph_id` 속성으로 구분한다.                  |
| 컨텍스트 노드           | 컨텍스트 그래프에서 하나의 컨텍스트 항목을 나타내는 노드다.                                                                 | 최소 단위, 필수 속성과 관계 제약은 후속 기획에서 정의한다.                                                                                                                     |
| 컨텍스트 시각화         | 컨텍스트와 그 관계를 작업자가 시각적으로 이해하고 탐색할 수 있도록 표현하는 기능이다.                                       | 시스템의 웹 페이지가 렌더링하며 MCP는 제공하지 않는다. 세부는 `SRS.md`의 「화면과 시각화 요구사항」이 정의한다.                                                                |
| 컨텍스트 식별자         | 컨텍스트 그래프를 넘어 전역으로 고유하며 생성 후 변경되지 않는 컨텍스트의 식별 값이다.                                      | UUIDv7을 사용하며 파생 컨텍스트는 식별자와 판 번호의 조합을 식별 단위로 삼는다.                                                                                                |
| 컨텍스트 예산           | 한 번의 검색 응답에 담을 수 있는 컨텍스트 본문의 허용량이다.                                                                | 응답에 담기는 `body`의 유니코드 문자 수로 산정하며 기본값은 20000자다. 플랜별 값은 후속 기획에서 정의한다.                                                                     |
| 팀                      | 계정을 묶어 권한을 함께 부여하기 위한 그룹이다.                                                                             | 작업자가 아니며 팀에 부여한 등급은 소속 계정에 적용된다. 인증된 계정이 생성하며 생성 계정이 팀 관리자가 된다.                                                                  |
| 팀 관리자               | 팀을 생성한 계정으로서 팀 구성원을 추가·제거하는 주체다.                                                                    | 팀 관리는 웹 페이지에서만 수행한다.                                                                                                                                            |
| 파생 컨텍스트           | 하나 이상의 원천 컨텍스트에서 생성한 요약, 성찰 또는 구조화된 정보다.                                                       | 에이전트만 생성하며 근거와 종류를 반드시 명시한다. 갱신 시 판 번호가 증가하고 이전 판을 대체 관계로 남긴다.                                                                    |
| 폐기                    | 에이전트가 판단해 컨텍스트를 사용자 접근에서 제외하는 관리 연산이다.                                                        | 사용자 직접 삭제와 구분하며 노드에만 적용하고 복구 연산으로 되돌릴 수 있다.                                                                                                    |
| 하이브리드 검색         | 직접 후보 검색과 그래프 기반 연상 검색을 조합하는 검색 방식이다.                                                            | 의미 유사도·키워드·그래프 경로·시간 필터를 독립 채널로 실행하고 채널별 순위의 역수 합으로 재순위화한다. 세부는 `SRS.md`의 「검색」이 정의한다.                                 |
| 행위 에이전트           | 계정을 대행해 컨텍스트를 실제로 기록한 에이전트다.                                                                          | 기여 계정과 함께 `created_by_agent`로 기록해 감사에 사용한다.                                                                                                                  |
| 홉 범위 조회            | 시작 노드에서 관계를 따라 지정한 홉 수 이내의 연결된 노드를 조회하는 방식이다.                                              | `0홉`은 시작 노드만 반환하며 탐색 방향, 관계 유형 필터, 순환 처리와 결과 상한은 `SRS.md`의 「홉 범위 조회」가 정의한다.                                                        |
| 확장 채널               | 진입 채널이 찾은 노드를 시작점으로 삼아 연결된 컨텍스트로 넓히는 검색 채널이다.                                             | 그래프 경로 하나이며 진입 채널이 모두 실패하면 `진입점 없음` 사유로 실패한 채널에 들어간다.                                                                                    |
