# 계정·권한·플랜 구현 검사

## 범위

2026-09-08 검사에서 확인한 계정 자격 증명·권한·플랜의 유지되는 결과만 기록한다. 계약의 정본은 [SRS](../SRS.md)와 [SDD](../SDD.md)다.

## 유지되는 발견 사항과 처리

- 권한 SQL의 예약어 별칭을 수정하고 부재 등급의 NULL을 명시적으로 처리했다.
- 소프트 삭제 그래프의 등급은 복구 자격을 위해 유지하며 일반 목록과 활성 그래프 수에서는 삭제 상태를 제외한다.
- 비밀번호의 8~128자 정책과 긴 한국어 입력을 검증하고 직접 bcrypt 저장값의 조건부 승격을 유지했다. 당시 해시 형식은 이후 보완되었으므로 현재 계약은 SDD를 따른다.
- 서명 검증은 kid로 단일 공개 키를 선택하고 미등록 키를 거부한다.
- 계정별 플랜 부분 재정의와 기본값, UUIDv7·보존 기간 관계를 기동 전에 검증한다.
- 서명 키의 활성 유일성·동시 생성·회전과 요청 빈도 창을 실제 DB에서 검증했다.

## 검증의 의미

메모리 대역만으로 SQL 예약어·NULL·트랜잭션 동시성을 검증할 수 없었으므로 실제 DB 시험을 추가했다. 이 기록은 당시 검사 결과이며 현재 전체 기능의 완료나 후속 직접 연결 인수 결과를 뜻하지 않는다.
