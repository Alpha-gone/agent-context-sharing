# 웹 관리 전송 계층

## 목적

- `internal/web/`은 웹 세션으로 인증한 사용자와 운영자에게 그래프 관리·시각화 화면을 제공한다.

## 소유권

- [내부 구현 DOX](../AGENTS.md)는 패키지·데이터 접근·업무 오류 경계를 소유한다.
- 이 폴더는 HTTP 처리기·서버 템플릿·브라우저 자산을 소유한다. 공통 배치는 `templates/layout.html`, 공통 스타일·서체·시각화 배포물은 `assets/`, 내장·HTTP 제공 목록은 `assets.go`에 둔다. 동작·접근·시각 규칙의 정본은 [웹 설계](../../spec/service/agent-context/sdd/web.md)다.

## 로컬 계약

- 보호 화면은 `web` audience의 웹 세션 쿠키로 인증한다. 로그인·가입·로그아웃을 포함한 상태 변경 요청은 [처리 순서](../../spec/service/agent-context/sdd/web.md#웹-요청-처리-순서)에 따라 세션·폼 해석 전에 같은 출처를 검사한다.
- 로그인·가입의 예산·본문·제한 응답은 [공개 인증 보호](../../spec/service/agent-context/sdd/authentication.md#공개-로그인가입-자원-보호)를 따른다. 출발지 식별은 서버 조립 계층의 검증 값을 받고 전달 헤더를 직접 신뢰하지 않는다.
- 그래프 화면은 유효 등급을 확인하고 같은 `graph_id`만 렌더링한다. 권한·팀 관리의 세션 기준 예외와 소유자·팀 관리자별 조회·변경 범위는 [화면 계약](../../spec/service/agent-context/sdd/web.md#웹-화면-계약)을 따른다.
- 상태 변경의 권한 재확인·한도·감사·재색인 등록은 `store`의 트랜잭션에 맡긴다. 권한·팀 관리와 사용자 직접 삭제는 웹 표면에 둔다.
- 없는 대상·상태 충돌·내부 장애는 [오류 계약](../../spec/service/agent-context/sdd/mcp.md#오류의-생성과-전달)으로 구분한다. 내부 장애를 권한 부족·마지막 소유자 안내로 숨기거나 오류 원문을 응답에 노출하지 않는다.
- 그래프 상세는 공통 홉 조회를 사용하고 상한·절단 경계를 그대로 표시한다. 삭제·복구 표시, 목록 필터·페이지 상태, 전체/국소 보기·포인터/키보드 선택은 화면 계약을 따른다.
- 고정 판 Cytoscape.js·Pretendard와 각각의 라이선스 전문을 함께 유지하고 CDN으로 대체하지 않는다. 공식 배포 경로·판·해시는 [자산 기록](assets/README.md)을 따른다. 자산의 내용 해시 `ETag`·보관 지시로 조건부 요청을 지원한다.

## 작업 지침

- 브라우저 데이터는 서버에서 만든 값으로 전달하고 사용자 입력을 신뢰된 JavaScript로 삽입하지 않는다.
- 화면 동작·경계·시각 규칙을 바꾸면 소유 웹 설계를 먼저 갱신한다.

## 검증

- 웹 시험은 [루트 시험 시점 계약](../../AGENTS.md#검증)을 따른다. 웹 작업 항목의 모듈 시험은 해당 패키지 범위로, 웹 분야 통합 테스트는 `go test ./internal/web ./cmd/server`와 아래 검증 내용으로 수행한다. 코드 변경 시 루트 공통 Go 정적 검증을 실행한다.
- 세션·출처·등급·팀 조회 경계, 자산 경로·캐시, 로그인·가입 예산·취소·상한 응답과 화면 계약의 상태 전이를 검증한다.
- Node.js가 있으면 렌더링된 스크립트와 저장소의 Cytoscape 자산으로 보기·선택·홉·근거 상태를 검사한다. 없으면 건너뜀을 보고한다.
- 실제 브라우저 인수는 `browser_acceptance_test.cjs`가 CDP로 headless Chrome을 조작하며 실행 조건·환경 변수는 [테스트 설계](../../spec/service/agent-context/sdd/testing.md#테스트-계층)를 따른다.
- 합성 요청·스크립트 시험과 실제 브라우저 제출·키보드·스크린리더 검증을 구분하고 미실행 조합을 보고한다.
