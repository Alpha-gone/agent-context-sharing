# #185 전환 시험의 rg 의존 검토

- 대상: [이슈 #185](https://github.com/Alpha-gone/agent-context-sharing/issues/185).
- 기준: `dev`의 `345f97a`, 브랜치 `fix/185-transition-test-grep`.

## 처리

`test-transition.sh`의 반복 적용 확인이 문서화된 준비 사항에 없는 `rg -q`를 사용했다. `rg`가 없으면 명령이 127로 끝나 `||` 분기의 "반복 적용이 무변경이 아니다"로 실패했다. 다른 시험 스크립트와 같이 고정 문자열 검색 `grep -Fq`로 바꿨다. 스크립트가 호스트에서 쓰는 나머지 명령은 Go·Docker·jq와 POSIX 기본 명령이며 [README 준비 사항](../../../../README.md#준비-사항)으로 충분하므로 사전 도구 검사나 문서 변경은 추가하지 않았다. DOX pass에서 소유권·경로 변경이 없어 기존 DOX를 유지했다.

## 재현과 검증

- `PATH=/usr/bin:/bin`의 `sh`에서 실제 판정 구문을 실행했다. 기존 `rg` 구문은 `rg: command not found` 뒤 실행기의 무변경 출력 문구(`적용할 마이그레이션이 없다. …`)를 담은 합성 로그를 "반복 적용이 무변경이 아니다"로 실패했다. `grep -Fq` 구문은 같은 로그를 통과시키고 문구가 없는 로그는 같은 메시지로 실패시켰다.
- `rg`를 PATH에서 제외한 전체 `GO_BINARY=… sh test-transition.sh`는 155행 이전의 별도 기존 결함으로 종료 코드 1이었다. 스크립트(`d75ee6c`)가 013만 제외한 합성 이전 형상이 012에서 멈춘다고 가정하지만 이후 `014_relation_query_scope.sql`(`10dd022`)이 추가되어 이전 형상이 014까지 적용되고 "합성 이전 형상이 012가 아니다"로 실패했다. 실패 주입용 `014_ops08_success.sql`도 같은 번호와 충돌한다. 이번 변경과 분리했으며 전체 전환 인수의 통과로 보고하지 않는다. 시험이 만든 컨테이너·볼륨·네트워크·이미지와 임시 디렉터리는 스크립트 정리로 남지 않았다.
- 셸 문법은 `sh -n test-transition.sh`로, 변경 문서는 `git diff --check`와 로컬 링크·앵커로 확인했다. Go 코드 변경은 없다.
