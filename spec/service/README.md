# 서비스 명세 색인

## 목적

이 문서는 프로젝트에서 기획하는 서비스의 범위, 상태와 주요 명세 진입점을 제공한다.

## 서비스 목록

| 서비스                 | 역할                                                                                                                                 | 상태 | 주요 문서                   |
|------------------------|--------------------------------------------------------------------------------------------------------------------------------------|------|-----------------------------|
| 에이전트 컨텍스트 관리 | AI 에이전트 제텔카스텐을 공유 컨텍스트 그래프로 구현하고, MCP 기반 작업 컨텍스트 흐름과 여러 작업자의 컨텍스트 공유·협업을 지원한다. | 초안 | [SRS](agent-context/SRS.md) |

## 서비스 관계

현재 정의된 서비스는 AI 에이전트 제텔카스텐을 궁극적인 목표로 삼고 공유 컨텍스트 그래프를 핵심 접근 방식으로 사용하는 에이전트 컨텍스트 관리 서비스 하나다. 하나의 그래프를 중심으로 여러 작업자의 컨텍스트 공유와 협업을 지원하며, 추가 서비스나 외부 시스템 경계는 후속 기획에서 확정한다.

## 공통 미정 사항

- MCP transport, protocol revision과 응답 직렬화 형식
- 웹 관리 화면 흐름과 그래프 모델의 Apache AGE 사상
- 배포와 운영 모델
- 임베딩 모델과 색인 비동기화, 검증 지표와 평가 시나리오
- 향후 비즈니스 모델과 계정 플랜별 이용 한도, 컨텍스트 소프트 삭제 전 보관 기간 및 플랜 변경 시 적용 기준
