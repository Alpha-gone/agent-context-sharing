# TRACE-02 요구사항·작업·선행 관계 대조

## 범위와 판정

2026-10-27 현재 SRS·SDD 추적표·개발 계획을 새로 대조하고 TRACE-02를 완료했다. 선행 OPS-09 변경은 77e1404474db6840d93ef5f300766e903cdf22af으로 커밋했다. 이번 대조는 로컬 문서의 추적 관계를 검증하며 제품 동작이나 실제 인수 상태를 변경하지 않는다.

## 입력과 검증 방법

- [SRS](../SRS.md)의 확정 요구사항 행에서 FR 171건/NFR 13건을 추출하고, 폐기된 FR 156~159를 제외한 기대 집합과 대조했다. 다른 절의 ID 인용이나 TBD 대응 행을 요구사항 정의로 중복 집계하지 않았다.
- [SDD 추적표](../sdd/traceability.md)와 [개발 대응표](../development-plan/traceability.md)의 요구사항 행이 각각 184건이고 중복·누락·추가가 없는지 확인했다. 상대 경로를 해석한 실제 파일/앵커 기준으로 184개 주 책임 링크가 일치했다.
- 개발 대응표의 구현 링크 286개와 인수 링크 265개가 비어 있지 않고 각 작업의 실제 파일·제목 앵커를 가리키는지 확인했다. 같은 칸의 중복 작업 링크도 없었다.
- 분야별 14개 계획 문서의 작업 ID 124개와 선행 링크 341개를 추출했다. 파일/앵커/표시 ID를 함께 대조하고 깊이 우선 탐색으로 순환을 검사했다. 선행 링크가 없는 시작점은 TRACE-01 하나이며 모든 작업이 이 시작점으로 이어진다. 완료 작업의 선행도 모두 완료 상태였다.
- 전체 계획의 0~9단계에서 물결표 범위와 슬래시로 나눈 작업 번호를 확장했다. 각 작업이 정확히 한 단계에 포함됐고 상세 작업 목록과 집합이 같았다. 단계 번호는 강제 실행 순서로 해석하지 않았다.
- 전체 계획·SRS·SDD 추적표·분야별 계획/DOX, 총 18개 문서의 로컬 링크 수정 전 1,793개·완료 근거 링크 추가 후 1,795개와 제목 앵커·코드 블록 닫힘을 검사했다. 검증 대상 링크는 외부 사이트에 접속하지 않고 로컬 파일에서 대조했다.

검증 명령은 저장소 루트의 `python3 /private/tmp/acs-trace02-verify.py`이며 Python 표준 라이브러리만 사용한다. 변경 전 원시는 /private/tmp/acs-trace02-before.json, 최종 원시는 /private/tmp/acs-trace02-final.json이다. 원시 JSON은 입력 파일별 SHA-256과 작업의 위상 정렬 결과를 포함한다. 스크립트와 원시 파일은 이번 세션의 임시 검증 자료이며 저장소의 영구 실행 도구로 추가하지 않았다.

## 교차 분야 계약의 대조

- 저장·색인·쓰기 재생: FR-023·081·146·170의 LIFE-02/IDX-01·05/MCP-05·08과 TEST-03·05·07은 원본·감사·큐·멱등성 결과의 한 커밋 경계를 나눠 담당한다. 구현 작업을 추가로 연결하기 위해 데이터·수명주기·MCP의 주 책임 설계를 옮기지 않았다.
- 현재 권한·인증·행위자: FR-028·037·091·166·169·170은 인증 주체·유효 등급·등록 결합·현재 재검사의 서로 다른 책임을 연결한다. 서버 계약 TEST-07과 실제 호스트 TEST-08의 범위를 유지했다.
- 검색·자원·응답: FR-054·066·087·149·152·175는 홉 상한·부분 실패·계측·전송 검증·일관 읽기·진단 파일의 소유와 인수 경계를 함께 확인했다. 검색의 주 책임을 인수 작업이나 관측성으로 옮기지 않았다.
- 실제 지원·평가: FR-164·168·171의 TEST-08 대응은 호스트 설정/실증 책임이며 서버 코드 작업으로 대체하지 않았다. FR-112~116·150~154·160~163 및 관련 NFR의 EVAL/TEST-09 대응은 통제 측정·최종 판정 책임을 보존한다. 구현/인수 두 칸에 같은 통합 작업이 있는 경우를 중복 요구사항으로 처리하지 않았다.

요구사항에 직접 연결된 고유 작업은 101개다. 직접 연결되지 않은 23개는 ARCH-05·AUTH-02·DATA-09·EVAL-01/03·IDX-02/06/08·MCP-01·OPS-01/05/07·PERM-06/07·SEARCH-10·TEST-01·TRACE-01~05·WEB-01/08이며, 공통 기반·분야별 인수·추적 책임으로 선행 그래프와 단계에 포함된다. 모든 작업을 요구사항 행에 억지로 추가하지 않았다.

## 변경과 남은 조건

개발 추적 계획의 “나머지 작업은 미착수”라는 오래된 소개를 현재 추적 작업 범위에 맞추고 TRACE-02의 새 근거를 연결했다. 요구사항 대응표 본문·주 책임 설계·선행 링크·단계 배치에는 수정이 필요하지 않았다. 전체 계획·README·서비스 색인과 요청 기록의 현재 집계를 119개 완료·1개 진행·4개 미착수로 맞췄다.

이번 검증으로 제품 시험을 새로 실행했다고 보고하지 않는다. SRS·분야별 SDD·DOX는 계약·구조·소유권이 바뀌지 않아 유지한다. 다음 독립 작업은 TRACE-03이다. TEST-06의 Safari·실제 음성 관찰과 TEST-09·TRACE-04~05, 실제 Tunnel·운영 공개·정량 효과의 별도 조건은 남아 있다. 과거 기록에 적힌 당시 상태는 현재 완료 상태로 덮어쓰지 않았다.
