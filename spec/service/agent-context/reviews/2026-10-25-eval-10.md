# EVAL-10 외부 원본 재현성 비교 모듈 인수

## 범위와 판정

[EVAL-10](../development-plan/evaluation.md#eval-10)·[FR-161 외부 원본 재현성 평가](../SRS.md#외부-원본-재현성-평가)의 격리 비교 실행기, 수집 당시 판·범위와 실제 내용 일치, 실패·미측정 집계를 인수했다. [실행 계약](../sdd/evaluation.md#외부-원본-비교-실행-계약)과 [시험 설계](../sdd/testing.md#외부-원본-재현성-비교-시험)를 대조했다. 과거 평가 결과를 이번 완료 근거로 승계하지 않는다.

`-original-reproduction` 구현과 통제 표본의 모듈 인수는 완료했다. 실제 외부 출처의 장기 보존·인가·판 제공 정책을 입증한 결과는 아니다. 모든 접속은 직접 만든 HTTPS 대역으로 제한했으며 실제 외부 원본·운영 DB·제공자 자격을 사용하지 않았다. 서버 source_ref·MCP 스키마·원천과 근거 연결에는 변경이 없다.

## 구현과 경계

- 수집 도구가 저장 원천 생성 전에 URI query 또는 경로 segment에 출처 판을 고정하고 비교할 바이트 범위를 fragment로 기록한다. 최초 어댑터는 승인한 HTTPS origin과 전체 HTTP 본문을 사용한다. 판·범위 해석은 격리 도구의 책임이며 서버에 locator fetch·재조회 상태·원천 수정/폐기를 추가하지 않는다.
- 비공개 입력의 수집/어댑터 판·출처·표본·독립 단위·요청 수/시간/크기 상한을 검사한다. 원본 snapshot은 입력 디렉터리 root 아래의 일반 파일만 읽고 전체 SHA-256과 범위를 대조한다. 경로 탈출·root 밖 symlink·원본 누락·stale checksum·잘못된 JSON·모드 충돌은 첫 GET 전에 거부한다. 자격은 입력에 지정한 환경 변수에서 준비하고 값은 결과·오류로 복사하지 않는다.
- 표본별 10회 GET을 순환한다. URI fragment를 보내지 않고 받은 본문에서 같은 바이트 범위를 추출해 정확히 비교한다. 승인하지 않은 origin이나 redirect를 따라가지 않는다. 인코딩 변환·최신 본문으로 원본 덮어쓰기·애플리케이션 재시도를 추가하지 않는다.
- HTTP 200, 응답 판 확인과 원본 내용 일치를 다른 필드로 남긴다. 바이트가 같아도 응답 판이 다르면 판 불일치 상태를 보존한다. 범위 밖 변경은 원본 범위 불일치로 세지 않는다. 부분 응답·304·본문 절단·크기 초과·지원하지 않는 인코딩·범위 누락·헤더 중복/불일치·시간 초과·전송 실패는 원본 일치 성공이 아니다.
- snapshot 없는 표본은 접속 가능성과 판 식별을 확인할 수 있지만 내용은 `-1`이다. 원본을 지정했는데 읽을 수 없으면 준비 실패이며, 없는 원본을 최신 내용으로 대체하지 않는다. GET 실패는 시도 분모에 남기고 다음 회차를 진행하며, 프로세스 취소는 정상 보고서를 만들지 않는다. 오류 메시지는 URI·본문·자격 대신 고정 사유를 사용한다.

## 실제 CLI와 집계

고정 판·내용 변경·이동·삭제·권한 상실·일시 장애·고정 판 없는 출처의 **일곱 유형·각 10회**, 총 **70회 GET**을 실제 CLI로 실행했다. DB 주소를 접속 불가능한 값으로 설정하고 임베딩 제공자를 비운 상태에서도 성공하여 서버/임베딩 경로와 분리된 것을 확인했다. 요청마다 시험 Bearer 자격과 URI 판을 대조했고 이동 대상에는 추가 접속 **0회**였다. 실행 뒤 원본 snapshot이 그대로인 것도 확인했다.

고정 판과 범위를 모두 식별한 표본은 **6/7**, HTTP 200은 **30/70**이며 수집 당시 내용 일치는 **20/70**이었다. 실제 비교 30건은 일치 20·불일치 10이고 비교하지 못한 40건도 전체 시도 분모에 포함했다. 변경된 최신 내용의 10회는 내용·응답 판 모두 불일치이며 이동·삭제·권한 상실·일시 장애를 일치 성공으로 기록하지 않았다. 고정 판 없는 출처 10회는 이번 내용이 같아도 고정 판 식별 표본으로 세지 않았다. 이 값은 합성 통제 입력의 관찰이며 실제 외부 출처의 성공률이 아니다.

유형별 건수와 전체 표본 분모를 따로 기록한다. 10회 반복이나 같은 원본의 여러 조건을 독립 표본으로 늘리지 않는다. CLI의 일곱 조건은 독립 원본 하나여서 구간은 `-1`이다. 별도 집계 시험에서 세 표본·30회를 독립 단위 둘로 묶어 대응 분모와 미측정 10건, 누락/중복 회차·독립 단위 변경 거부를 확인했다. URI·본문·snapshot 파일명·자격은 결과와 CLI 오류에 없었다.

실제 CLI의 모드/직접 입력 충돌·검색 예산 flag·반복 9회 거부와 마지막 snapshot의 준비 실패가 첫 GET도 막는지 확인했다. 진행 중 GET에 실제 종료 신호를 보내 실패 종료·취소 원인 보존·정상 보고서 미생성을 확인했다. 응답 헤더와 본문 대기 제한, 잘린 본문·지원하지 않는 인코딩·크기/범위 경계도 모듈에서 검증했다.

## 실행 결과와 보완 이력

전체 평가 패키지의 단일 명령은 **627건**(최상위 **163건**, 하위 사례 포함)을 실패·건너뜀 없이 **206.690초**에 통과했다. 기존 **240초** 제한을 유지했고 원본 비교 실제 CLI는 **1.18초**, 신호 취소는 **0.02초**였다.

전체 실행 뒤 검토에서 ETag 입력 검사가 시작·끝 따옴표만 확인하는 것을 발견했다. Go 1.27.1의 공식 `net/http` 소스 `scanETag`·`etagStrongMatch`의 유효 문자/강한 비교 조건을 대조해 한 글자 따옴표·내부 따옴표·제어문자를 거부하도록 보완했다. 약한 ETag 거부와 정상 경로/query 판 결합을 유지했다. 보완한 최종 코드의 원본·manifest·모드 모듈 **107건**(최상위 **9건**)이 race에서 **3.040초**에 실패·건너뜀 없이 통과했다. 이 보완 뒤 전체 627건을 다시 실행했다고 주장하지 않는다.

전체 회귀와 최종 모듈의 합집합은 **고유 630건**(최상위 **163건**)이다. 기존 554건에 추가한 76건을 포함하며 중복 실행을 합산하지 않는다. [EVAL-10 모듈 인수](../development-plan/evaluation.md#eval-10)는 이 범위와 실제 최종 코드의 입력 경계 재검증으로 판정했다.

- Go 1.27.1과 직접 생성한 `acs-eval10-db`의 새 `eval10_verified` DB, PostgreSQL 18.6·AGE 1.8.0·pgvector 0.8.6, vector 768·정식 마이그레이션 6개를 사용했다. 원본 비교 자체는 DB를 사용하지 않으며 DB는 기존 평가 경로의 전체 회귀를 위한 것이다.
- 전체 명령은 `TEST_DATABASE_URL`·`TEST_DATABASE_REQUIRED=1`과 `go test -race -count=1 -json -timeout=240s ./cmd/eval`이다. 최종 모듈은 `-run '^(TestOriginal.*|TestManifestModesAndMeasuredZero|TestEvaluationModesRejectConflictsBeforeIO)$'`로 입력 경계 보완의 영향 범위를 재검증했다.
- 최종 코드의 `GO_BINARY=/Users/alphagone/sdk/go1.27.1/bin/go sh check-go.sh` 의존성 확인·전체 build·vet·gofmt가 통과했다. 실제 외부 네트워크 원본·공개 다운로드·유료 호출은 실행하지 않았다.

시험 DB의 잔여 클라이언트 연결 **0개**를 확인하고 직접 만든 컨테이너·익명 볼륨만 정리했다. 기존 개발 컨테이너 두 개는 보존했다. DOX pass에서 기존 실행기·명세 소유 범위와 서버 패키지·마이그레이션·배포 환경 변수 경계가 유지되어 DOX를 바꾸지 않았다. SRS의 후속 상세 설계 문구를 현행 소유 SDD 참조로 정합화했고, 평가/시험 계약·계획·진입점·서비스 색인·공식 근거·요청 기록에 이번 완료 범위와 제한을 반영했다.

전체 계획은 **113개 완료·1개 진행·10개 미착수**이며 다음은 EVAL-11 임베딩 순위·관계/전역 임계값 비교다. `feat/evaluation`에 upstream이 없어 원격 대비 상태를 확인하지 못했다. 변경은 미커밋이며 개인 `.idea` 파일 두 개는 제외한다. 최초 어댑터 외의 출처별 수집/판·절/심볼 해석과 실제 외부 출처 인수는 후속 범위다.

변경 Markdown 10개·로컬 링크/앵커 498개, 계획 ID 124개와 완료 113개를 대조했다. DOX 색인·문서 상태·용어와 `git diff --check`가 통과했다.
