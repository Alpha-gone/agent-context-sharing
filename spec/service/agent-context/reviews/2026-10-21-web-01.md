## 구현과 경계

`internal/web/templates/layout.html`에 공통 문서·오류/안내·본문 이동·라이선스 고지·계층/상태 범례를 두고 `html/template.ParseFS`로 바이너리에 내장한다. 기존 계정·업무·인가·연결 화면 열두 종류가 같은 배치를 사용한다. 계정 양식에는 명시적 label 연결·필수 안내·자동 완성·식별자의 자동 교정 해제와 가입 도움말 연결을 적용했다. 목록·업무 데이터는 기존 조회·권한 계약을 유지하고 모두 템플릿의 문맥 이스케이프를 통과한다.

공통 CSS는 `assets/app.css`로 내장한다. 4px 배수의 간격 척도·48px 양식 조작 대상·전체 조작 수단의 `:focus-visible`·본문 이동 링크·고대비 포커스를 제공한다. 계층 색은 원천 `#1e3a8a`, 파생 `#7c3aed`, 사건 `#2dd4bf`이며 상대 명도는 각각 0.051·0.134·0.514다. 노드 라벨 대비는 10.36:1·5.70:1·9.59:1이다. 상충은 점선 테두리, 근거 무효는 마름모로 함께 표현하여 상태가 계층 색을 대신하지 않는다. 범례는 한국어·계층 식별자·표식 설명을 함께 제공한다. 반응형 배치와 기존 선택·상세·근거 상태 전이는 유지했다.

Pretendard 1.3.9의 공식 가변 WOFF2와 SIL OFL 1.1 전문을 수정 없이 내장했다. 기존 Cytoscape.js 3.34.3과 MIT 고지도 같은 고정 태그의 공식 배포 파일과 바이트 단위로 일치함을 새로 확인했다. 출처·판·SHA-256은 [자산 기록](../../../../internal/web/assets/README.md)에 보관하고 고정 파일 검증을 모듈 시험에 포함한다. 서체를 새로 부분 집합화하거나 이름을 변경하지 않았다.

`assets.go`의 다섯 파일 허용 목록만 HTTP로 제공한다. CSS·서체·스크립트·고지의 MIME과 `nosniff`, SHA-256 ETag·하루 캐시를 명시한다. `http.ServeContent`로 GET/HEAD·조건부 응답·범위 요청을 처리하고 나머지 메서드는 405로 거부한다. 템플릿·자산 기록·디렉터리·경로 이동은 제공하지 않는다. 시각화 스크립트는 그래프 상세만 요청하며 다른 화면의 라이선스 링크는 스크립트 적재를 일으키지 않는다.

렌더링은 임시 버퍼에서 완료한 뒤 상태·본문을 보낸다. 템플릿 실행 실패가 200이나 일부 본문으로 전송되지 않으며 고정된 500 안내만 반환한다. 사용자 입력을 신뢰된 HTML로 승격하지 않고 기존 시각화 JSON의 HTML 위험 문자 이스케이프를 유지한다.

## 검증

- Go 1.27.1 darwin/arm64. Modern Go CLI의 대상 버전 전체 지침과 적용 판 `html/template`·`net/http` 공식 문서·SDK 소스의 ParseFS·문맥 이스케이프·ServeContent 계약을 확인했다.
- Modern Web Guidance의 `forms`·`accessibility`를 조회·적용했다. 서버 렌더링 양식과 기존 CrossOriginProtection 계약을 유지하며 신규 클라이언트 검증·인증 처리는 추가하지 않았다.
- **WEB-01 고유 시험·하위 시험 92건 통과**, 실패·건너뜀 0. 열두 화면의 제목·오류·이름·본문·팀·감사 입력, 그래프 상세 전용 스크립트, 계정 양식 이름/도움말, 템플릿 실패 비노출, 공식 자산 해시와 다섯 자산의 MIME·ETag/304·HEAD·범위·허용 메서드·닫힌 경로를 확인했다.
- **웹 패키지 전체 411건 통과·실패 0·건너뜀 2**, `-race -count=1`. 위 92건을 포함한 수이며 중복 합산하지 않는다. Node.js v26.11.1이 있어 기존 Cytoscape 자산과 렌더링 스크립트의 선택·국소/전체·키보드 상태 전이 시험도 실행했다.
- 건너뜀은 `TestPermissionAcceptanceIntegration`·`TestPermissionLookupFailureHTTPIntegration` 두 건이다. 이번 실행은 `TEST_DATABASE_URL` 미설정이며 해당 DB 권한 인수의 재통과 근거로 사용하지 않는다. WEB-01의 자산·렌더링 경계에는 DB가 필요하지 않다.
- `check-go.sh`: 의존성 확인·의존성 빌드·전체 `go build ./...`·`go vet ./...`·`gofmt -l .` 통과.
- 변경 Markdown 10개의 로컬 링크·앵커 280개와 코드 블록, 계획 69개 완료·55개 미착수 및 부모 Child DOX 색인을 대조했다. `git diff --check`도 통과했다.
- 합성 데이터의 로그인·가입·목록·상세·팀·연결 HTML 표본을 로컬 임시 경로로 렌더링했다. Computer Use에 연결된 브라우저가 없어 실제 브라우저 시각·키보드·보조 기술 확인은 수행하지 않았다. 루프백 미리보기 서버는 종료했으며 임시 렌더링 도우미는 저장소에서 제거했다.

## 남은 범위와 DOX pass

WEB-02의 공통 출처·세션·계정 요청 경계와 WEB-03~09의 업무 화면·분야 통합 인수는 미완료다. 서버 전체 조립에는 WEB-02 외에도 OBS-01→OBS-02가 필요하며 실제 브라우저·보조 기술은 WEB-09·TEST-06에서 인수한다. 이번 공통 기반을 전체 웹·서버·호스트 인수로 확장하지 않는다.

템플릿·자산은 기존 웹 DOX 소유 경계 안에 두므로 새 하위 DOX를 만들지 않았다. 웹 DOX의 파일 소유권·고정 배포/라이선스 규칙과 계획·설계 상태·서비스 색인·공식 근거·요청 기록을 정합화했다. 동작·요구사항·패키지 의존·스키마·환경 변수는 바뀌지 않아 SRS·상세 웹 계약·용어집·마이그레이션·환경 예시를 유지했다.

브랜치 생성 전 원격 `dev`의 해시가 로컬 기준과 같음을 확인했다. 기존 `compose.prod.yaml`과 두 IDE 미추적 파일을 보존했으며 commit·push·PR·배포는 수행하지 않았다.
