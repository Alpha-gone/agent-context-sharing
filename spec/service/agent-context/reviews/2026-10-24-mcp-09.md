## 새 인수 표본과 스냅샷

[서버 인수 시험](../../../../cmd/server/mcp_acceptance_test.go)은 기동 경로의 `assembleApplication`을 두 번 호출해 동일 DB에 독립 저장소·인증·SDK·진단·업무 처리기를 조립한다. 두 실제 TLS 서버에 서명 검증을 거치는 Bearer로 요청한다. 계정·인가 코드·자격은 실제 인증 서비스에서 준비한다. 브라우저 동의·호스트 자격 저장은 실행하지 않는다. 외부 임베딩 제공자만 로컬 TLS 대역의 503으로 바꾼다. 작업자 소비 루프·운영 수신기는 시작하지 않는다.

[새 응답 스냅샷](../../../../cmd/server/testdata/mcp09_contract.json)은 HTTP 상태·Content-Type·no-store·challenge·Allow와 실제 JSON 본문 **43개 표본**을 고정한다.

- 두 인스턴스 모두 발견 전 첫 `tools/call`을 처리한다. 첫 서버는 `agent_register`, 둘째는 `graph_create`로 시작하며 등록·인증 결합이 DB를 통해 이어진다.
- 실제 14종 모두 성공한다. 원천·파생·사건 생성, 파생 갱신·폐기·복구, 사건 간 관계 확정·조회·폐기, 그래프 생성·갱신·목록·상세와 홉·흐름을 실행한다. 성공한 도구 집합은 실제 `tools/list`의 이름 집합과 일치해야 하며 14종 중 하나라도 대응이 없으면 실패한다.
- `server/discover`의 지원 판·tools 기능·instructions·serverInfo, 목록의 스키마·description·annotations, `resultType=complete`·private/0 캐시와 모든 업무의 text/structuredContent 의미 일치를 확인한다. 반환 목록을 이름별로 대조하면 기존 `internal/mcp/testdata/tools.json`과 동일하다. SDK가 정렬한 실제 목록 순서도 새 스냅샷에 보존한다.
- 실제 저장·등급·플랜·현재 판에서 `invalid_argument`·`permission_denied`·`not_found`·`version_conflict`·`limit_exceeded`·`not_supported`를 생성한다. 업무 조회용 `graph_grant`를 이 시험만 소유하는 DB에서 잠시 이름 변경해 `internal`을 발생시키고 즉시 복원한다. 모두 HTTP 200·완료 외피·`isError=true`이고 필드·등급·판·한도·웹 대체 채널이 유지된다. 복원 뒤 조회 성공도 대조한다.
- 계정 플랜의 노드 상한 1개와 문자 예산 1자로 홉·빈 흐름의 정상 절단을 확인한다. 임베딩 제공자의 503은 `semantic.failure=embedding_unavailable`로 남고 다른 채널의 실제 결과를 반환한다. 부분 결과는 업무 오류가 아니다.
- 필수 revision/method/name 헤더 부재·name 불일치는 400/-32020, 필수 version/capabilities 메타데이터 부재는 400/-32602다. 이전 revision은 400/-32022·요청/지원 판, 유효 외피의 initialize는 404/-32601, GET/DELETE는 빈 405·Allow POST다.
- Bearer 부재·잘못된 자격은 401·challenge, 둘째 저장소를 닫은 인증 저장 장애는 500·challenge 부재다. 첫 인스턴스의 후속 목록은 원래 목록과 같다. 세션 ID·쿠키·리디렉션·토큰/키/제공자 내부 원문 노출이 없다.

ID는 새 UUIDv7·유일성을 먼저 확인하고 알려진 계정·등록·그래프·노드·관계에만 기호를 부여한다. 대응하지 않은 UUIDv7은 실패한다. 생성/활동/기록/확정/폐기 시각은 UTC 형식을 확인한 뒤 정규화하고 고정 입력 시각은 그대로 보존한다. 채널 latency는 비음수 정수임을 검사한 뒤 값만 정규화한다. 버전·순서·상태·본문·참조·순위·채널 수/기여·예산·절단·오류 부가 정보는 그대로 고정한다. text는 원래 구조화 결과와 의미가 같은지 먼저 검사한 뒤 같은 규칙으로 정규화한다.

## 정리·DOX pass와 남은 범위

`acs-mcp09-contract`는 `agent-context.task=mcp09` 라벨·tmpfs·임시 IPv4 loopback 포트·합성 자격의 별도 컨테이너다. 각 DB 시험은 정식 마이그레이션으로 고유 DB를 만들었다. 종료 뒤 자식 DB 잔류 없음·다른 client backend 0을 확인하고 생성 컨테이너만 제거했다. 기존 개발 DB·WAL 정리 컨테이너는 유지했다.

변경은 서버 인수 시험·새 응답 스냅샷과 MCP/테스트/전체 계획·검토·요청/근거 기록·SDD의 현재 검증 상태다. 기존 DOX의 `cmd/server` 시험/자산 및 명세 기록 소유권 안에 있어 새 경계를 만들지 않았다. 동작·구조·API·의존·스키마·환경 기본값·요구사항·용어가 바뀌지 않아 DOX·SRS·용어집과 추적표는 유지했다. 과거 검토의 시점·범위도 유지한다. 변경은 미커밋이며 `.idea` 미추적 파일 두 개는 제외했다.

ARCH-08의 상태 공유·배치 종합 인수와 TEST-08의 정확한 Codex CLI 표면·브라우저 최초 인가·갱신·호스트 재시작·지원 판정은 별도다. TEST-06의 Safari·실제 VoiceOver 음성은 진행 중으로 유지한다. 실제 외부 임베딩 API·운영 배포·외부 공개는 실행하지 않았다.
