# 웹 관리 전송 계층

## 목적

- `internal/web/`은 웹 세션으로 인증한 사용자와 운영자에게 그래프 관리·시각화 화면을 제공한다.

## 소유권

- `spec/service/agent-context/SDD.md`의 「웹 화면 계약」과 「시각 표현 규칙」이 화면 동작과 접근 경계를 소유한다.
- 이 폴더는 HTTP 경로 처리, 서버 렌더링 템플릿과 브라우저 시각화 자산을 소유한다.

## 로컬 계약

- 보호 화면은 MCP 접근 토큰이 아닌 `web` audience의 웹 세션 쿠키만 받는다.
- 로그인·등록·로그아웃을 포함한 상태 변경 요청은 SDD의 「웹 요청 처리 순서」에 따라 세션 검증과 폼 해석 전에 출처를 검사한다. 같은 사이트의 다른 출처도 허용하지 않는다.
- 로그인·가입 POST의 공유 시도 예산·본문 상한·429와 재시도 안내는 SDD의 「공개 로그인·가입 자원 보호」를 따른다. 요청 출처는 조립 계층의 기존 프록시 신뢰 판정에서 받으며 이 계층이 전달 헤더를 직접 신뢰하지 않는다.
- 등급 부여·회수·복구 요청·운영자 복구는 SDD의 「오류의 생성과 전달」에 따라 없는 대상·상태 충돌·내부 장애를 구분한다. 내부 장애를 권한 부족이나 마지막 소유자 안내로 숨기거나 오류 원문을 응답에 노출하지 않는다.
- 인가 서버에는 검증된 세션의 계정과 최초 인증 시각을 함께 전달한다. 요청 입력이나 현재 시각으로 인증 시각을 대신하지 않는다.
- 그래프별 화면은 요청 계정의 유효 등급을 먼저 확인하고, 화면 데이터는 같은 `graph_id`만 렌더링한다.
- 그래프 목록의 GET 필터 양식은 활성 이름·등급 조건을 표시한다. 등급은 복수 선택 체크박스로 표현하고 선택 없음은 모든 등급 조회다. 이름 재제출·페이지 이동의 조건 보존과 새 제출의 커서 초기화는 SDD를 따른다.
- 권한과 팀 관리만 예외로 세션까지만 요구한다. 등급 부여·회수와 등급 표는 소유자에게만 두고, 실제 변경의 소유자 재확인과 팀 동작의 관리자 판정은 `store`의 트랜잭션에 맡긴다.
- 등급 부여는 계정·팀 양식을 제공하고 활성 팀의 이름과 식별자 목록은 소유자에게만 조회한다. 팀별 현재 구성원은 요청 계정이 관리하는 팀에만 표시하며, 없는 팀·삭제된 팀의 부여는 내부 장애와 구분한다. 세부는 SDD의 「웹 화면 계약」을 따른다.
- 그래프 상세는 화면 전용 조회를 만들지 않고 「홉 범위 조회」를 쓴다. 그 규칙의 결과 상한과 절단 경계를 화면에 그대로 싣는다.
- 플랜의 홉 한도 `0`은 한도 없음으로 조회하며, 국소 보기 슬라이더에는 「웹 화면 계약」이 정한 표시 노드 수 기반의 유한 범위를 전달한다. 조회의 `0홉`과 혼동하지 않는다.
- 국소 보기에서 전체 보기로 복귀하고 범위 밖 노드를 목록에서 선택할 수 있어야 한다. 선택 해제·홉 값 유지·근거 경로 갱신은 SDD의 「웹 화면 계약」을 따르며 추가 조회로 표시 범위를 넓히지 않는다.
- 소프트 삭제된 컨텍스트는 복구 화면 밖에서 표시하지 않는다. 노드의 삭제와 복구는 삭제와 복구 화면에 둔다.
- 컨텍스트 복구는 요청 계정 플랜의 저장량 한도를 저장소에 전달하며, 상태 변경·저장량 검사·재색인 등록·웹 감사 기록은 한 트랜잭션에 묶는다.
- `assets/cytoscape.min.js`와 `CYTOSCAPE-LICENSE.txt`는 함께 유지한다. 자산은 CDN으로 대체하지 않는다.
- 자산 응답에는 내용 해시로 만든 `ETag`와 보관 지시를 싣는다. 내장 파일의 수정 시각이 제로 값이라 이것이 없으면 조건부 요청이 성립하지 않는다.

## 작업 지침

- 템플릿에 전달하는 브라우저 데이터는 서버에서 만든 값만 사용하고, 사용자 입력을 신뢰된 JavaScript로 삽입하지 않는다.
- 권한·팀 관리와 사용자 직접 삭제는 웹 경로에만 두고 MCP 표면에 추가하지 않는다.
- 화면 변경이 SDD의 동작·경계·시각 규칙을 바꾸면 SDD를 먼저 갱신한다.

## 검증

- `go test ./internal/web ./cmd/server`를 실행한다.
- 그래프 상세의 세션·등급 검사와 정적 Cytoscape.js 자산 경로를 확인한다.
- 목록의 전체·단일·복수 등급 표시, 이름 재제출, 선택 변경·해제와 페이지 이동을 검증한다. 합성 요청 시험과 실제 브라우저 제출 결과를 구분해 보고한다.
- Node.js가 있으면 웹 시험에서 렌더링된 스크립트와 저장소의 Cytoscape 자산으로 보기 전환·목록 선택·홉 범위·근거 강조를 검사한다. 없으면 이 계층을 건너뛴 사실을 보고한다.
- 로그인과 모든 상태 변경 경로에서 다른 출처의 요청을 부작용 없이 거부하고 같은 출처의 요청은 유지하는지 확인한다.
- 로그인·가입의 예산 공유, 전체·출처별 상한, 성공·실패와 무관한 제한 회복, 취소·본문 거부와 인가 작업 초과의 응답을 검증한다.
