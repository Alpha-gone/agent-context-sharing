- 요청 없는 전환 재등록은 이전 상관 ID를 NULL로 초기화한다. 선택 열이 없는 합성 이전 형상도 012가 열을 추가하고 기존 작업은 NULL로 보존한다. 형상이 같은 경우 기존 요청 상관 ID·failed 예산·등록 시각을 바꾸지 않는다.
- 010의 OAuth·등록·문자열 멱등성 이행을 새 모듈 실행에서 다시 검증했다. UUID 키의 텍스트 값·지문·완료 결과·최초 접수/만료와 과거 이력을 보존하며, 잘못된 기존 행은 자동 삭제·수정하지 않고 실패한다. 인증·등록·멱등성 업무 연산의 완료를 뜻하지 않는다.
- 001·009·010·011과 과거 시험용 007의 SQL·주석·적용 이력은 변경하지 않았다. 적용된 012의 재사용 없이 이후 전환·복귀는 새 번호를 추가한다. 미적용 파일만 현재 구성으로 치환하고 과거 파일은 당시 구성으로 검증한다.
- [운영 매뉴얼](../../../../OPERATIONS.md#벡터-형상-변경과-데이터-보존)에 정지·격리 사전 검증·파일별 커밋·감사·재색인·중단·복귀 절차를 추가했다. tablespace 설정 변경은 기존 물리 파티션의 자동 이동을 뜻하지 않는다.

## 검증 결과 — 2026-10-17

- Go 1.27.1 darwin/arm64, Docker Engine 29.8.2. 고정 Dockerfile로 별도 이미지를 빌드하고 소유 라벨이 있는 전용 컨테이너·새 볼륨·임시 IPv4 loopback 포트·합성 자격을 사용했다. PostgreSQL 18.6 / AGE 1.8.0 / pgvector 0.8.6 / Linux aarch64를 확인했다. 기존 개발 DB·볼륨·실제 자격은 사용하지 않았다.
- **고유 시험·하위 시험 100건 통과**: migrate 81·store 13·server 6, 최상위 31개·하위 69개. `-race -count=1`, `TEST_DATABASE_REQUIRED=1`을 적용했다. 재검증 전 결과는 같은 최상위 시험 전체를 최종 결과로 교체하여 중복 합산하지 않았다. 최종 범위의 실패·건너뜀은 0이다.
- 새 전환 표본은 vector 8→16, vector→halfvec 8, halfvec→vector 16과 vector/halfvec 동일 형상을 두 색인 대상 구성에서 대조했다. 두 업무 그래프·hot/cold 벡터·파생 근거·폐기 표본, 계정·OAuth·등록·완료된 멱등성 결과를 함께 보존·검증했다. 실제 SQL 마지막의 장애에서 원본·큐·벡터·내용 판·열·HNSW·이력이 롤백됐다. 같은 형상은 전체 가변 상태가 그대로 남았다.
- 후속 013 합성 파일을 추가해 원래 타입·차원으로 복귀하고 원본 보존·이력 재사용 없음·반복 적용 0개를 확인했다. 저장소 회귀는 시험용 007 대신 정식 012의 SQL을 새 번호로 사용하여 사건·확정 관계·관리 기록 보존, 실패 롤백·양쪽 HNSW·복구 후 실제 큐 소비와 새 벡터 공개·연결/예약 회복을 확인했다.
- 구형 이력의 실제 DB 복원·보충 실패 원자성·다른 파일 checksum 불일치 시 보충 0건·복원 후 재시도 성공과 선택 상관 ID 열 추가를 확인했다. 기존 010 제약·UUID 키 보존·취소·잠금·최대 1연결 풀의 병행 실행도 새 모듈 실행에 포함했다.

## 완료 판정과 후속 범위

DATA-09의 정식 전환·구성 이력·원본/완료 결과 보존·동일 형상 무변경·실패 롤백·새 번호 복귀 조건을 충족했다. 전체 25/124개 완료·99개 미착수다. 다음 권장 항목은 선행이 준비된 [PERM-02](../development-plan/authorization.md#perm-02)의 현재 유효 등급 조회·검사다. DATA-10 전체 저장 인수는 LIFE-09 등 후속 선행이 필요하다.

운영 DB 이행·물리 백업 복구·실제 저장 장치/tablespace 장애·외부 Gemini API·품질/비용·실제 호스트·amd64 runtime·최종 통합 인수는 미실행이다. 복귀 시험의 013은 합성 fixture이며 배포용 파일로 추가하지 않았다. 검증 기록 작성 시점에는 커밋·푸시를 수행하지 않았다.

DOX pass에서 마이그레이션 DOX의 전환 SQL 링크를 정식 012로 갱신했다. 패키지·소유 경계·환경 키·DOX 경로가 바뀌지 않아 부모 색인·나머지 DOX는 유지했다. 데이터·색인 SDD·계획·운영 안내·근거·요청 기록을 정합화하고 SRS·용어집과 과거 검토 기록은 보존했다.
