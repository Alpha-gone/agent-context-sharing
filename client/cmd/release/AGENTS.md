# 클라이언트 배포 후보 도구

## 목적

- 네 플랫폼의 Go 실행 파일·SPDX JSON·빌드 출처·checksum과 오프라인 서명 검증 자료를 생성한다.

## 소유권

- `client/AGENTS.md`가 독립 모듈 계약을, 클라이언트 SDD가 배포 형상과 신뢰 경계를 소유한다.

## 로컬 계약

- Go `1.27.1`, `CGO_ENABLED=0`, `-trimpath`, 읽기 전용 모듈 선택과 네 target을 유지한다.
- 새 출력 디렉터리만 생성한다. 개인 키는 복사·출력하지 않고 기존 산출물을 덮어쓰지 않는다.
- 실행 파일의 Go build information을 SBOM·출처 근거로 사용한다. 라이선스 미확인 값과 dirty 빌드를 숨기지 않는다.
- 각 target 빌드 직전 Git 상태를 읽고 출처의 dirty 값과 실행 파일의 `vcs.modified`를 대조한다. 생성·검증 모두 누락·불일치를 거부하며 저장소 내부 출력도 실행 파일별 상태를 기록한다.
- checksum 목록은 실행 파일·SBOM·출처 기록 전체를 포함한다. 검증은 별도 경로로 신뢰한 Ed25519 공개 키를 요구한다.
- 동봉된 공개 키, 서명 없는 후보 검사와 임시 시험 키는 공식 발행자 신뢰나 출시 판정을 대신하지 않는다.

## 작업 지침

- 운영 업로드·GitHub release·키 생성 또는 키 교체는 이 명령의 책임이 아니다.

## 검증

- 네 target 빌드 정보, SBOM 목록, 서명 부재·다른 키·파일 변조·누락·경로 우회를 확인한다.
- 생성 SBOM은 공식 SPDX 2.3 schema로 검증하며 실제 운영체제·호스트 검증과 구분한다.

## Child DOX Index

- 현재 하위 `AGENTS.md` 문서는 없다.
