# 계정 인증·검증 캐시·서버 기동 회귀

## 범위

2026-10-04 [GitHub #58](https://github.com/Alpha-gone/agent-context-sharing/issues/58) 검토 중 현재 유지되는 계정 인증·검증 캐시·서버 생명주기 결과를 기록한다. 현재 계약은 [SDD](../SDD.md)가 소유한다.

## 유지되는 처리 결과

- 폐기 캐시의 세대 번호로 이전 DB 조회가 로컬 폐기·최신 적재를 덮어쓰지 않도록 했다. 조회 실패를 자격 증명 부재로 숨기지 않는다.
- bcrypt 입력에 SHA-256의 패딩 없는 Base64를 사용하여 긴 한국어 비밀번호와 원시 다이제스트의 NUL 문제를 처리했다. 기존 저장 형식은 로그인 성공 시 조건부 승격한다.
- 조립·수신 실패에서도 시작한 작업자를 정리하며 정상 종료와 기동 실패가 같은 종료 경계를 사용한다. 작업자 종료 오류와 시간 예산을 보존하고 이미 종료한 작업자는 중복 호출하지 않는다.

## 검증과 제한

당시 관련 회귀·실제 DB·서버 종료 시험을 수행했다. 현재 실행 상태와 검증 결과는 후속 기록을 따른다. 해시 형식 보완을 전체 인증 고도화의 안전성 인증으로 간주하지 않으며 `TBD-AGENT_CONTEXT-048`은 유지한다.
