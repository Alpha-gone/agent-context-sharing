# 에이전트 컨텍스트 관리 서비스

## 목적

- 이 영역은 AI 에이전트를 위한 제텔카스텐을 공유 컨텍스트 그래프로 구현하고, 여러 작업자가 에이전트와 MCP로 컨텍스트를 공유·활용하며 협업하는 서비스의 요구사항, 근거와 요청 기록을 보관한다.

## 소유권

- `spec/service/AGENTS.md`가 서비스 명세 공통 계약과 이 서비스 경계를 소유한다.
- 이 문서는 `agent-context/` 하위 문서의 서비스별 계약을 소유한다.

## 로컬 계약

- 서비스의 궁극적인 목적은 AI 에이전트가 지식과 작업 맥락을 지속적으로 축적·연결·재활용할 수 있는 제텔카스텐 시스템을 구축하는 것이다.
- 공유 컨텍스트 그래프는 AI 에이전트 제텔카스텐을 실현하기 위한 현재의 핵심 접근 방식이며, 여러 작업자의 컨텍스트 공유와 협업은 핵심 활용 목표다.
- 에이전트는 사용자 입력과 관련된 컨텍스트를 MCP로 조회·활용해 업무 연속성과 작업자 간 협업을 지원한다.
- 컨텍스트 데이터베이스는 Apache AGE를 사용한다.
- 사용자 입력, 에이전트의 MCP 기반 컨텍스트 조회, 여러 작업자의 공유 그래프 접근, 후속 업무 활용과 컨텍스트 시각화는 서비스의 확정 범위다.
- 시스템은 에이전트 측 MCP 클라이언트의 요청을 기다리는 MCP 서버 역할을 담당한다.
- MCP 요청에 포함된 현재 작업 컨텍스트를 기준으로 연결된 작업 컨텍스트 흐름을 반환하며, 지속 연결이나 프로토콜 세션 상태에 의존하지 않는 요청별 상호작용을 지향한다.
- 작업 컨텍스트 흐름은 에이전트가 사용하는 기계 판독형 결과이며 사용자에게 제공하는 컨텍스트 시각화와 구분한다.
- MCP는 컨텍스트 그래프와 컨텍스트 노드의 생성·조회·수정을 제공하며 노드 조회에서 `0홉`은 단일 노드 조회와 동일하다.
- 컨텍스트 그래프와 컨텍스트 노드의 사용자 직접 삭제는 MCP에 노출하지 않고 웹 페이지에서 소프트 삭제로 수행한다.
- 계정 플랜별 보관 정책이 적용되기 전에는 접근 가능한 계정이 하나 이상 있는 컨텍스트를 사용자 직접 삭제 전까지 무기한 보관한다.
- 마지막 접근 가능 계정이 사라지면 30일의 소프트 삭제 유예 기간을 시작하고, 기간 안에 접근 가능한 계정이 다시 연결되면 예정된 소프트 삭제를 취소한다.
- 유예 기간이 만료되면 컨텍스트를 소프트 삭제하고 사용자 접근을 차단하며 영구 삭제는 수행하지 않는다.
- 상호작용은 사건 컨텍스트로 묶고 사건 사이의 시간·인과·부분·의미 관계를 최소 관계 후보로 실험한다.
- 원천 사실과 관찰·경험·의견 성격의 파생 정보를 구분하고 의견이나 해석에는 근거와 신뢰 상태를 연결한다.
- 그래프 구조의 효과는 가정하지 않고, 비그래프 기준선을 먼저 구성한 뒤 동일한 입력·표현·검색 예산과 평가 조건에서 그래프 기능을 단계별로 추가해 비교한다.
- 컨텍스트는 원천·파생·사건 세 계층으로 구성하며, 원천의 최소 단위는 하나의 발화 또는 턴이고 생성 후 불변이다. 검색용 명제는 파생으로 생성한다.
- 파생은 갱신 시 판 번호를 증가시키고 이전 판을 대체 관계로 연결하며, 컨텍스트 식별자는 전역 고유한 UUIDv7을 사용한다.
- 계층별 필수 속성, 불변·가변 규칙, 식별 방식과 참조 카디널리티의 기준 문서는 `SRS.md`의 「컨텍스트 모델」이다.
- 작업자는 계정 단위로 식별하며 계정이 인증 주체다. 접근 토큰은 계정을 대표하고 에이전트와 MCP 클라이언트는 계정을 대행한다.
- 컨텍스트에는 기여 계정을 `created_by`로, 실제 기록 에이전트를 `created_by_agent`로 함께 기록한다. 계정과 에이전트의 식별자는 UUIDv7을 사용한다.
- 팀은 작업자가 아니라 계정을 묶는 권한 그룹으로 다룬다.
- 시스템과 함께 배치되는 인증 서버는 MCP 클라이언트의 인증 정보를 검증해 1시간 동안 유효한 접근 토큰을 발급한다.
- MCP 클라이언트는 모든 보호된 MCP 요청에 접근 토큰을 포함하며, 만료 10초 전부터 만료 전까지 유효한 요청이 도착하면 토큰을 1시간 단위로 자동 갱신한다.
- MCP 클라이언트의 접근 토큰은 프로세스 메모리에 보관하고 임시 파일은 운영 기본 저장소로 사용하지 않는다.
- 컨텍스트 시각화는 Obsidian Graph view를 참고 모델로 사용하되 동일한 UI와 기능 전체를 복제하는 것으로 해석하지 않는다.
- MCP primitive와 연산 매핑, transport, protocol revision, CRUD 스키마와 작업 컨텍스트 흐름 응답 스키마는 확정 전까지 미정 사항으로 유지한다.
- 시각화 표현 형식, 렌더링 주체, 상호작용과 업무 효과 측정 기준은 확정 전까지 미정 사항으로 유지한다.
- 작업자 모델, 컨텍스트 단위, 그래프 모델, 접근 제어, 동시 갱신, 협업 정책, 검색, 계정 플랜별 소프트 삭제 전 보관 기간과 AI 에이전트 제텔카스텐 운영 모델은 사용자 결정 없이 확정하지 않는다.
- 현재 요구사항의 기준 문서는 `SRS.md`다.
- 공식 기술 근거는 `reference.md`, 사용자 요청과 반영 결과는 `logs/prompt.md`에 기록한다.

## 작업 지침

- 새 요구사항은 기존 ID와 상태를 확인한 뒤 가장 좁은 책임으로 추가한다.
- AI 에이전트 제텔카스텐이라는 서비스 비전과 이를 구현하는 현재 접근 방식인 공유 컨텍스트 그래프를 구분한다.
- Apache AGE를 선택했다는 사실과 구체적인 그래프 스키마·질의 설계를 구분한다.
- 확정된 MCP 서버 역할 및 비지속 요청-응답 방식과 아직 미정인 primitive, transport 및 protocol revision을 구분한다.
- 확정된 그래프·노드 CRUD 기능, 소프트 삭제·보관 수명주기와 아직 미정인 필드, 홉 탐색 정책, 연산 스키마, 계정 플랜별 소프트 삭제 전 보관 기간 및 웹 삭제 세부 정책을 구분한다.
- 채택된 사건 중심 조직과 최소 관계 후보를 아직 미정인 사건 분할·중첩·병합 기준 및 관계별 정의·방향·제약과 구분한다.
- 채택된 근거·해석 구분과 근거·신뢰 상태 연결을 아직 미정인 분류 규칙, 연결 스키마, 신뢰 상태 계산 및 상충 처리 정책과 구분한다.
- 채택된 그래프 효과 통제 검증 방향을 아직 미정인 비그래프 기준선 구성, 비교 대상 기능, 통제 조건, 반복 횟수 및 채택 기준과 구분한다.
- 확정된 컨텍스트 구조와 아직 미정인 값 체계를 구분한다. 근거·신뢰 상태 값은 `TBD-AGENT_CONTEXT-016`, 사건 경계는 `TBD-AGENT_CONTEXT-014`, 파생 생성 정책은 `TBD-AGENT_CONTEXT-011`, 작업자 식별자 형식은 `TBD-AGENT_CONTEXT-021`이 소유한다.
- 컨텍스트의 저장 구조는 `TBD-AGENT_CONTEXT-003`, 지식의 축적·갱신·재구성·재활용 운영 정책은 `TBD-AGENT_CONTEXT-034`가 소유하도록 구분한다.
- 확정된 작업자 식별 단위와 아직 미정인 계정 간 권한 경계·팀 구성·공유 범위를 구분한다. 권한은 `TBD-AGENT_CONTEXT-007`, 공유는 `TBD-AGENT_CONTEXT-023`, 인증 매핑은 `TBD-AGENT_CONTEXT-030`이 소유한다.
- 확정된 토큰 수명·갱신 구간·클라이언트 메모리 보관과 아직 미정인 인증 주체, OAuth 매핑, 갱신 응답, 토큰 형식 및 서버 검증 상태를 구분한다.
- 상세 설계는 요구사항과 주요 미정 사항이 충분히 확정된 뒤 `detailed-design` 스킬로 작성한다.

## 검증

- 모든 확정 문장을 사용자 요청 또는 `reference.md`의 공식 근거로 추적할 수 있는지 확인한다.
- `SRS.md`의 요구사항, 결정과 미정 사항이 서로 모순되지 않는지 확인한다.
- 사용자 입력부터 MCP 조회, 업무 활용과 시각화까지의 흐름이 `SRS.md`와 서비스 색인에서 일치하는지 확인한다.
- 에이전트용 작업 컨텍스트 흐름과 사용자용 컨텍스트 시각화가 혼용되지 않는지 확인한다.
- MCP의 생성·조회·수정 기능, 웹의 사용자 직접 소프트 삭제와 시스템의 계정 접근 소멸 후 자동 소프트 삭제 경계가 모든 요구사항에서 일치하는지 확인한다.
- 접근 가능한 계정이 있는 동안의 무기한 보관, 마지막 접근 가능 계정 소멸 후 30일 유예, 기간 안 계정 재연결 시 삭제 취소, 기간 만료 후 사용자 접근 차단과 영구 삭제 금지가 일치하는지 확인한다.
- 사건 컨텍스트와 시간·인과·부분·의미 관계가 채택된 최소 후보로 일관되게 표현되고 구체적인 사건 경계와 관계 스키마가 미정 사항으로 남아 있는지 확인한다.
- 원천 사실과 관찰·경험·의견 성격의 파생 정보가 구분되고 의견·해석의 근거와 신뢰 상태 연결이 확정 방향으로 일관되며 세부 분류·신뢰 정책은 미정으로 남아 있는지 확인한다.
- 비그래프 기준선의 우선 구성과 그래프 기능의 단계적 비교가 확정 방향으로 일관되게 표현되고 구체적인 비교 조건과 채택 기준이 미정 사항으로 남아 있는지 확인한다.
- 「컨텍스트 모델」의 모든 속성이 근거 요구사항을 갖고, 값 체계를 위임한 속성이 소유 미정 사항과 정확히 연결되는지 확인한다.
- 「컨텍스트 모델」이 vertex·edge·label 표현에 의존하지 않아 비그래프 기준선으로도 구성 가능한지 확인한다.
- 원천 불변 규칙과 `FR-AGENT_CONTEXT-025`의 노드 수정 범위가 모순되지 않는지 확인한다.
- 계정·작업자·사용자의 역할 설명과 인증 주체가 서로 모순되지 않고 `created_by`·`created_by_agent`의 의미가 일관되는지 확인한다.
- 보호된 모든 MCP 요청의 토큰 검증, 1시간 수명, 만료 직전 10초 갱신 구간과 메모리 보관 정책이 일치하는지 확인한다.
- AI 에이전트 제텔카스텐이라는 궁극적 목적, 공유 컨텍스트 그래프라는 핵심 접근과 여러 작업자의 공유·협업이라는 활용 목표가 `SRS.md`, 서비스 색인과 용어 정리집에서 일치하는지 확인한다.
- `README.md`, 용어 정리집과 서비스 명칭·경로가 일치하는지 확인한다.
