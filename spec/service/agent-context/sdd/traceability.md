## 요구사항 추적표

FR 171건과 NFR 13건, 총 184건을 각 한 행으로 추적한다. 폐기된 FR 156~159는 제외한다. 주 책임 문서의 상세 절과 설계 요소·검증 방법을 대응하며 교차 분야는 연결된 문서의 계약을 따른다. `설계 반영`은 구현이나 시험 합격 상태가 아니다. 실행·실증 대기 항목은 진입 문서와 각 분야에서 구분한다.

## 설계 미정 사항

요구사항 수준 미정 다섯 건은 [SRS 미정 사항](../SRS.md#미정-사항)이 소유한다. 설계 미정 사항 ID는 기존 번호를 유지하며 새 번호는 `065`부터 사용한다.

현재 설계 수준의 미정 사항은 없다. 첫 CLI 지원 범위의 실행 근거는 아래 TBD-064 해소 기록을 따르며 다른 호스트/저장 모드는 자동 지원으로 승격하지 않는다.
