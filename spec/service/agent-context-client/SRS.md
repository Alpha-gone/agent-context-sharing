## 서비스 개요

에이전트 컨텍스트 관리 시스템의 요구사항과 상세 설계는 확정되었고 서버 구현이 갖춰져 있으나, 시스템이 상대하는 에이전트 측 MCP 클라이언트는 서버 명세에서 외부 행위자로만 정의되어 구현이 없다. 이 서비스는 그 클라이언트를 개발하기 위한 요구사항을 정의한다.

클라이언트는 에이전트를 대신해 인가 서버에서 접근 토큰을 발급받고, 토큰과 함께 MCP 서버의 도구 13종을 호출해 컨텍스트를 조회·기여·활용하게 한다. 상호운용 대상은 서버의 공개 계약이므로 이 문서의 기능 요구사항 대부분은 서버 명세에서 도출되며, 서버 계약이 바뀌면 이 문서가 함께 따라가야 한다.
