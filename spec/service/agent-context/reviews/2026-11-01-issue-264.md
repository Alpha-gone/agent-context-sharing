# #264 전역 요약 진입점의 현재 유효 시각

## 원인과 변경

전역 요약을 찾는 globalSummaries가 input.AsOf를 저장소에 넘겼다. 의미·키워드 채널은 검색 흐름의 현재 시각을 쓰므로 과거 as_of 요청만으로 현재 만료된 전역 요약을 선택하고 현재 대체 요약은 제외할 수 있었다. FR-AGENT_CONTEXT-068의 기본 검색 만료 제외와 FR-AGENT_CONTEXT-082의 as_of 적용 범위에 맞지 않는 동작이었다.

검색 흐름이 이미 확보한 current를 전역 요약 조회에도 전달한다. 명시적 global·기존 auto 전환·적응형 전역 진입이 이 값을 공유한다. 의미·키워드·전역 채널은 같은 현재 UTC 시각을, 시간 필터만 요청 as_of를 받는다. 저장소의 삭제·유효 기간·정렬·상한 SQL은 유지하고 인자 이름과 주석을 current로 명확히 했다. 홉·직접 조회의 만료 파생 허용 예외도 유지했다.

[검색 설계](../sdd/search.md#작업-컨텍스트-흐름-조회)와 [시험 설계](../sdd/testing.md#전역-요약-진입점의-유효-시각-시험)를 갱신했다. 기존 SRS 요구사항으로 동작이 확정되어 있어 SRS·개발 계획·용어·DOX 소유권·환경 키·스키마는 변경하지 않았다. 새 외부 API나 의존성을 도입하지 않았으며 Go 1.27.3의 time.Now·Time.UTC 계약은 해당 SDK의 go doc으로 확인했다.

## 재현과 회귀

- 수정 전 병렬·순차 × 명시적 global·auto 전환·적응형 전역 경로 × 과거·미래 as_of의 12개 조합 모두 전역 조회에 요청 시각이 전달되어 실패했다. 수정 후 같은 회귀가 통과하고 자동 경로에서 semantic·keyword·global의 시각이 같으며 time만 요청 시각임을 확인했다.
- 전용 DB에 60일 전부터 10일 전까지 유효한 요약, 이를 실제 SUPERSEDES로 대체하고 10일 전부터 10일 뒤까지 유효한 현재 요약, 10일 뒤부터 유효한 미래 요약과 삭제 요약을 준비했다. 시점별 국소 요약도 함께 두었다. 현재 전역 요약의 DERIVED_FROM은 현재 만료된 국소 파생을 가리키도록 구성했다.
- 과거 30일·현재·미래 30일·미지정 as_of × 세 전역 경로 × Read Committed·동기화 스냅숏의 24개 조합에서 진입점은 현재 요약 하나였다. 이전·미래·삭제 전역 요약은 결과에 없었고, 만료된 근거 파생은 홉 결과에 남았다. 자동 경로의 실제 시간 채널 후보만 과거·현재·미래에 맞게 달라졌다.
- 기존 전역 후보의 정렬·상한·국소 채널 제외, vector·halfvec의 의미·키워드·시간 후보와 입력 검증도 함께 실행했다. 이 과정에서 이전 015 추가 뒤 누락됐던 임베딩 시험 DB 준비의 마이그레이션 수 기대값을 7→8로 맞췄다. 초기 DB 표본 실패는 삭제할 그래프의 소유자 등급 누락이었으며, 대체 연산 자체는 성공했다. 시험에 소유자 부여를 추가한 뒤 통과했다.

## 검증 결과

Go 1.27.3, .env의 TEST_DATABASE_URL·TEST_DATABASE_REQUIRED=1을 사용했다. 새 검색 회귀와 임베딩 계약 시험은 각자 새 DB에 정식 마이그레이션을 적용하고 자신이 만든 DB만 정리했다. 기존 전역 후보 시험은 공유 DB 안에서 자기 그래프와 자원을 사용했다. 외부 임베딩 제공자는 호출하지 않았다.

- `go test -race -json -count=1 ./internal/search`: 하위 사례 포함 360건 통과.
- `go test -race -json -count=1 -run 'Test(GlobalSummary|FlowValidatesAsOf|EntryChannel)' ./internal/search ./internal/store`: 저장소 48건 통과. 검색 28건은 위 전체 검색 시험에 포함되어 중복 집계하지 않는다.
- 합계 408건이며 실패·건너뜀 없음. check-go.sh의 의존성 검증·전체 build·vet·gofmt·govulncheck 통과. 독립 코드 리뷰에서 수정이 필요한 발견 사항 없음.
- 변경 문서의 링크·내부 앵커·Markdown·용어와 git diff --check를 확인했다. 신규 소유 경계가 없어 DOX와 부모 색인은 유지했다.

전체 저장소 시험·실제 외부 제공자·운영 부하·배포는 수행하지 않았다. 기존 .env.example·IDE 변경은 포함하지 않는다.
