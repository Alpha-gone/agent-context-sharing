# 지속 평가 본 측정

## 목적과 방법

- 측정일: 2026-09-20
- 대상: `cmd/eval -continual`
- 목적: 온라인 갱신, 재생, 전이, 복구, 망각과 상충 해소 후에도 검색 품질이 기준선보다 나빠지지 않고 상태 계약과 관리 연산 기록이 남는지 확인한다.
- 반복: 시나리오별 3회, 회차별 독립 그래프
- 공통 조건: 문자 예산 512, 채널별 후보 상한 50, 최대 4홉, 홉 노드 상한 200, 의미 유사도 하한 0.50, `bge-m3:vector:1024`

각 시나리오는 같은 질의의 상태 변경 전·후 재현율, 순위 역수와 정답 1건당 문자 수를 비교한다. 세 회차의 쌍별 차이와 95% 신뢰구간을 계산하고, 나쁜 방향의 유의한 차이가 없을 때 품질 기준을 통과한다. 검색 지표와 별개로 시나리오별 상태 불변조건과 `operation_log.judgment_input`의 판단 표식 존재를 확인한다.

온라인 갱신, 재생, 복구, 망각과 상충 해소는 기본 운영 구성인 `baseline`에서 측정했다. 전이는 다른 사건에서도 파생의 근거를 제공하는지가 판정 대상이므로 `references`를 사용했다. 이는 국소 그래프 확장을 기본 운영 구성에서 제외한 판정을 바꾸지 않고, 기능의 전이 계약을 별도로 검증한다.

온라인 갱신, 재생, 전이와 복구의 세 지표는 기준선과 같았다. 망각은 만료한 파생이 기본 검색에서 빠지면서 순위 역수가 `+0.500 ± 0`, 정답 1건당 문자 수가 `-54 ± 0`으로 개선됐다. 상충 해소는 재현율·순위 역수를 유지하면서 정답 1건당 문자 수가 `-46 ± 0`으로 개선됐다. 결과가 결정적이어서 반복 표본의 분산은 0이었다.

모든 시나리오에서 품질 지표의 유의한 악화가 없었고 상태 불변조건과 판단 기록이 세 회 모두 확인됐다. 따라서 `FR-AGENT_CONTEXT-115`, `NFR-AGENT_CONTEXT-007`, `NFR-AGENT_CONTEXT-008`의 지속 평가 기준을 이 세트에서 충족한다.

## 재현 명령

```shell
set -a
. ./.env
set +a
go run ./cmd/eval -continual -repeat 3 -out /tmp/continual-eval-report.json
```

결과 JSON은 시나리오 이름, 회차, 지표, 상태·판단 기록 확인 여부와 집계 판정만 담는다. 컨텍스트 본문, 질의문, 계정·에이전트 식별자는 기록하지 않는다.
