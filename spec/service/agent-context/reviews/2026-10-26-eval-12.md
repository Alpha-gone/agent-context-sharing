# EVAL-12 업무 효과·토큰·총비용·축소 비교 검토

## 범위와 구현

`FR-AGENT_CONTEXT-116`·`163`·EVAL-12의 업무 효과 비교를 구현했다. 기존 `-business`의 네 지표·최소 세 대응 표본을 유지하고, 별도 `cmd/eval -business-tasks 입력.json -out 결과.json`으로 외부 통제 과업의 비식별 집계 trace를 수입한다. 상세 계약은 [평가 설계](../sdd/evaluation.md#에이전트-업무-비용과-축소-비교), 검증 범위는 [시험 설계](../sdd/testing.md#업무-효과비용축소-비교-시험)를 따른다.

- 조회 없음/있음, 조회를 고정한 무관 컨텍스트, 같은 관찰 이력의 원문/요약/관찰 마스킹을 세 독립 실험으로 구분한다. 공통 모델·프롬프트·도구·성공 조건·예산·준비/캐시 판과 과업 해시를 고정하고, 조건별 10회·회차 내 순환·최초/준비 실행 상태를 검사한다. 같은 과업 입력을 다른 독립 단위로 나누는 것을 거부한다.
- 성공·실패·timeout·취소를 모두 분모에 넣고 상태 수·성공률과 전체/성공만 시간·모델 턴·도구 호출·사용자 개입·필수 근거 재조회를 보고한다. 시간 초과의 실제 종료 지연을 한도 값으로 잘라내지 않는다. 준비/재색인 시간의 누락은 -1이다.
- input/output/cache_read/cache_write 토큰을 겹치지 않는 과금 범주로 받고 세 구간의 토큰을 따로 보고한다. 전체 토큰에는 요약 준비도 포함한다. preparation/reindex/execution × agent/embedding/summary/search/storage의 15개 비용 항목을 모두 검사한다. 금액은 사용량×단가/단가 기준량×배분율이며 단가 판·통화·산정일·배분 판과 사용량·단가·금액을 보존한다.
- 측정 0·미측정·비해당을 구분한다. 가격이 null이어도 실제 토큰은 유지하고 비용은 -1이다. 미측정 항목이 있는 구간/총비용은 알려진 소계와 별도로 unmeasured다. 일부 독립 단위만 측정된 추정량은 partially_measured이며 후보 판정을 보류한다.
- 반복→과업→독립 단위 평균과 Student t 대응 95% 구간을 사용한다. 과업 유형 네 가지와 전체 집계를 구분한다. 성공률의 유의한 악화는 거부하며 다른 지표 악화도 공개한다. 독립 표본 부족·합성 trace·시간/사용량/비용 누락·축소의 필수 근거 재조회 불가는 보류한다. 완전한 실제 trace에서 시간·턴·전체 토큰·총비용 중 하나가 유의하게 개선되어도 통제 비교 후보만 남기며 `default_activation`은 false다.
- 본문·내부 추론·원문 이력·개인 행동 식별자를 받지 않는다. 알 수 없는 필드와 잘못된 JSON은 안전한 오류로 거부한다. 기존 업무 입력의 JSON 오류도 원문을 전달하지 않도록 보완했다. 입력은 32 MiB로 제한하고 모드/전용 옵션 충돌은 파일 읽기·DB 접속·출력 생성 전에 거부한다. 수입 해시는 결정적인 JSON으로 결합한다.

## 모듈 검증

최종 코드에서 관련 **327건**(최상위 **53건**, 하위 사례 포함)이 **race·120초 제한**에서 **7.535초**에 실패·건너뜀 없이 통과했다. 범위는 `business_test.go`·`business_tasks_test.go`·`manifest_test.go`·`validation_test.go`·`aggregation_test.go`·`judge_test.go`·`comparison_test.go`의 시험 함수다. 전체 평가/저장소 시험을 실행한 것으로 표시하지 않는다.

```sh
GOCACHE=/private/tmp/acs-eval12-go-cache \
/Users/alphagone/sdk/go1.27.1/bin/go test -race -count=1 -json \
  -timeout=120s ./cmd/eval -run '<위 일곱 파일의 시험 함수에 해당하는 정규식>'
GOCACHE=/private/tmp/acs-eval12-go-cache \
GO_BINARY=/Users/alphagone/sdk/go1.27.1/bin/go sh check-go.sh
```

실제 정규식은 `/private/tmp/acs-eval12-test-pattern.txt`, 최종 시험 결과는 `/private/tmp/acs-eval12-module-complete-final.json`, 전체 의존성 검증·build·vet·gofmt 결과는 `/private/tmp/acs-eval12-static-final.log`에 남겼다. 모두 통과했다. 처음에는 단가 맵의 비결정적 순회 때문에 trace 결합 시험이 실패했고 결정적 직렬화로 수정했다. 시간/비용의 시험 표본 선택 오류도 바로잡았다. 범위를 넓힌 기존 HTTP 시험의 sandbox 포트 바인딩 거부는 로컬 시험 서버를 허용하는 실행으로 복구했다. 이 예비 실패·중복 실행을 최종 통과 수에 더하지 않았다.

실제 CLI의 세 성공 실행은 **210개 과업/조건/회차 집계 기록**을 수입한다. 이는 에이전트 과업을 새로 210회 수행했다는 뜻이 아니다. 잘못된 DB URL에서도 접속하지 않고 성공하며 결과에서 본문/관찰 이력 해시가 제외되는 것을 확인했다. 여섯 옵션 충돌은 입력 읽기·출력 생성 전에 거부했다. 측정 0/null/누락·가격 미측정·분모·요약 준비량·초기/준비 상태·독립 단위·과업 유형·악화/보류·입력 순서 결정성과 출력 실패도 대조했다.

## 결과와 후속 범위

이번 검증은 합성 외부 trace를 가져오는 비교 실행기의 모듈 인수다. `agent_trace` 출처의 선언은 가져온 기록의 구분이며 CLI가 실제 에이전트 실행이나 제공자 청구를 독립 검증했다는 뜻이 아니다. 실제 에이전트 업무 효과, 유료 제공자 단가/금액, 공개 데이터의 품질·비용 개선과 최종 채택은 입증하지 않았다. 운영의 원문·응답·예산·기본 정책은 변경하지 않았다. 실제 DB·유료 API·운영 배포를 호출하지 않았으며 기존 HTTP 시험은 격리 로컬 서버를 사용했다.

EVAL-12 완료로 전체 **115개 완료·1개 진행·8개 미착수**다. 다음은 EVAL-13의 manifest 실물 연결·원자적 결과 공개·실패 보고·최종 채택 판정이다. TEST-06의 Safari·실제 음성과 실제 호스트/운영 인수도 남아 있다. 변경은 미커밋이며 개인 `.idea` 파일 두 개를 보존했다. `feat/evaluation`에 upstream이 없어 원격 대비 상태를 확인하지 못했다.

DOX pass에서 패키지·소유권·배포/스키마 경계가 유지됨을 확인해 DOX는 변경하지 않았다. SRS의 기존 업무 지표·수집 경계와 확장 요구사항도 유지했다. 평가/시험 상세 계약·분야/전체 계획·SDD 진입 상태·서비스 색인·공식 근거·요청 기록을 갱신했다.

변경 Markdown 9개·로컬 링크/앵커 501개, 개발 작업 ID 124개와 완료 115개를 대조했다. 미완료 표시 9개는 진행 1개·미착수 8개에 대응한다. Markdown 구조·DOX 색인·문서 상태·용어와 `git diff --check`를 확인했다.
