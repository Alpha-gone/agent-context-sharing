# TEST-06 노드 선택 강조 보완

## 발견과 변경

사용자 수동 검증에서 노드를 선택해도 시각적 강조가 약해 선택 여부를 알기 어렵다는 제보를 받았다. 기존 코드에서 선택 상태와 목록 aria-pressed는 갱신됐지만 그래프에는 선택 전용 스타일이 없었다. 목록 버튼의 배경·테두리 차이도 작았다.

[웹 시각 표현 정본](../sdd/web.md#시각-표현-규칙)에 선택 강조 기준을 먼저 추가했다. 그래프의 node:selected에 굵은 테두리와 바깥 underlay를 두고 계층 색·마름모·상충 점선은 유지했다. 목록 버튼은 같은 aria-pressed 상태로 진한 외곽선·배경과 `✓ 선택됨` 표식을 표시한다. 표식은 aria-hidden으로 접근성 이름과 분리하고 버튼 이름·포커스·토글 동작을 유지했다. 강제 색상 모드에는 시스템 Highlight 외곽선을 적용했다.

## 확인한 근거와 검증

적용 자산은 기존 Cytoscape.js 3.34.3이다. [공식 스타일 문서](https://js.cytoscape.org/#style)의 :selected·underlay와 [W3C 버튼 패턴](https://www.w3.org/WAI/ARIA/apg/patterns/button/)의 고정 이름·aria-pressed 규칙을 확인했다. Modern Web Guidance의 최신 패키지 다운로드/실행은 자동 승인 검토가 공급망 위험을 이유로 거부했다. 이 실행을 다른 경로로 우회하지 않았고 공식 문서와 실제 설치 자산의 스타일 계산으로 확인했다. 새 가이드를 검색/가져오는 데 성공했다고 보고하지 않는다.

실제 Cytoscape 자산을 쓰는 Node 상태 검사에 선택 시 굵은 테두리·underlay, 계층 색·상태 모양 유지와 선택 해제 시 강조 제거를 보강했다. 포인터/목록 토글·0/최대 홉·전체 복귀·범위 밖 재선택·근거 경로·pressed·포커스/고정 이름의 관련 검증을 함께 실행했다. HTML 검사에서는 노드마다 시각 표식이 있고 aria-hidden으로 분리되는지 확인했다.

필수 DB·race에서 관련 고유 시험 14건이 2.296초에 실패·건너뜀 없이 통과했다. 원시는 /private/tmp/acs-node-selection-final.json이다. 앞선 DB 없는 실행은 13건 통과·1건 건너뜀이었으며 최종 필수 DB 실행과 합산하지 않는다. 전체 의존성 검증·build·vet·gofmt도 통과했고 원시는 /private/tmp/acs-node-selection-static.log다. 실제 Safari·VoiceOver의 수정 후 관찰은 사용자 확인 대기다.

## 수정본 수동 환경과 안내

이전 20:39 세션은 20:54에 정상 종료됐고 소유 DB 컨테이너 제거를 확인했다. 이전 원시는 /private/tmp/acs-test06-user-session-before-selection.json·acs-test06-user-session-before-selection.log로 보존했다. 수정본을 새 합성 DB에서 다시 기동했고 주소는 https://127.0.0.1:60143/login, 만료는 약 2026-10-28 21:09 KST다. 실제 TLS 로그인과 상세 HTML·CSS에서 수정된 선택 스타일/표식을 제공하는지 확인했다. 초기화된 합성 환경이며 로그인 정보는 이전과 같다.

사용자가 이전 임시 안내 파일에 접근할 수 없어 프로젝트의 Git 제외 경로 .personal/test06에 접속 안내·체크리스트·연결 정보·공개 시험 인증서를 다시 준비했다. 디렉터리 0700·파일 0600을 적용했고 기존 관찰 체크리스트는 덮어쓰지 않았다. 이 파일은 사용자 검증 편의를 위한 비공개 자료이며 공개 검토의 요구사항/설계 근거로 사용하지 않는다. 서버 만료 뒤에도 안내·체크리스트는 남지만 주소의 유효 시간은 별개다.

제품 데이터·권한·외부 라이브러리 판·배포 기본값은 바꾸지 않았다. DOX pass에서는 기존 웹 구현·시각 표현·시험 소유 경계를 유지했다. TEST-06은 실제 수동 인수 진행 중이며 전체 완료 수 120개는 유지한다. 새 변경은 미커밋이다.
