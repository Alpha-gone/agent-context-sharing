## 변경과 경계

- README·OPERATIONS·두 환경 예시의 서버 OAuth·Bearer·14종 MCP와 본인 연결 폐기 상태를 현재 조립에 맞췄다. 서버/색인/감사/평가/적용 실행기의 실제 경로와 이미지 포함 범위를 명시했다. 호스트 지원·전체 브라우저·운영 공개를 구현 완료와 구분한다.
- [도구 목록](../../../../internal/mcp/testdata/tools.json)은 현재 protocol revision·instructions·14종 설명/입력 스키마/annotations다. 결정적 JSON과 실제 SDK 목록의 정의 일치를 대조했다. 성공/도메인 실패/부분 결과의 전체 스냅샷과 호스트 인수인 MCP-09·TEST-07/08은 완료 처리하지 않는다.
- [격리 실행기](../../../../test-transition.sh)는 운영 Compose에 합성 예시 환경·프로젝트·비공개 포트·internal 네트워크·새 볼륨을 적용한다. 색인은 external이며 외부 제공자를 호출하지 않는다. 013만 제외한 같은 소스의 합성 이전 이미지는 과거 출시 판을 검증한 증거가 아니다. 배포 SQL은 추가·수정하지 않았다.
- 실행 전 검토 자료에 대상·현재/목표 이미지 ID·보관 이미지·비밀을 제외한 구성 차이·적용 이력·백업/tablespace·정지 주체·중단/손실 승인 조건을 두었다. 감사 전 재기동을 막고 복귀 시 자동 migrate를 우회하는 절차를 안내한다.

## 실행 증거

Go 1.27.1 darwin/arm64의 실행기로 Linux ARM64 시험 바이너리를 만들고 고정 Dockerfile의 PostgreSQL 18.6·AGE 1.8.0·pgvector 0.8.6 및 애플리케이션 이미지를 별도 프로젝트 `transition-test-odgc7f`에서 실행했다. 실제 `.env`·운영/개발 DB·공개 포트·Cloudflare·외부 Gemini는 사용하지 않았다.

1. 이전 이미지의 적용 이력 최대 012, 전체 감사 0, 실제 서버 이미지 ID·healthz·readyz와 정상 종료 코드 0을 확인했다. 합성 계정·직접 소유권·등록·원천·키·웹 세션·pending 작업을 만들고 지문을 보존했다.
2. 서버 정지 후 plain 물리 백업·WAL stream·`pg_verifybackup`을 완료했다. 현재 이미지로 status의 pending 013 한 개→적용→재실행 무변경, 기존 표본 지문·세션 보존과 전체 감사를 확인했다.
3. 목표 이미지 ID·healthz·readyz를 확인하고 실제 저장 연산으로 파생을 생성해 013의 판 이력 1건을 사용했다. 전체 감사의 그래프 1개·위반 0을 다시 확인했다.
4. 임시 이미지에만 014 성공/015 실패 SQL을 넣었다. CLI 종료 코드 1, 014 테이블·이력 보존, 015의 테이블·그래프 이름 변경·이력 전부 롤백을 확인했다. 실패 로그는 합성 자료만 담으며 실행기 내부에서 폐기했다.
5. 새 DB 볼륨으로 백업을 복원해 013/014 부재·이전 012까지의 이력 전체 지문 일치·원본/권한/등록/키/세션/큐 지문을 확인했다. 보관한 이전 이미지로 자동 migrate 없이 전체 감사→기동·준비→정상 정지→표본 재확인을 수행했다. 전환한 원본 DB의 014 이력이 그대로 남음을 확인하여 복귀가 원본을 덮어쓰지 않았음을 대조했다.
6. 격리 fixture는 seed/verify/write 단계 총 6회 모두 통과했다. 전체 감사 CLI 4회가 각각 위반 0을 보고했다. 종료 플래그와 자신의 프로젝트 라벨로 컨테이너·볼륨·네트워크 잔여 0 및 시험 이미지 정리를 확인했다. 마지막 실행기 종료 코드 0이며 로그에 `transition:`·`restore:`·최종 `PASS`가 모두 있다.

도구 목록 시험은 최상위 3개·하위 14개, 총 17건 통과·실패/건너뜀 0이며 race가 없다. 첫 SDK 실행은 샌드박스의 `httptest` 루프백 bind 거부로 중단되어 권한을 확보한 동일 범위의 최종 실행으로 대체했다. 전체 Go 의존성·빌드·vet·gofmt와 셸 구문 검사가 통과했다. 원시 실행 결과는 `/private/tmp/acs-ops08-runtime.log`, `/private/tmp/acs-ops08-mcp-final.json`, `/private/tmp/acs-ops08-static.log`에 확인했다.

## 제한과 DOX

이번 표본은 OAuth 계열·완료 멱등성 결과·임베딩 행이 없는 합성 배포다. 이들의 비어 있지 않은 상태 보존·벡터 형상 전환은 DATA-09, cold tablespace·시점 목표 복구는 OPS-07의 별도 인수 범위를 유지한다. 모든 과거 출시 이미지·실제 호스트·외부 제공자·Tunnel·운영 장애/부하·재해 복구 시간은 검증하지 않았다. 실제 운영 배포·대상 전환·외부 공개는 검증 자료와 실제 구성을 갖춘 별도 최종 실행 단계다.

루트 DOX에 실행기 소유권을 추가했다. 패키지·환경 키·API·요구사항·용어·하위 DOX 경로는 바뀌지 않아 나머지 계약·SRS·용어집·과거 검토 기록을 보존했다. 운영 정본은 경계를, 매뉴얼은 실제 명령을, 계획·검토·요청 기록은 이번 결과를 소유하도록 유지했다. 커밋·푸시는 수행하지 않았다.
