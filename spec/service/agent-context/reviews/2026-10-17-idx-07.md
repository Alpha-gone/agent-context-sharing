# IDX-07 전체 재색인·형상 변경 모듈 검토

- 기준: [색인 계획 IDX-07](../development-plan/indexing.md#idx-07), [재색인](../sdd/indexing.md#재색인), [전환·복귀](../sdd/indexing.md#전환복귀-경계), [DATA-07](../development-plan/data.md#data-07).
- 범위: 현재 대상 재등록, 모델·입력 판 격리, 계층 전환, 진행 집계, 기존 타입·차원 전환 표본과 복구. 실제 전환 마이그레이션의 배포·이력 이행 전체는 [DATA-09](../development-plan/data.md#data-09)에서 수행한다.

## 발견 사항과 구현

| ID | 영향도 | 발견 사항 | 처리와 근거 |
|---|---|---|---|
| IDX07-R1 | 중간 | `ReindexGraph`가 삭제 컨텍스트도 재등록하고 소비자가 폐기·제외 대상을 제공자에게 전달했다. | 대상 열거·등록을 같은 트랜잭션에 두고 활성 대상만 등록한다. 소비 직전 삭제·대상 여부를 확인하고 같은 확보 세대의 작업만 제거한다. 삭제 대상의 제공자 호출 0회와 복구 후 재등록을 검증했다. |
| IDX07-R2 | 중간 | 옛 모델 행만 진행률로 기록하고 0이면 관측을 중단하여 차원 전환 뒤 미색인·pending·failed를 놓쳤다. | `ReindexProgress`가 같은 SQL 스냅숏에서 현재 활성 대상의 옛 모델·현재 모델 누락과 범위 내 큐의 pending·failed를 계산한다. 1분 주기 관측을 유지하며 항목의 중복을 합계 완료율로 표시하지 않는다. 그래프/전체 집계·리스·실패·읽기 무변경·취소·로그를 검증했다. |
| IDX07-R3 | 중간 | 같은 모델의 계층 변경은 기동 시 옛 모델 검색으로 발견되지 않아 원천 제외 잔여나 재포함 누락이 남았다. | 제외 원천의 벡터·작업과 현재 대상의 벡터/작업 동시 누락을 찾는다. 이미 있는 리스·재시도·failed만으로 재등록하지 않는다. 원천 제외·재포함과 이전 확보분의 성공/실패 무효화를 검증했다. |

- 위 세 항목은 수정·재검증 완료다. 제외 계층은 작업→임베딩 순서로 같은 트랜잭션에서 제거하며 실제 벡터 제거가 있을 때만 내용 판을 증가시킨다. 재등록은 기존 upsert·실패 초기화·세대 보호 계약을 사용한다. 확인된 미해결 결함은 없다.
- 기존 의미 검색·관계 제안의 graph_id/model_id 필터와 형상 기동 검사를 유지하고 새로운 실행 근거를 확보했다. 옛 물리 행 집계 API는 호환성을 유지하며 삭제 보존 벡터도 포함하는 수임을 주석으로 명시했다. 신규 진행 API와 구분한다.
- DOX pass: 패키지·소유권·실행기·설정·의존성 변화가 없어 DOX·SRS·용어집은 유지한다. 색인 SDD의 활성 대상·네 집계 설명을 기존 전환 계약과 정합화했다. 데이터 설계·기존 SQL·checksum은 변경하지 않았다.
