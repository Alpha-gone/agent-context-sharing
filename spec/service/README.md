# 서비스 명세 색인

## 목적

이 문서는 프로젝트에서 기획하는 서비스의 범위, 상태와 주요 명세 진입점을 제공한다.

## 서비스 목록

| 서비스                 | 역할                                                                                                                                 | 상태 | 주요 문서                   |
|------------------------|--------------------------------------------------------------------------------------------------------------------------------------|------|-----------------------------|
| 에이전트 컨텍스트 관리 | AI 에이전트 제텔카스텐을 공유 컨텍스트 그래프로 구현하고, MCP 기반 작업 컨텍스트 흐름과 여러 작업자의 컨텍스트 공유·협업을 지원한다. | 확정 | [SRS](agent-context/SRS.md) |

## 서비스 관계

현재 정의된 서비스는 AI 에이전트 제텔카스텐을 궁극적인 목표로 삼고 공유 컨텍스트 그래프를 핵심 접근 방식으로 사용하는 에이전트 컨텍스트 관리 서비스 하나다. 하나의 그래프를 중심으로 여러 작업자의 컨텍스트 공유와 협업을 지원하며, 추가 서비스나 외부 시스템 경계는 후속 기획에서 확정한다.

## 공통 미정 사항

- 응답 직렬화 형식
- 화면 배치와 시각 디자인, Row Level Security 채택, 벡터 인덱스 방식
- 공개 벤치마크 선정, 재시도 한계와 반복 횟수 조정
- 계정 플랜의 이름과 구체 값 (명세는 항목과 기본값만 정하고 값은 운영 구성으로 둔다)
