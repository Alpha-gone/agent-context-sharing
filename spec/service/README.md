# 서비스 명세 색인

## 목적

이 문서는 프로젝트에서 기획하는 서비스의 범위, 상태와 주요 명세 진입점을 제공한다.

## 서비스 목록

| 서비스                 | 역할                                                                                 | 상태 | 주요 문서                   |
|------------------------|--------------------------------------------------------------------------------------|------|-----------------------------|
| 에이전트 컨텍스트 관리 | MCP 서버로서 토큰 인증 후 작업 컨텍스트 흐름을 에이전트에 제공하고 여러 작업자의 컨텍스트 공유·협업을 지원한다. | 초안 | [SRS](agent-context/SRS.md) |

## 서비스 관계

현재 정의된 서비스는 하나의 공유 컨텍스트 그래프를 중심으로 여러 작업자의 협업을 지원하는 에이전트 컨텍스트 관리 서비스 하나다. 추가 서비스나 외부 시스템 경계는 후속 기획에서 확정한다.

## 공통 미정 사항

- MCP primitive, transport, protocol revision과 작업 컨텍스트 흐름 응답 스키마
- 에이전트, 사용자와 프로젝트 사이의 컨텍스트 격리 정책
- 작업자 식별, 공유 권한과 동시 갱신 충돌 처리 정책
- 인증 주체·OAuth 매핑·서버 검증 상태, 세부 인가, 배포와 운영 모델
