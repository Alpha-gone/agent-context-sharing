# #173 폐기된 사건 구성원의 입력 거부와 재생

- 대상: [이슈 #173](https://github.com/Alpha-gone/agent-context-sharing/issues/173).
- 기준: `dev`의 `d742682`, 작업 브랜치 `fix/173-discarded-event-members`.

## 원인과 변경

`validateEventMembers`가 폐기된 구성원을 일반 오류로 반환하여 MCP의 결정적 입력 거부 분류를 통과하지 못했다. 이 때문에 `internal` 응답과 전체 롤백이 발생해 거부 감사와 요청 키의 재생 결과가 남지 않았다. 이 오류를 `model.FieldError{Field: "member_refs"}`로 바꾸어 기존 `invalid_argument`·거부 감사·멱등성 저장 경계를 사용한다. 저장 값 해석 장애의 `StorageError` 처리와 실제 내부 장애의 롤백은 유지한다.

사건 생성과 모든 일반 갱신에서 최종 구성원 집합을 재검증하는 기존 정책을 유지한다. `member_refs`를 생략한 본문·시간 변경도 폐기된 기존 구성원이 있으면 거부하며, 활성 구성원으로 참조를 고친 갱신은 허용한다. 구성원 폐기가 기존 사건을 자동 폐기하지 않는 정책과 함께 [수명주기 정본](../sdd/context-lifecycle.md#사건-재구성)에 명시하고 [시험 설계](../sdd/testing.md)에 검증 범위를 반영했다. 기존 입력 오류 요구사항과 MCP 오류·멱등성 계약을 구체화하므로 SRS·공개 스키마·배포 구성은 변경하지 않았다. DOX pass에서도 책임·구조·색인 변경이 없어 DOX를 유지했다.

## 검증

Go 1.27.1과 별도 합성 PostgreSQL/AGE 컨테이너를 사용하고 `TEST_DATABASE_REQUIRED=1`로 DB 건너뜀을 금지했다. 기존 개발 DB와 운영 구성은 사용하지 않았다.

- 수정 전 신규 회귀의 생성·구성원 변경·본문만 변경·시간만 변경 네 경로 모두 `invalid_argument` 대신 `internal`로 실패했다.
- 수정 후 신규 회귀는 race에서 5건 통과했다. 네 경로의 `member_refs` 필드 오류, 거부 감사·재생 기록 각 1건, 기존 사건 미변경·새 노드 미생성, 활성 참조 복구 성공을 확인했다. 복구 후 다른 Store 인스턴스에서 이전 키를 재생해 동일 결과와 전체 쓰기 fingerprint 불변을 대조했다.
- 관련 저장소 회귀 `go test -race -count=1 -json -timeout=10m -run 'Test(LifeEvent|Event|ConcurrentDiscard|ContextRevisionReference|IsolationWriteReferences|Reference)' ./internal/store`: 77건, 7.069초, 실패·건너뜀 없음.
- MCP·서버 전체 `go test -race -count=1 -p 1 -json -timeout=15m ./internal/mcp ./cmd/server`: MCP 480건(10.312초), 서버 693건(118.535초) 통과. 서버의 실제 CLI 19건·물리 복구 1건·이전 인수 1건은 별도 실행 환경 미설정으로 건너뛰었으며 통과로 집계하지 않았다. 건수는 하위 사례를 포함하며 신규 회귀는 서버 전체 건수에도 포함된다.
- `go build ./...`, `go vet ./...`, `gofmt -l .`, `git diff --check` 통과. 정본 두 문서의 상대 링크·앵커 84개를 확인했다.
- 읽기 전용 독립 검토는 Critical/Important/Minor 발견 사항 없이 Ready였다. 독립 검토자는 별도 시험을 실행하지 않았고 위 실행 결과는 구현자가 확인했다.

결과는 `/private/tmp/acs-173-red.log`, `acs-173-green.json`, `acs-173-store.json`, `acs-173-modules.json`에 남겼다. 시험별 임시 DB 잔류 없음과 idle transaction 0개를 확인한 뒤 소유 식별자를 대조해 생성 컨테이너·볼륨만 정리했다. 사용자의 `AGENTS.md` 변경과 개인 IDE 파일은 보존하고 커밋에서 제외했다. 실제 CLI·운영 배포 인수는 이번 수정의 검증 범위가 아니다.
