# 대화 수집 개발 계획

[전체 계획](../DEVELOPMENT_PLAN.md) · [기준 SDD](../sdd/conversation-ingestion.md) · [작업 추적](traceability.md)

## 목표와 구현 범위

2026-11-14 사용자 결정으로 추가한 대화 수집을 구현하고 기록에 드는 에이전트 사용 비용의 전후를 측정한다. 기존 124개 작업, LIFE-10과 RINF-01~06의 인수 이력을 승계하지 않는다. INGEST-01~05는 모두 미착수다.

- 설계 입력: [처리 흐름](../sdd/conversation-ingestion.md#처리-흐름), [수집 경로](../sdd/conversation-ingestion.md#수집-경로), [수집 자격](../sdd/conversation-ingestion.md#수집-자격), [서버 구간화](../sdd/conversation-ingestion.md#서버-구간화), [설계 대기 항목](../sdd/conversation-ingestion.md#설계-대기-항목).
- 착수 조건: `TBD-AGENT_CONTEXT-066`~`068`을 정하고 기준 SDD의 설계 대기 항목을 확정한 뒤 착수한다. 그 전에는 코드·스키마를 변경하지 않는다.
- 다른 분야와의 경계: 대화·턴 저장은 데이터, 사건 생성 트랜잭션은 수명주기, 연결 관리 화면은 웹, 구성 검증은 운영, 진단 필드는 관측성 계획이 소유한다.
- 실행 제한: 기존 운영 DB에 migration을 적용하지 않는다. 수집 클라이언트는 사용자의 실제 대화 기록을 사용자 승인 없이 전송하지 않으며 시험에는 합성 대화를 사용한다.

## 개발 작업

### INGEST-01

- [ ] **수집 자격의 저장·발급·폐기·검증을 구현한다.**
- 선행: [AUTH-10](authentication.md#auth-10), [WEB-08](web.md#web-08), `TBD-AGENT_CONTEXT-067`의 결정.

1. 수집 자격의 저장 스키마를 새 migration으로 추가하고 해시 저장·계정 결합·폐기 판정을 구현한다.
2. 연결 관리 화면에 발급·목록·폐기 동작을 추가하고 원문을 발급 응답에서만 표시한다.
3. OAuth Bearer 검증기와 분리한 수집 자격 검증기를 구현한다.

- 산출물: migration·저장 API·검증기·연결 관리 화면 변경.
- 완료 기준: 수집 자격이 `/mcp`와 웹 경로에서 거부되고 OAuth 접근 토큰이 수집 경로에서 거부되며, 폐기 뒤의 요청과 다른 계정의 폐기 시도가 거부되고 원문이 저장·로그·응답에 남지 않는다.

### INGEST-02

- [ ] **수집 경로와 턴별 원천 저장을 구현한다.**
- 선행: [INGEST-01](#ingest-01), [LIFE-10](context-lifecycle.md#life-10), `TBD-AGENT_CONTEXT-068`의 결정.

1. 수집 경로의 요청 검증·본문 상한·그래프 등급·한도 검사를 구현하고 서버 조립에 연결한다.
2. 턴을 기존 원천 생성 경로로 저장하고 대화·턴 유일 제약으로 건너뜀과 본문 불일치 거부를 판정한다.
3. 활성 여부를 정하는 배포 구성 키의 검증과 허용 목록·두 환경 예시·실행 안내를 갱신한다.

- 산출물: 경로 처리기·저장 연결·구성 검증과 재전송 표본.
- 완료 기준: 같은 묶음의 재전송이 원천을 늘리지 않고, 본문이 다른 턴만 거부되며, 열람자 등급과 한도 초과가 에이전트 쓰기와 같은 결과로 거부되고 MCP 도구 스냅숏이 바뀌지 않는다.

### INGEST-03

- [ ] **서버 구간화 작업과 사건 생성을 구현한다.**
- 선행: [INGEST-02](#ingest-02), [RINF-05](relation-inference.md#rinf-05), `TBD-AGENT_CONTEXT-066`의 결정.

1. 구간화 작업의 등록·확보·재시도를 구현하고 내장·분리 작업자 배치에 연결한다.
2. 확정한 기준으로 수집 원천을 사건으로 묶고 위임 계정의 등급을 반영 시점에 다시 확인한다.
3. 관리 연산 기록의 판정 주체 `ingest`와 불변식 감사 규칙을 반영한다.

- 산출물: 작업 큐·구간화 처리·모델과 감사 변경.
- 완료 기준: 구간화 실패가 저장한 원천을 되돌리지 않고, 위임 등급을 잃은 계정의 사건이 만들어지지 않으며, 에이전트가 만든 원천과 사건이 바뀌지 않고 서버가 만든 사건에서도 색인·관계 추론 작업이 등록된다.

### INGEST-04

- [ ] **수집 클라이언트와 실행 안내를 작성한다.**
- 선행: [INGEST-02](#ingest-02).

1. 지원 호스트의 대화 기록 형식과 실행 시점을 공급자 공식 문서로 확인하고 확인되지 않은 호스트는 지원 대상에서 제외한다.
2. 대화 기록을 읽어 수집 경로로 전송하고 기록 제외 대화·구간을 전송하지 않는 클라이언트를 구현한다.
3. README에 수집 자격 발급, 클라이언트 설정과 기록 제외 방법을 추가한다.

- 산출물: 수집 클라이언트·실행 안내·호스트별 확인 기록.
- 완료 기준: 합성 대화 기록의 전송과 재전송이 서버 저장 결과와 일치하고, 제외 표시한 구간이 전송 본문에 없으며, 자격 원문이 클라이언트 출력과 로그에 남지 않는다.

### INGEST-05

- [ ] **분야 통합 시험을 수행하고 사용 비용의 전후를 측정한다.**
- 선행: [INGEST-03](#ingest-03), [INGEST-04](#ingest-04).

1. 별도 합성 DB에서 자격 발급부터 전송·저장·구간화·관계 추론 작업 등록·조회까지의 통합 시험을 수행한다.
2. 같은 합성 대화를 에이전트 도구 경로와 수집 경로로 기록하여 호출 수와 요청·응답 크기를 비교한다.
3. 실제 호스트의 모델 토큰과 검색 활용도는 별도 실증으로 구분해 기록한다.

- 산출물: 통합 시험 기록과 전후 비교 결과.
- 완료 기준: 격리·권한·로그 금지 필드 검사와 build·vet·gofmt가 통과하고, 측정하지 않은 항목이 절감으로 표시되지 않는다.
