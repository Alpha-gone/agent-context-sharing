## 혼합 쓰기의 교착 재현과 수정

신규 [혼합 인수 시험](../../../../internal/store/storage_acceptance_integration_test.go)은 정식 스키마를 가진 독립 DB에 두 저장소를 조립한다. 각 풀은 실제 연결 4개로 제한한다. 같은 그래프에서 원천 자연 키 중복 2개·같은 정체성의 관계 확정 2개·같은 판의 파생 갱신 2개·남은 저장량 한 자리를 다투는 서로 다른 노드 복구 2개를 함께 실행한다. 선행 그래프 잠금에 실제 두 연결이 대기한 것을 확인한 뒤 해제한다.

폐기 fixture의 MCP 채널을 맞춘 뒤 수정 전 10회 중 7회에서 PostgreSQL `40P01` 교착을 재현했다. 노드 갱신이 AGE label/정점을 잡고 그래프를 기다리는 동안, 관계 확정은 그래프를 잡고 AGE label의 ShareLock을 기다렸다. 원천 중복·복구의 그래프/정점 대기도 같은 순환에 포함됐다. 실제 DB 로그로 확인했으며 보존된 원인을 숨기는 공개 오류 문자열을 바꾸지 않았다.

잠금 순서 정본을 먼저 고치고 노드 생성·갱신·유지·폐기·복구를 그래프→AGE/정점 순서로 통일했다. 관계 처리의 기존 그래프 잠금과 맞추며 참조 전이 자문 잠금·빈도 행의 선행 순서는 유지한다. 같은 그래프에서 이미 필요한 직렬화 시점을 앞당겼고, 전역 잠금·스키마·관계 판·자동 재시도는 추가하지 않았다. 잠금 대기 뒤 현재 판·삭제 회차·권한·저장량을 다시 판정한다. 다른 그래프의 독립성과 취소·저장점/바깥 커밋 수명도 관련 회귀에서 대조했다.

수정 뒤 혼합 시나리오 10회가 모두 통과했다. 최종 분야 실행에서도 같은 시험이 통과했다. 원천은 원래 식별자를 반환하고 관계는 하나로 합쳐지며, 갱신과 복구는 각각 한 번 성공하고 나머지는 현재 판 충돌·저장량 제한으로 거부된다. 실제 활성 문자 합계와 누계를 비교한다. 커밋 직전 장애를 추가로 주입해 정점·간선·판 이력·저장량·큐·감사·멱등성 결과가 모두 롤백됨을 확인하고 전체 불변식 감사와 연결/예약 반환을 대조한다.

## 시험 준비와 기대값 정합화

- 그래프 입력 검증은 nil 수신자 대신 DB 연결이 없는 저장소 객체를 사용한다. 입력이 DB 접근 전에 거부되는 검증 목적은 같다.
- 합성 TLS 임베딩 시험에는 원천 작성자의 실제 계정 fixture를 추가했다. 외부 Gemini를 호출하지 않는다.
- 기존 근거 무효화 fixture가 그래프 잠금 안에서 다른 공개 갱신을 동기 호출해 멈추므로 해당 실행을 중단했다. 공개 경로는 그래프 대기 뒤 새 본문·판을 읽는 직렬화로 검증한다. 방어적 0행 충돌·전체 롤백은 잠금을 우회한 시험용 AGE 쓰기로 분리해 검증한다. 유지 판단의 선행 트랜잭션도 정본 순서로 잠근다.
- 계층 이동 경합 시험은 정본의 한 번 재시도 뒤 남은 `40001` 반환을 실패로 취급하던 기대값을 바로잡았다. 주기 이동과 접근 기록의 반환 횟수를 따로 기록하고, 그 밖의 오류는 실패한다. 중복·유실 없음과 경합 종료 뒤 12개 전체의 hot 승격·접근 시각·연결/예약 회복을 직접 확인한다. 재시도 횟수·다른 오류/취소 전파는 기존 결정적 단위 시험으로 검증한다. 제품의 재시도 정책은 그대로다.

중간 전체 실행에서 유지 판단의 조회 횟수와 웹 삭제의 선행 잠금 fixture도 새 순서에 맞춰 수정했다. 재검증 범위를 같은 합성 관리 DB에서 겹쳐 실행하여 전역 fixture 지문에 영향을 준 실행은 중단했다. 누적 표본에서 복합 인덱스 계획 기대값이 달라진 결과도 인수로 사용하지 않고 새 관리 DB에 정식 스키마를 적용해 쓰기·조회 계획·마이그레이션·감사를 순차 재실행했다. 최종 집계는 같은 제품 코드의 통과한 홉 범위와 이 순차 재실행만 사용한다.

## 호환 범위·정리·DOX pass

선언된 PostgreSQL 13~18·AGE 1.8.0 이상·pgvector 0.7.0 이상의 전체 조합을 인수한 것이 아니다. 실행 조합은 위 고정 이미지뿐이며 다른 PostgreSQL/확장 판·Linux amd64·다른 실제 저장 장치는 미시험이다. bit 구성은 여전히 거부한다. 실제 운영 복원·배포·Gemini 실연결·호스트·브라우저 인수와 품질/비용/지연의 개선 판정은 이번 범위가 아니다.

`agent-context.task=data10` 라벨의 전용 tmpfs 컨테이너만 생성했다. 종료 뒤 시험 DB/연결 정리를 확인하고 해당 컨테이너를 제거했다. 물리 복원 실행도 자체 클러스터·볼륨·백업·이미지만 제거했다. 기존 개발 DB·WAL 정리 컨테이너 두 개는 유지했다.

기존 저장소·명세 DOX의 소유 경계 안에서 구현·시험·잠금 정본·현재 인수 상태·검토/요청/근거 기록을 정합화했다. 요구사항·공개 API·패키지 의존·스키마·구성값·용어·정본 소유권은 그대로여서 SRS·DOX·용어집·요구사항 대응표를 유지했다. 변경은 미커밋이며 `.idea`의 기존 미추적 설정 두 파일은 제외한다.
