## 목표와 구현 범위

서버 렌더링 기반 여섯 업무 화면, 로그인·가입과 목표 연결 관리 화면을 새로 구현한다. 그래프 시각화는 반환된 부분 그래프 안에서 전체·국소 보기와 동등한 포인터·키보드 선택을 제공한다.

- 설계 입력: [요청 순서](../sdd/web.md#웹-요청-처리-순서), [화면 계약](../sdd/web.md#웹-화면-계약), [배치](../sdd/web.md#화면-배치), [표현 규칙](../sdd/web.md#시각-표현-규칙), [연결 관리](../sdd/web.md#목표-연결-관리-화면).
- 예정 구현 영역: `internal/web`의 처리기·html/template·내장 자산, 서버의 웹 어댑터.
- 다른 분야와의 경계: 계정·자격 판정은 인증, 권한·팀 쓰기는 권한, 삭제·유예는 수명주기, 감사·연결 저장은 각 소유 계획이 담당한다.

### WEB-06

- [x] **그래프 상세·전체/국소 시각화 상태를 구현한다.**

4. 한도 없는 슬라이더는 반환 n개 노드의 0..max(0,n-1), 빈/단일 그래프는 0으로 구성한다. 보기 전환으로 추가 조회·한도 우회를 하지 않는다.

- 완료 기준: 고립·다중 시작점·빈 그래프에서 보기가 회복되고 삭제 노드를 가리키는 선이 없다. 상세에서만 시각화 자산을 사용한다.
- 완료 근거: 2026-10-24 [WEB-06 모듈 인수](../reviews/2026-10-24-web-06.md). 왼쪽 그래프 속성·전역 요약 영역, 참조 실선/사건 관계 점선과 연결 범례, 선택 상세의 상태 표식을 보완했다. 실제 DB/TLS에서 빈 그래프·활성 시작점·전역 요약 시작점, 한도 없음 n-1·유한 홉·노드 상한 절단 슬라이더, 관계 분류와 삭제 노드·간선 제외, 상세 전용 자산과 삭제 그래프 404를 확인했다. 신규 8건을 포함한 웹 751건·race·Node.js 상태 전이·전체 Go 정적 검사가 실패·건너뜀 없이 통과했다. 실제 브라우저·보조 기술·전체 웹 인수는 후속 범위이며 다음 권장은 WEB-07이다.
