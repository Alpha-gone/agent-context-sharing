# RINF-06 후속 평가 사전 계획

상태: **완료(2026-11-15)**. [정식 인수 결과](2026-11-15-rinf-06-acceptance.md)에서 신규 독립 표본·정답 검토·4,000회 판정·120회 전체 흐름·총비용과 최종 활성화 보류를 확인한다. 기존 초안의 탐색 결과는 정식 합격 근거에 소급 사용하지 않았다.

## 후속 정식 평가의 사전 판정 기준

2026-11-15 사용자 위임으로 [SRS 관계 추론 모델 비교](../SRS.md#관계-추론-모델-비교)에 유형별 품질·표본·반복·보류 기준을 확정했다. SRS가 정본이다. 기존 탐색 측정은 합격 근거로 소급 사용하지 않으며 현재 자료는 표본 수와 정답 조건이 부족하므로 자동 확정을 보류한다.

## 자료 및 실행 경계

새 평가 자료는 그래프, 시간·구성원, 정답 관계와 채널별 검색 정답을 포함한다. 판정 입력은 실제 후보 생성 경로에서 고정하며 무관 후보, 인과 근거 부재, 판단 보류, 유도 지시와 양방향 사례를 포함한다. 조정·판정 과업과 생성 템플릿을 분리하고 판정 표본의 의미와 정답은 작성자가 아닌 검토자가 확인한다. 원본 및 정답 checksum, 프로필 지문, 순서, 반복 횟수, 가격 판을 실제 호출 전에 고정한다.

같은 초기 그래프와 과업에서 `agent_relations`와 `server_apply`의 실제 trace를 각각 수집한다. 에이전트, 임베딩, 추론, 재시도와 검색을 포함한 전체 비용을 별도로 기록한다. 기존 실행기는 trace를 수입할 뿐 에이전트 과업을 실행하지 않으므로 별도의 실제 수집 경로가 필요하다.

승인 예산은 전체 미화 10달러다. 각 제공자의 실제 요금제와 사용량, 요청당 최대 토큰 및 실패·재시도 상한을 확인해 호출 전 보수적 최대 비용을 계산하고 누적 사용량을 기록한다. 한도를 강제할 수 없거나 누적 비용을 알 수 없으면 호출을 중단한다. 실제 청구 금액과 추정치를 구분한다.

## 현재 상태

합격선은 SRS에 확정했고 신규 독립 판정 표본과 실제 생성 입력·전체 흐름·총비용의 정식 인수를 완료했다. 두 유형은 품질 기준을 통과했지만 과업별 품질 비악화 조건이 실패하여 자동 확정 활성화는 보류한다. 운영 후속 판단은 이번 측정 작업의 미완료 조건으로 남기지 않는다.

## 정식 인수 실행 계획

- [x] 새 독립 합성 과업의 `relates_to`·`part_of` 양성/음성 각 100건을 준비한다. 의미 정답은 모델 판정 응답과 분리하여 검토하고 표본·정답·생성 코드 checksum을 호출 전에 고정한다.
- [x] 실제 후보 생성·`BuildInput`·`ValidateOutput`을 사용하는 판정 실행기에 출력 토큰 상한과 누적 예산 예약을 적용한다. 각 독립 표본을 10회 반복하고 반복을 독립 단위로 더하지 않는다.
- [x] 동일 과업·초기 그래프·동일 모델의 두 조건을 동등한 유형 범위로 실행한다. 준비·임베딩·재시도·후속 검색·실행 전체의 토큰 및 캐시 세부, 지역 실행 자원과 할당 단가를 고정해 총비용을 산정한다. 무료/비과금과 미측정을 구분한다.
- [x] SRS의 유형별 기준과 전체 비용을 판정하고, 불합격도 유효한 종료 결과로 기록한다. 결과 묶음·문서 상태·검증과 독립 최종 검토를 마친다.

누적 제공자 예산은 앞선 측정의 보수 환산 $0.0231057을 포함해 $10이다. 소규모 결과만으로 위 계획을 완료 처리하지 않는다.

실행 종료: `rinf-06-acceptance/bundle/summary.json`의 `measurement_complete=true`, `assessment=negative_qualification`, `default_activation=false`와 검증된 비용 상한 $1.0840251을 따른다.
