# 운영자 복구의 요청자 소유자 등급 복원 검증

## 결정과 수정

GitHub 이슈 [#51](https://github.com/Alpha-gone/agent-context-sharing/issues/51)은 운영자 복구가 삭제·유예 상태만 해제하고 접근 등급을 복원하지 않아 아무도 접근할 수 없는 활성 그래프를 남기는 문제다. 사용자는 2026-10-04에 복구 요청자의 소유자 등급을 복원하는 방식을 선택했다. SRS의 `FR-AGENT_CONTEXT-108`과 「복구 요청」, SDD의 「복구」에 정책과 트랜잭션 경계를 먼저 반영했다.

`OperatorRestoreGraph`는 그래프 행을 잠근 뒤 자동 삭제 상태와 가장 오래된 미처리 요청을 확인한다. 요청자에게 직접 `owner` 등급을 upsert하고 삭제·유예 상태를 해제하며, 같은 `operator_restore` 감사 기록에 요청자·운영자와 직접 등급의 이전·이후 값을 남긴다. 전부 같은 트랜잭션이며 실패하면 부분 적용을 남기지 않는다. 다른 계정·팀 등급과 팀 구성원은 유지하고 운영자 자격만으로는 등급을 부여하지 않는다. 기존 감사 속성을 사용하므로 스키마·공개 API·의존성 변경은 없다.

## 재현과 회귀

마지막 팀 구성원 제거로 접근이 사라진 뒤 해당 표본의 유예 시각만 과거로 옮기고 현재 시각으로 자동 삭제했다. 생성자와 등급 감사 이력으로 확인되는 과거 소유자 두 경우 모두 복구를 요청하게 했다. 수정 전 두 경우 모두 복구 뒤 유효 등급이 없어 신규 접근 회복 테스트가 실패했다.

수정 후 다음을 확인했다.

- 두 요청자가 직접 소유자로 복원되고 활성 그래프 목록에서 소유자 등급으로 조회된다. 삭제·유예 시작·유예 만료 시각은 모두 해제된다.
- 요청자와 다른 운영자에게 등급이 생기지 않고 팀 구성원도 되살아나지 않는다.
- 기존 직접 `viewer` 등급은 `owner`로 복원하고 다른 계정의 `editor`는 유지한다. 감사 기록은 없던 등급과 기존 등급의 이전·이후 값을 구분한다.
- 실제 그래프·등급 쓰기 뒤 감사 쓰기에만 오류를 반환하는 테스트 트랜잭션 대역을 사용했다. 저장점 롤백 뒤 삭제·유예와 등급 부재가 유지되고 정상 재시도는 성공한다. 프로덕션 코드에 시험용 분기는 추가하지 않았다.
- 동시 복구 네 건 중 한 건만 성공하고 처리 감사 기록도 한 건만 남는다.
- 활성 그래프와 웹 직접 삭제 그래프는 과거 요청이 있어도 거부된다. 요청 없는 자동 삭제 그래프도 거부되며 소유자 등급을 부여하지 않는다.

## 검증 결과

Go 1.27.1과 PostgreSQL·AGE 개발 DB를 사용했다. DB 테스트에는 `TEST_DATABASE_URL`과 `TEST_DATABASE_REQUIRED=1`을 설정했다.

```shell
go test -race ./internal/store -run '^(TestOperatorRestore|TestWebRestore|TestRevokeGraphGrant|TestRemoveTeamMember|TestGrantGraph)' -count=10
# 서버 루트와 client/에서 각각 실행
go test ./...
go build ./...
go vet ./...
# 서버 전체 결과에서 실패·건너뛰기 확인
go test -json ./...
# 저장소 루트
gofmt -l .
git diff --check
```

신규 복구 회귀와 기존 웹 복구·등급·팀 구성원·유예 회귀가 race 검사로 10회 통과했다. 서버 전체 테스트는 DB 통합 계층을 포함해 통과했고 클라이언트 전체 테스트, 양쪽 모듈 build·vet도 통과했다. 최종 서버 JSON 결과에 실패나 테스트 항목의 건너뛰기는 없었고 테스트 파일이 없는 세 패키지만 `skip`이었다. gofmt 미정리 파일과 diff 공백 오류도 없었다. 별도 `embedding_live` 실제 제공자 시험과 운영 부하 시험은 실행하지 않았다.

## DOX와 범위

루트와 `spec/`→`spec/service/`→`agent-context/` DOX 체인, 용어, 한국어 맞춤법·띄어쓰기와 문서 정합성을 점검했다. 서비스 AGENTS에 요청자 등급 복원의 원자적 경계를 추가하고 SRS·SDD·요청 기록을 갱신했다. 소유권 경계·폴더 구조는 바뀌지 않아 부모 AGENTS와 Child DOX Index는 유지했다. 외부 기술 근거를 새로 사용하지 않아 `reference.md`는 유지했다.

이전 복구로 이미 접근 불능 상태가 된 그래프를 일괄 수정하지 않는다. 합성 시험 데이터를 개발 DB에 기록했으며 DB 초기화·볼륨 삭제·운영 권한 변경·외부 API 호출·배포는 수행하지 않았다. 커밋·푸시·PR 생성과 GitHub 이슈 종료는 아직 수행하지 않았다.
