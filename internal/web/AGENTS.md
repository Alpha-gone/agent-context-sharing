# 웹 관리 전송 계층

## 목적

- `internal/web/`은 웹 세션으로 인증한 사용자와 운영자에게 그래프 관리·시각화 화면을 제공한다.

## 소유권

- `spec/service/agent-context/SDD.md`의 「웹 화면 계약」과 「시각 표현 규칙」이 화면 동작과 접근 경계를 소유한다.
- 이 폴더는 HTTP 경로 처리, 서버 렌더링 템플릿과 브라우저 시각화 자산을 소유한다.

## 로컬 계약

- 보호 화면은 MCP 접근 토큰이 아닌 `web` audience의 웹 세션 쿠키만 받는다.
- 인가 서버에는 검증된 세션의 계정과 최초 인증 시각을 함께 전달한다. 요청 입력이나 현재 시각으로 인증 시각을 대신하지 않는다.
- 그래프별 화면은 요청 계정의 유효 등급을 먼저 확인하고, 화면 데이터는 같은 `graph_id`만 렌더링한다.
- 권한과 팀 관리만 예외로 세션까지만 요구한다. 등급 부여·회수와 등급 표는 소유자에게만 두고, 팀 동작은 `store`의 팀 관리자 판정에 맡긴다.
- 그래프 상세는 화면 전용 조회를 만들지 않고 「홉 범위 조회」를 쓴다. 그 규칙의 결과 상한과 절단 경계를 화면에 그대로 싣는다.
- 플랜의 홉 한도 `0`은 한도 없음으로 조회하며, 국소 보기 슬라이더에는 「웹 화면 계약」이 정한 표시 노드 수 기반의 유한 범위를 전달한다. 조회의 `0홉`과 혼동하지 않는다.
- 소프트 삭제된 컨텍스트는 복구 화면 밖에서 표시하지 않는다. 노드의 삭제와 복구는 삭제와 복구 화면에 둔다.
- `assets/cytoscape.min.js`와 `CYTOSCAPE-LICENSE.txt`는 함께 유지한다. 자산은 CDN으로 대체하지 않는다.
- 자산 응답에는 내용 해시로 만든 `ETag`와 보관 지시를 싣는다. 내장 파일의 수정 시각이 제로 값이라 이것이 없으면 조건부 요청이 성립하지 않는다.

## 작업 지침

- 템플릿에 전달하는 브라우저 데이터는 서버에서 만든 값만 사용하고, 사용자 입력을 신뢰된 JavaScript로 삽입하지 않는다.
- 권한·팀 관리와 사용자 직접 삭제는 웹 경로에만 두고 MCP 표면에 추가하지 않는다.
- 화면 변경이 SDD의 동작·경계·시각 규칙을 바꾸면 SDD를 먼저 갱신한다.

## 검증

- `go test ./internal/web ./cmd/server`를 실행한다.
- 그래프 상세의 세션·등급 검사와 정적 Cytoscape.js 자산 경로를 확인한다.
