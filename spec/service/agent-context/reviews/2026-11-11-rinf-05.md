# RINF-05 추론 노출·진단·작업자 조립 검증

## 범위

사건 쓰기의 추론 작업 등록과 색인 작업자 배치를 따르는 추론 소비자를 서버·분리 실행기에 연결했다. `off`에서는 추론 제공자와 작업을 만들지 않고, 활성 모드에서는 OpenAI 어댑터와 현재 임베딩 모델·후보 예산으로 프로필을 구성한다. 기동 지문과 자동 확정 상태를 시스템 진단에 기록한다.

MCP `relation_list`에 확정 주체와 추론 판정 출처를 추가하고 `propose`·`apply`에서만 서버 관계 탐색 안내를 제공한다. 색인 종류에는 추론 작업·제공자·큐 지표를, 관리 종류에는 판정별 적용·거부를 고정 코드와 검증된 식별자로 기록한다. 본문·발췌·근거·판정 사유·자격 증명은 진단에 기록하지 않는다.

## 검증

- 필수 합성 DB의 실제 조립 서버에서 내장·분리 배치의 MCP 사건 생성부터 대역 제공자 판정·관계 조회까지 확인했다. 다른 그래프 후보·권한 격리, 진단 누락·본문/자격 미노출, 토큰·큐 지표와 적용·거부 단계를 확인했다.
- 실제 분리 indexer 실행 경로의 추론 큐 확보·종료를 합성 DB에서 확인했다. 작업자와 두 실행 배치의 관련 race 검사가 통과했다.
- Go 1.27.3 `go build ./...`, `go vet ./...`, `gofmt -l .`이 통과했다. 필수 합성 DB에서 `go test -v -count=1 -p 1 -timeout=35m ./internal/mcp ./internal/relinfer ./internal/config ./internal/diagnostic ./internal/store ./cmd/server ./cmd/indexer`가 필터 없이 통과했다. 저장소는 396.354초, 서버는 104.090초였고 나머지 패키지도 통과했다.
- 기존 MCP 공개 스키마 시험은 기준 커밋에서도 JSON 객체의 키 순서 때문에 간헐적으로 실패했다. 원본 `default`의 JSON 의미를 비교하도록 시험을 수정했다.

실제 OpenAI 모델 호출·품질·비용과 자동 확정 합격선은 [RINF-06](../development-plan/relation-inference.md#rinf-06)의 별도 평가 대상이다. 운영 DB·운영 배포는 변경하지 않았다.
