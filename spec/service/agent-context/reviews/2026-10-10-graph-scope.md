# 그래프 상세의 전체 보기 복귀와 반복 선택 검증

## 범위와 처리 결과

2026-10-10에 [GitHub #101](https://github.com/Alpha-gone/agent-context-sharing/issues/101)의 국소 보기 해제와 노드 반복 선택을 처리했다. 기준은 원격 `dev`와 일치하는 `20e85e1`이다. 기존 사용자 IDE 설정 staging은 보존했다.

기존 스크립트는 노드 선택으로 국소 보기에 들어간 뒤 선택을 해제하는 경로가 없었다. 홉 최댓값도 연결된 이웃만 넓혀 고립 노드를 선택하면 다른 노드가 계속 숨겨졌다. 수정 전 회귀 시험에서 복귀 수단과 목록 선택 수단의 누락을 확인했다.

- SDD의 「웹 화면 계약」에 전체 보기 버튼·빈 영역·Esc 해제와 목록을 통한 범위 밖 노드 선택을 먼저 정의했다. 기존 `FR-AGENT_CONTEXT-110`·`111`의 구체화이며 요구사항을 추가하지 않았다.
- 해제하면 선택·노드 상세·근거 강조를 초기화하고 반환된 모든 노드와 간선을 다시 표시한다. 홉 값과 절단 안내는 유지하며 조회 범위와 플랜 한도를 바꾸지 않는다.
- 목록의 기본 HTML 버튼으로 숨겨진 노드도 선택하고 현재 홉 범위를 적용할 수 있다. 선택한 범위를 시각화에 맞추며 상세와 나가는 `derived_from` 근거 경로를 함께 갱신한다.
- 현재 보기 상태, 연결된 홉 레이블과 도움말, 키보드 초점 표시를 추가했다. 접근성 가이드에 따라 기본 버튼의 키보드 동작을 사용하며 새 웹 의존성은 추가하지 않았다.

## 검증

IntelliJ IDEA에 등록된 Go 1.27.1 `darwin/arm64` SDK와 Node.js 26.10.0을 사용했다.

- 최초 웹·서버 비DB 시험은 통과했으나 `TEST_DATABASE_URL`이 없어 통합 시험 2개를 건너뛰었다. 이후 실행 중인 개발 DB 서버에 별도 시험 DB `issue101_test_20261010`을 만들고 정식 `001_init` 마이그레이션을 적용해 재시험했다.
- `TEST_DATABASE_URL`과 `TEST_DATABASE_REQUIRED=1`을 설정한 `go test -count=1 -v ./internal/web ./cmd/server`: 모든 시험 통과, 건너뜀 없음. `TestStartupFailureClosesWorkersIntegration`의 6개 기동 실패 경로와 `TestWebAuthenticationPreservesAuthenticationTimeIntegration`도 통과했다.
- 렌더링한 실제 HTML의 스크립트를 저장소 Cytoscape 자산으로 실행했다. DOM 이벤트만 시험용으로 대체하고 이웃 확장·표시·근거 탐색은 실제 라이브러리를 사용했다.
- 고립 노드의 홉 `0`·최댓값, 버튼·빈 영역·Esc 복귀, 복귀 후 다른 노드 선택, 국소 범위 밖 노드의 목록 선택, 홉 `0`·`1`·최댓값, 들어오는 후손 간선의 근거 강조 제외와 반복 선택을 확인했다. 간선 클릭이 국소 보기를 해제하지 않는 것과 빈 그래프의 안전한 조작도 확인했다.
- 기존 홉 한도·한도 없음·결과 절단·본문 이스케이프·세션·등급 검사 회귀도 통과했다.
- 서버·클라이언트 각각 `go build ./...`, `go vet ./...`: 통과. 루트 `gofmt -l .`과 `git diff --check`: 출력 없음.

시험 종료 후 별도 시험 DB를 삭제하고 `pg_database` 재조회 결과 0건으로 정리를 확인했다. 기존 개발 DB의 데이터와 서명 키, 컨테이너 구성은 변경하지 않았다. DB 자격 증명은 기록하지 않았다.

브라우저 검증용 loopback 화면은 실제 DB·계정 없이 구성했으나 브라우저 연결과 컴퓨터 제어 권한이 없어 실제 화면을 조작하지 못했다. 임시 시험 서버는 종료했고 전용 시험 코드는 제거했다. 화면 클릭·키보드 조작의 브라우저 수동 검증은 남아 있다. 운영 확인·배포와 GitHub 상태 변경은 수행하지 않았다.

## DOX pass

웹과 서비스 소유 AGENTS, 영향받은 부모 Child DOX Index를 갱신했다. SDD·공식 근거·한국어 표현·맞춤법·Markdown 구조와 참조 경로를 검토했다. SRS·용어집·공개 MCP 계약·클라이언트·저장소 조회·마이그레이션·배포 구성은 기존 요구사항과 용어, 조회·권한·데이터 경계가 바뀌지 않아 유지했다.

개발 DB 재시험은 검증 기록만 갱신했다. 적용 DOX 체인을 다시 확인했으며 계약과 지속 구조가 바뀌지 않아 AGENTS와 Child DOX Index는 추가로 변경하지 않았다.
