# 그래프 목록 등급 필터 상태 보존 검토

## 대상과 근거

- 분석일: 2026-10-10.
- 관련 이슈: [#108](https://github.com/Alpha-gone/agent-context-sharing/issues/108).
- 기준: `dev`의 `016c6fb`, SRS의 `FR-AGENT_CONTEXT-019`·`105`, SDD의 「웹 화면 계약」·「화면 배치」.
- 범위: 그래프 목록 GET 양식의 활성 이름·등급 표시, 재제출·선택 변경·해제와 다음 페이지 조건 보존.
- 근거: 기존 템플릿·필터 해석 경로, 수정 전 회귀 실패, 수정 후 렌더링·요청 및 실제 개발 PostgreSQL의 격리 DB 검증.

## 해결된 결함

- `DEF-20261010-108` — 낮음, 기준 코드 `internal/web/web.go:952`: 서버가 전달한 `.Grades`를 단일 등급 선택 폼이 사용하지 않아 활성 필터를 표시하지 않았다. 기본 빈 값으로 재제출하면 기존 등급 조건이 사라졌다. SDD에 복수 선택 표현을 먼저 명시하고 현재 선택 집합을 네이티브 체크박스에 반영했다. 수정 전 새 회귀의 8개 조건이 실패했으며 수정 후 전체·단일·복수 조건의 표시·재제출·페이지 이동을 검증했다.

## 미해결 결함과 검증 제한

- 이번 구현 범위에서 추가로 확인한 미해결 결함은 없다. 다만 실제 브라우저 제출 확인은 미실행이므로 해당 검증을 완료로 표시하지 않는다.
- Chrome 컴퓨터 사용 접근이 승인되지 않았다. 합성 세션만 사용하는 임시 loopback fixture를 준비했으나 브라우저를 조작하지 못해 정상 종료했다. fixture 기동·종료 성공은 브라우저 종단 간 시험 통과가 아니다.

## 변경과 계약 보존

- 등급은 소유자·편집자·열람자 체크박스로 표현한다. `fieldset`·`legend`, 입력별 레이블·고유 식별자, 선택 없음의 모든 등급 조회 안내와 키보드 포커스를 제공한다. Modern Web Guidance의 `forms` 지침에 따라 JavaScript나 새로운 UI 의존성 없이 복수 선택을 구현했다.
- 선택한 값은 반복된 `grade` 매개변수로 제출하고 체크박스 상태는 검증한 현재 필터에서 얻는다. 기존 빈 값 URL은 유지하며 중복 URL 값은 선택 집합으로 표시해 재제출 때 중복하지 않는다.
- 이름만 변경해도 등급 조건을 유지한다. 새 양식 제출에는 이전 커서를 넣지 않고 더 보기는 기존 이름·등급 조건과 발급된 다음 커서를 유지한다.
- 필터 의미·권한·세션·오류 처리·공개 MCP 도구·DB·환경 변수·의존성은 바꾸지 않았다. 등급을 선택하지 않거나 모두 해제하면 모든 등급 조회로 돌아간다.

## 검증 결과

- Go `1.27.1`을 사용했다. 개발 PostgreSQL의 전용 `issue108_test_20261010` DB에 정식 `001_init` 마이그레이션을 적용하고 `TEST_DATABASE_REQUIRED=1`로 `go test -race -count=1 ./internal/web ./cmd/server`를 실행했다. 최종 테스트·하위 테스트 181건 통과, 실패·건너뜀 0건이다. 시험 DB는 정상 삭제했고 기존 개발 데이터·서명 키·컨테이너·볼륨은 변경하지 않았다.
- `go test -count=10 -race ./internal/web` 통과. 기존 세션·출처·권한·팀 관리·보기 전환·Cytoscape 자산 회귀를 포함하며 Node.js 계층도 실행했다.
- `TestGraphListFilterFormPreservesGrades`에서 전체·기존 빈 값·각 단일 등급·복수 등급·세 등급·중복과 빈 값의 표시를 대조했다. 실제 렌더링 입력에서 제출되는 값을 추출해 이름 변경 요청을 보내고, 저장소 경계로 전달된 이름·등급 및 커서 초기화를 확인했다.
- 같은 시험에서 실제 렌더링된 더 보기 링크를 따라가 현재 이름·등급 선택과 다음 커서가 유지되는지 확인했다. 따옴표·HTML 특수 문자·더하기가 있는 이름과 특수 문자 커서도 대조했다.
- `TestGraphListFilterCanChangeAndClearGrades`에서 일부 해제 뒤 남은 조건 유지와 전체 해제 뒤 모든 등급 조회를 확인했다. `TestGraphListFilterRejectsInvalidGrade`는 잘못된 등급의 HTTP 400·안내·목록 조회 0회를 검증했다.
- 서버·클라이언트 각각 `go build ./...`·`go vet ./...` 통과. 저장소 전체 `gofmt -l .`·`git diff --check`, 문서 상대 링크·Child DOX Index·요구사항 추적성과 한국어 표현·맞춤법을 점검했다.
- 서버 전체·클라이언트 전체 race 및 운영 배포는 이번 범위에서 재실행하지 않았다. 실제 브라우저·운영 인증 연결 결과는 주장하지 않는다.
