## 변경

선택 버튼·`aria-pressed`·고정 이름·`aria-controls`, 범위 밖 노드의 목록 선택, 세 해제 수단과 텍스트 근거는 기존 스크립트를 이번 시험으로 다시 인수했다. 목록과 버튼은 국소 범위로 숨기거나 다시 만들지 않으며 선택이 포커스를 옮기지 않는다.

시각화 영역은 역할 없는 `div`에 `aria-label`을 붙이고 있었다. 이름을 붙일 수 없는 요소이므로 `role=img`·고정 이름과 조작 안내 연결로 바로잡았고, 키보드 선택은 계속 목록의 기본 버튼이 담당한다. 홉 슬라이더는 초기값과 변경 때마다 `aria-valuetext`로 홉 단위 값을 알린다.

근거 영역에 계산 범위 설명을 상시 표시했다. 반환된 부분 그래프 안에서 나가는 `derived_from`을 따라가며, 국소 홉 범위로 숨겨진 근거는 포함하고 조회 상한으로 반환되지 않은 근거는 표시할 수 없다. 근거 연결이 없을 때도 조회 범위 밖의 근거 여부는 알 수 없다고 안내한다.

## 실행 증거

- **신규 1건 포함 웹 752건 통과**: 최상위 89개·하위 663개, `-race -count=1`·필수 DB 설정. 실패·건너뜀 0, race 없음. 기존 시각화 상태 시험의 표본과 단언을 보강했다.
- Node.js v26.11.1과 저장소 Cytoscape 3.34.3으로 렌더링된 스크립트를 실행했다. 고립 노드의 버튼·빈 영역·Esc 해제, 포인터 선택과 목록 버튼 토글의 `aria-pressed` 동기화, 0홉에서 숨겨진 노드의 목록 선택, 동일 노드 재선택 해제, 0·1·최대 홉을 확인했다.
- 홉 변경마다 슬라이더 `aria-valuetext`와 상태 안내의 홉 값이 일치했다. 근거 두 단계를 가진 노드를 0홉으로 좁혀도 텍스트 근거와 강조 간선 2개가 유지되고, Esc 해제는 근거·선택·pressed를 초기화하며 홉 값을 유지했다.
- HTML 검사는 노드별 기본 버튼·고정 이름·`aria-controls`, 단일 `role=status`, 상세 제목 이동 링크와 제목 포커스 대상, Esc 처리, 선택 스크립트의 포커스 강제 이동·버튼 이름 변경 부재, 양의 tabindex·위젯 역할 부재를 확인했다. 시각화 영역의 `role=img`·고정 이름·안내 연결과 근거 범위 설명도 확인했다.
- `check-go.sh`의 의존성 확인·빌드·vet·gofmt가 통과했다. 웹 SDD·개발 계획·설계 진입점·README/서비스 색인·요청 기록·근거를 정합화했다. 템플릿·스크립트는 기존 웹 DOX 소유 안의 변경이므로 DOX와 부모 색인을 유지했다. 요구사항·용어·SQL 스키마·환경 설정·저장소 계약은 바뀌지 않아 해당 정본은 유지했다.

```sh
TEST_DATABASE_URL='<WEB-07 전용 합성 URL>' TEST_DATABASE_REQUIRED=1 go test -race -json -count=1 -timeout=240s ./internal/web
GO_BINARY="$(command -v go)" sh check-go.sh
```

별도 `acs-web07-20261024` 컨테이너·`agent-context.task=web07` 라벨·tmpfs·임시 IPv4 loopback 포트와 합성 자격을 사용했다. 종료 후 자식 DB·시험 연결 0과 이 작업의 컨테이너 잔류 없음, 기존 개발 컨테이너 보존을 확인했다. 원시 근거는 세션 임시 폴더의 `acs-web07-web.json`·`acs-web07-static.log`다.

Modern Web Guidance의 `accessibility`에서 이름을 붙이면 안 되는 일반 `div`, `aria-pressed` 상태를 이름에 반복하지 않는 규칙, 양의 tabindex 금지와 단일 상태 안내 영역을 확인해 반영했다.

## 남은 범위

Node.js headless Cytoscape와 합성 DOM 이벤트는 실제 브라우저의 Enter·Space 기본 동작, Tab 순서, 포커스 표시와 유지를 대신하지 않는다. 이 항목은 WEB-09에서 CDP로 조작하는 headless Chrome과 수동 Safari로, 실제 스크린리더 음성은 [TEST-06](../development-plan/testing.md#test-06)에서 확인한다. WEB-08~09와 실제 호스트·운영 배포는 미실행이며 커밋·푸시는 수행하지 않았다.
