# RINF-06 정식 인수 실행 상태

사용자 승인: 이전 탐색 측정의 보수 환산 $0.0231057을 포함해 외부 제공자 누적 최대 $10. 운영 활성화·배포는 승인 범위가 아니다.

- 표본: 신규 400개 의미 쌍, 유형별 양성/음성 각100. 별도 작성자와 검토자가 전체 정답을 확인했으며 review-approval.json에 ID·checksum·한계를 기록했다.
- 실제 Gemini 문서 임베딩: 1,200개, 39,185토큰, 고정 Standard 요금 환산 $0.007837. vectors.json·vector-receipts.jsonl 보존.
- 실제 DB 후보·BuildInput: 400개 생성 완료. 같은 프로필 지문 하나, 기대 쌍의 유형 자격 누락0. 입력은 prepared.jsonl, 모델 호출 전 manifest.json 고정.
- 판정: run_judgments.py 완료. 총4000, 최대동시8, 출력상한1536/default, 품질 구간 최대$6.50. 진행은 judgments.jsonl/quality-intents.jsonl, 종료와 재개는 quality-execution.json을 따른다. 이미 완료된 키는 재호출하지 않는다.
- 전체 흐름: 여섯 과업·두 조건·10회, 독립$1상한. 최초 flow-run-1은 manifest의 Duration 직렬화 오류로 호출 전 실패했으며 비용0. 수정 뒤 새 flow-run-2를 사용한다.
- 오프라인 분석: analyze_acceptance.py가 quality와 flow-run-2를 함께 대조한다. 전체 결과가 갖춰지기 전에 네 결과 파일을 완료 산출물로 만들지 않는다.

API 키는 .env 또는 환경 변수에서만 읽고 기록하지 않는다. 원시 판정 응답은 임시 디렉터리에서 Go ValidateOutput에 전달한 뒤 제거한다. 결과에는 본문·근거·원시 응답 대신 ID·지문·안전한 판정 필드만 남긴다. 입력/벡터 파일은 명시적인 합성 평가 자료다.

재개 시 비용 원장을 먼저 읽는다. 실행 중인 process를 중복 시작하지 않는다. 새 측정 기준이나 프로필로 기존 결과를 덮어쓰지 않는다.

진행 중 세션(복구용): 품질 호출 `28502`, 전체 흐름 `40893`. `quality.lock`이 잠겨 있거나 flow-run-2의 종료 기록이 없으면 원래 실행의 상태부터 확인한다. 결과가 아직 끝나지 않았다는 이유로 새 유료 실행을 만들지 않는다. 전체 흐름은 최초 manifest 직렬화 오류를 비유료 회귀로 수정한 뒤 실행했다.

최종 종료: 품질4,000회와 흐름120회 모두 완료했다. `analysis-final` 집계 및 `bundle` 재검증을 마쳤다. 독립 최종 검토는 측정 완료·최종 활성화 보류를 승인했다. 누적 제공자 비용 상한은 $1.0840251이다. 위 세션은 모두 종료했으며 추가 호출을 하지 않는다.
