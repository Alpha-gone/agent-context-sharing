# TEST-06 Safari·VoiceOver 수동 인수 준비

## 현재 상태와 실행 제약

2026-10-28 TEST-06의 남은 실제 브라우저·보조 기술 인수를 이어갔다. 컴퓨터 사용 도구의 앱 목록/브라우저 목록을 확인한 뒤 com.apple.Safari 접근을 요청했으나 “Computer Use was not approved to use Safari”로 거부됐다. 도구의 앱 접근 권한 제한이며 Safari나 제품의 기능 실패로 판정하지 않는다. 다른 수단으로 이 거부를 우회하지 않았다.

Safari 조작과 실제 VoiceOver 음성은 미실행이다. 스크린샷·접근성 트리·Node.js 결과로 실제 음성을 대신하지 않는다. [기존 Chrome·접근성 트리 인수](2026-10-24-test-06.md)의 당시 범위와 미실행 항목을 유지한다. TEST-06은 진행 중이고 전체 120개 완료·1개 진행·3개 미착수다. TEST-09·TRACE-04~05는 선행 대기다.

## 수동 시험 서버

internal/web/manual_browser_acceptance_test.go의 browser_manual 태그는 기존 permissionDatabase·web08Service·web03Graph·web05Context 도우미를 사용한다. 전용 자식 DB에 합성 소유자/구성원·빈/단일/다중 노드/고립 노드·열람 전용 그래프·두 단계 파생 근거·사건·활성 연결/등록을 만든다. 소유자의 목록 페이지 크기는 2개이며 홉 상한 없는 합성 플랜으로 0/최대 홉을 조작할 수 있다.

서버는 httptest의 loopback TLS에서만 수신한다. 로그인 POST의 Origin과 Secure 세션 쿠키를 적용한 실제 HTTPS 대조 뒤 네 그래프의 상세 렌더링을 확인한다. TLS 검증을 끄거나 사용자 브라우저 인증서 저장소를 변경하지 않는다. 헤더/요청/응답/유휴 제한을 두며 WEB_MANUAL_WAIT는 최대 15분이다. 미설정 시 준비 확인 뒤 바로 종료한다. 대기 중 STOP 파일·시간 만료·Interrupt로 종료하면 서버·자식 DB·임시 자료를 정리한다.

URL은 로그에, 합성 로그인 정보와 그래프/노드 식별자는 임시 connection.json(0600)에 기록한다. 공개 시험 인증서도 같은 디렉터리(0700)에 0600으로 둔다. 자격 원문은 시험 로그·검토 문서에 넣지 않는다. 이 시험의 PASS는 fixture_only=true·browser_observations=not_performed이며 사람이 접근성 인수를 마쳤다는 뜻이 아니다.

## 준비 검증과 정리 결과

필수 DB·race에서 같은 고유 시험 1건을 두 종료 경로로 실행했다. 1초 대기 만료는 시험 1.420초·패키지 3.028초, 15분 대기를 STOP 파일로 끝낸 실행은 시험 0.630초·패키지 1.997초에 각각 실패·건너뜀 없이 통과했다. 두 실행을 고유 시험 2건으로 합산하지 않는다. 바깥 실행기에서 자료 파일 0600·디렉터리 0700과 종료 뒤 임시 디렉터리 부재를 대조했다. Interrupt 경로는 구현만 했으며 별도 실행 검증은 하지 않았다.

예비 준비 검증은 t.TempDir의 하위 디렉터리가 기대한 0700과 달라 외부 권한 확인에서 실패했다. Go 1.27.1 testing.TempDir의 하위 디렉터리가 os.Mkdir(..., 0777)을 사용하는 것을 SDK 소스로 확인하고 시험 소유 디렉터리에 0700을 명시했다. 예비 실행의 잔여 DB가 없는지 확인한 뒤 위 두 최종 경로를 다시 실행했다. 예비 결과는 통과 수에 넣지 않는다.

원시는 /private/tmp/acs-test06-manual-expiry.json·acs-test06-manual-stop.json·acs-test06-manual-lifecycle.json이며 바깥 검증은 /private/tmp/acs-test06-manual-lifecycle.py로 실행했다. 전체 의존성 검증·build·vet·gofmt와 browser_manual 태그의 웹 패키지 vet도 통과했다. 정적 검사 원시는 /private/tmp/acs-test06-manual-static.log다. 이 작업에서 Chrome 시나리오나 웹 전체 회귀를 새로 실행했다고 보고하지 않는다.

새 합성 DB는 기존 고정 이미지 sha256:2b6d51048c03dae147064683f5b078690f1525365d561fd80b78f74de8c3c697와 loopback 포트에서 실행했다. 시험 종료 뒤 자식 DB·잔여 클라이언트 연결 0개를 확인했다. 소유 컨테이너 4f55d77f7864a534158b7a7c9c8d84b787aba44bc1acc413f9b2f0a7283f0b84의 라벨 acs.task=test06-manual을 대조하고 정상 정지·제거했으며 익명 볼륨 1개의 부재도 확인했다. 기존 개발 DB/WAL과 TEST-08 DB는 유지했다. 원시는 /private/tmp/acs-test06-manual-cleanup.json이다. 현재 관찰 대기용 서버나 자격 파일을 남겨 두지 않았다.

## 실제 수동 인수 순서

1. Safari 앱 접근 권한을 준비한다. 새 합성 DB 접속 정보로 아래 명령을 실행하고 로그의 loopback URL과 비공개 connection.json 경로를 확인한다. 자료는 실행 중에만 존재한다.
2. 브라우저가 시험 TLS 인증서 신뢰 확인을 요구하면 공개 server-certificate.pem과 대상 URL을 확인하고 사용자가 직접 처리한다. 컴퓨터 사용 도구는 브라우저 보안 경고를 대신 통과하지 않는다. 기존 인증서 저장소를 자동 변경하지 않는다.
3. connection.json의 합성 계정으로 로그인한다. 목록 필터/페이지·빈/단일/고립/다중 노드·선택/해제·0/최대 홉·전체 복귀·범위 밖 재선택·상세 제목 포커스와 Tab/Shift+Tab/Enter/Space/Esc/방향키를 실행한다. 팀/삭제·복구/감사/연결 관리·로그아웃도 [기존 미실행 목록](2026-10-24-test-06.md#남은-수동-인수)과 대조한다.
4. Chrome/VoiceOver와 Safari/VoiceOver 각각에 실제 OS·브라우저·보조 기술 판, 키보드 탐색 설정, 사용 명령, 들은 문구와 순서를 기록한다. 짧은 상태 안내·선택 상태·홉 단위·제목 탐색·본문/방향이 있는 두 단계 근거 읽기를 관찰한다. 원문 본문 전체가 상태 안내로 반복되는지와 의도하지 않은 포커스 이동도 확인한다. 실행하지 않은 조합은 미실행으로 남긴다.
5. 로그에 표시된 같은 임시 디렉터리에 STOP 파일을 만들거나 15분 만료를 기다려 종료한다. 시험이 만든 DB/서버/자료와 별도로 준비한 소유 DB 컨테이너의 정리 결과를 확인한다. 관찰 결과를 검토에 연결한 뒤에만 TEST-06 완료 기준을 판정한다.

```sh
TEST_DATABASE_URL='<새 합성 DB>' TEST_DATABASE_REQUIRED=1 WEB_MANUAL_WAIT=15m \
GOCACHE=/private/tmp/acs-eval12-go-cache \
/Users/alphagone/sdk/go1.27.1/bin/go test -tags browser_manual -race -count=1 -v \
  -run '^TestTEST06ManualBrowserFixture$' -timeout=20m ./internal/web
```

DOX pass에서 제품 동작·설계·기본값·소유권이 바뀌지 않아 기존 DOX·SRS·SDD를 유지했다. 새 시험 서버·실행 안내·진행 기록만 추가했으며 실제 음성 인수는 별도다.

## 사용자 직접 관찰용 세션 기동

사용자가 Safari·VoiceOver를 직접 검증하도록 요청해 2026-10-28 20:39 KST에 새 합성 DB와 TLS 서버를 기동했다. 주소는 https://127.0.0.1:59761/login이며 대기 만료는 약 20:54 KST다. 소유 라벨 acs.task=test06-user-manual의 새 DB만 사용하고 기존 개발/시험 컨테이너는 유지했다. 로그인 GET을 세션의 공개 시험 인증서로 검증해 200을 확인했다. 앞 절의 서버/자료 정리 결과는 준비 검증 종료 당시의 기록이다.

로그인 정보와 직접 이동 링크는 임시 0600 manual-guide.md에, 관찰 체크리스트는 /private/tmp/acs-test06-user-observations-20261028.md에 준비했다. 체크리스트는 만료 뒤에도 남긴다. /private/tmp/acs-test06-user-session.json에서 URL·안내 경로·STOP 경로·만료 시각과 종료 결과를 확인한다. 대기 만료/STOP 뒤 실행기가 소유 DB 컨테이너와 익명 볼륨을 정리하도록 구성했으며 종료 완료를 미리 보고하지 않는다. 실제 Safari/음성 관찰은 사용자 결과 대기이며 TEST-06은 진행 중으로 유지한다.

## 사용자 인수 범위 조정

2026-10-28 사용자가 “보이스 오버는 그냥 넘길게”라고 지시해 실제 VoiceOver 음성 관찰을 이번 인수 범위에서 제외했다. 실행 결과는 미실행·범위 제외이며 통과가 아니다. 키보드·DOM/접근성 트리 검증과 실제 Safari 관찰은 확인된 범위로 유지한다. 같은 시점에 사용자가 노드가 잘 보인다고 확인해 선택 강조의 시각적 식별 개선을 기록했다. 브라우저/보조 기술 판과 Safari 전체 시나리오의 통과를 추정하지 않았다. TEST-06과 전체 완료 수는 그대로 유지한다. 이전 절의 음성 수동 절차는 제외 지시 전의 준비 기록이며 현재 실행할 필수 항목이 아니다.

후속 범위 조정: 사용자가 키보드 직접 검증도 생략하도록 지시해 추가 수동 키보드 관찰을 이번 인수에서 제외했다. 기존 자동 키보드·Node·DOM/접근성 트리 실행 결과와 지원 구현은 유지한다. 제외한 사용자 수동 항목을 다시 요구하거나 통과로 기록하지 않는다. Safari의 확인하지 않은 다른 시나리오와 구분한다.
