## 변경

그래프 상세를 왼쪽 그래프 속성·전역 요약, 가운데 시각화, 오른쪽 선택 상세의 세 영역으로 배치했다. 왼쪽은 식별자·설명·생성 시각·마지막 활동과 반환 노드·연결 수를 표시한다. 전역 요약은 같은 조회 결과에서 범위가 `global`인 요약 파생만 고르고, 없으면 활성 컨텍스트를 시작점으로 썼다고 안내한다. 960px 이하에서는 세 영역을 한 열로 쌓는다.

서버가 만든 시각화 데이터에 간선 분류를 추가했다. 참조(`derived_from`·`supersedes`·`has_member`)는 실선, 확정 사건 관계(`precedes`·`causes`·`part_of`·`relates_to`)는 점선이며 모두 화살표와 종류 이름을 유지한다. 범례에 두 연결과 근거 경로 강조를 추가했다. 선택 상세는 계층·식별자 뒤에 `상충`·`근거 무효` 표식을 텍스트로 붙인다.

시작점 선택·플랜 한도 없음과 0홉의 구분·유한 슬라이더·절단 표시·전체/국소 보기 전환과 해제는 기존 처리기와 스크립트를 이번 시험으로 다시 인수했다. 보기 전환은 추가 조회를 하지 않으며 응답 범위 재검사가 삭제 노드·범위 밖 간선을 계속 거부한다.

## 실행 증거

- **신규 8건 포함 웹 751건 통과**: 최상위 88개·하위 663개, `-race -count=1`·필수 DB 설정. 실패·건너뜀 0, race 없음. 신규는 최상위 4개·하위 4개이며 기존 시각화 상태 시험의 표본을 보강했다.
- 단위 시험은 세 영역 순서, 속성·시각, 전역/국소 요약 구분과 시작점 안내, 일곱 연결 종류의 실선/점선 분류·노드 계층/상태 클래스·범례, 시각화 조회 장애의 고정 500과 취소 중단을 확인했다.
- Node.js v26.11.1과 저장소 Cytoscape 자산으로 렌더링된 스크립트를 실행해 고립 노드 해제 세 수단, 목록 선택과 범위 밖 노드, 0·1·최대 홉, 근거 방향, 빈 그래프 복귀를 다시 확인했다. 상충 노드의 상세에 표식 텍스트가 붙고 표식 없는 노드에는 붙지 않는다.
- 실제 DB·서명 세션·TLS에서 빈 그래프는 노드 0·슬라이더 0이다. 전역 요약이 없으면 고립 노드를 포함한 활성 6개가 시작점이고 한도 없음 슬라이더는 5다. 참조 3개와 `precedes` 관계 1개가 각각 실선/점선으로 분류됐다.
- 원천 하나를 삭제하면 그 노드와 구성원 간선이 빠져 노드 5·간선 3이 되고 모든 간선의 양 끝이 반환 노드 안에 있다. 전역 요약을 추가하면 요약이 왼쪽 영역에 이스케이프되어 표시되고, 요약에서 닿는 노드만 반환되며 고립 노드는 빠진다.
- `max_hop_nodes=2`는 노드 2·슬라이더 1과 절단 안내를, 유한 `max_hops=1`은 슬라이더 1을 표시했다. 권한 화면은 시각화 자산을 읽지 않고, 삭제된 그래프와 등급 없는 계정의 상세는 404다.
- `check-go.sh`의 의존성 확인·빌드·vet·gofmt가 통과했다. 웹 SDD·개발 계획·설계 진입점·README/서비스 색인·요청 기록·근거를 정합화했다. 처리기·템플릿·스타일은 기존 웹 DOX 소유 안의 변경이므로 DOX와 부모 색인을 유지했다. 요구사항·용어·SQL 스키마·환경 설정·저장소 계약은 바뀌지 않아 해당 정본은 유지했다.

```sh
TEST_DATABASE_URL='<WEB-06 전용 합성 URL>' TEST_DATABASE_REQUIRED=1 go test -race -json -count=1 -timeout=240s ./internal/web
GO_BINARY="$(command -v go)" sh check-go.sh
```

별도 `acs-web06-20261024` 컨테이너·`agent-context.task=web06` 라벨·tmpfs·임시 IPv4 loopback 포트와 합성 자격을 사용했다. 시험별 자식 DB를 정식 마이그레이션으로 준비하고 종료 후 자식 DB·시험 연결 0, 이 작업의 컨테이너/볼륨 잔류 없음과 기존 개발 컨테이너 보존을 확인했다. 원시 근거는 세션 임시 폴더의 `acs-web06-web.json`·`acs-web06-static.log`다.

첫 통합 실행들은 시험 코드 문제로 실패했다. 사건 시간 범위가 구성원 원천의 발생 시각을 포함하지 않아 저장소가 사건을 거부했고, 이어 시험의 JSON 구조체에 태그가 없어 대소문자를 구분하는 `encoding/json/v2`가 노드 식별자를 비워 범위 대조가 실패했다. 사건 시간을 구성원 발생 시각 기준으로, 구조체에 명시 태그를 지정한 뒤 해당 시험과 전체 모듈 실행이 통과했으며 반복 실행을 중복 합산하지 않았다.

Cytoscape.js 공식 문서에서 간선 `line-style`의 `solid`·`dotted`·`dashed` 값을 확인했고, 내장 3.34.3 자산의 headless 실행으로 클래스 선택자의 점선 적용을 대조했다.

## 남은 범위

WEB-07~09의 키보드·접근성 상태와 감사·연결 화면, 전체 웹 분야 통합, 실제 브라우저의 레이아웃·포인터·키보드·스크린리더 음성, 실제 호스트·운영 배포는 미실행이다. 실제 브라우저 인수는 WEB-09에서 CDP로 조작하는 headless Chrome과 수동 Safari로 수행한다. Node.js headless Cytoscape와 HTML 검사는 실제 브라우저 렌더링을 대신하지 않는다. 커밋·푸시·배포는 수행하지 않았다.
