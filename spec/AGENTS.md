# 명세 문서 영역

## 목적

- `spec/`은 지속적인 명세 문서와 공통 용어 정리집을 보관한다.

## 소유권

- 이 문서는 명세 문서의 분류·용어와 서비스별 문서 경계를 소유한다.
- [DICTIONARY.md](DICTIONARY.md)는 서비스·기획 용어의 대표 표기와 정의를 소유한다.

## 로컬 계약

- 서비스 동작·요구사항·설계, 외부 근거, 검토·요청 기록은 각 소유 문서에서 관리한다. 기록을 정본으로 취급하지 않는다.
- 용어집에서 서비스 용어와 기획 용어를 구분하고, 정의·동의어·코드/API 대응을 해당 분류에 유지한다.
- 서비스별 고유한 범위가 생기면 `service/`에 하위 영역을 두고 서비스 DOX에서 문서별 소유권을 정한다.

## 작업 지침

- 명세의 대상·상태를 확인하고, 미확정 내용을 추측하여 확정 계약으로 기록하지 않는다.

## 검증

- 문서 분류·소유권·용어집 표기와 서비스 진입 링크가 일치하는지 확인한다.

## Child DOX Index

- `service/AGENTS.md`: 서비스 색인과 요구사항·설계·근거·기록의 공통 계약.
