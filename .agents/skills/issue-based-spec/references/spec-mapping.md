# 이슈-명세 매핑 기준

## 분류표

| 이슈 내용                                            | 분류      | 기본 반영 위치                                | 처리 기준                                                                         |
|:-----------------------------------------------------|:----------|:----------------------------------------------|:----------------------------------------------------------------------------------|
| 사용자가 해야 할 일, 시스템 동작, 정책, 권한, 제약   | 요구사항  | `SRS.md`                                      | `service-design` 계약을 사용하고 검증 가능한 문장으로 작성한다.                   |
| 구성 요소, API, 이벤트, 데이터 모델, 상태 전이, 배포 | 상세 설계 | `SDD.md`                                      | `detailed-design` 계약을 사용하고 요구사항 ID에 연결한다.                         |
| 사용자가 명시적으로 선택하거나 승인한 항목           | 결정      | 관련 `SRS.md` 또는 `SDD.md`, `logs/prompt.md` | 결정 범위와 출처를 기록하고 기존 명세와의 충돌을 확인한다.                        |
| 아직 채택되지 않은 개선 아이디어                     | 제안      | `suggestion.md`                               | `미검토`로 기록하고 확정 명세에 넣지 않는다.                                      |
| 선택에 따라 결과가 달라지며 답이 없는 항목           | 미정 사항 | `SRS.md` 또는 `SDD.md`의 미정 사항            | 영향받는 ID와 필요한 결정을 적는다.                                               |
| 파일 수정, 코드 작성, 테스트 실행 같은 수행 항목     | 구현 작업 | 명세 반영 대상 아님                           | 요구사항이나 설계의 근거가 있을 때만 연결하고 완료 사실을 명세로 확대하지 않는다. |
| 외부 문서, 표준, 기사 또는 공식 API 자료             | 출처      | `reference.md`                                | 원문 링크와 사용 맥락을 기록한다.                                                 |

## 확정성 판단

- 이슈 본문과 댓글에서 사실, 사용자 결정, 제안과 미정 사항을 구분한다.
- `open`, `closed` 상태나 라벨만으로 요구사항·설계의 확정 여부를 판단하지 않는다.
- 체크된 항목은 작업 완료 표식일 수 있으므로 결정 근거와 검증 결과를 별도로 확인한다.
- 댓글의 제안은 사용자의 명시적 채택이 확인된 경우에만 결정으로 분류한다.
- 기존 명세가 더 구체적이거나 서로 다르면 이슈가 자동으로 우선한다고 가정하지 않는다.

## 추적성 규칙

1. 기존 요구사항 ID와 설계 항목의 식별자를 보존한다.
2. 신규 요구사항 ID는 `service-design`의 서비스 경로 기반 규칙으로 부여한다.
3. `SRS.md`의 `관련 이슈` 열 또는 `SDD.md`의 요구사항 추적표에서 원본 이슈를 연결한다.
4. 여러 이슈가 같은 항목을 다루면 각 이슈의 담당 범위를 구분한다.
5. 링크만 추가해도 의미가 달라지는지 확인하고, 변경 기록에 실제 반영 위치를 남긴다.

## 반영 전 점검

- 대상 서비스와 문서 경로가 확정되었는가
- 이슈 원문과 댓글을 최신 상태로 재조회했는가
- 기존 명세와 충돌하는 문장이 있는가
- 채택되지 않은 제안이 확정 범위에 섞이지 않았는가
- 보존할 ID와 새로 필요한 ID가 구분되었는가
- 변경 파일, 추적 링크와 검증 방법이 승인 범위에 포함되었는가
