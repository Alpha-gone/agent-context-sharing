# 독립 검토와 산출물 해석

작성자와 별도 검토자가 측정 출력을 읽기 전에 입력·정답·SRS·코드를 검토했다. `n01`의 관련 관계, `n03`의 포함 의미·방향, `n05`의 명시적 인과, `n06`의 인과 보류/없음은 타당하다. `n02`와 `n07`의 강제 음성은 SRS의 ‘같은 주제나 대상’ 정의와 충돌할 수 있다. `n03`은 08:00 메타데이터와 오전 9시 본문이 불일치한다. 원래 고정 입력의 일치 수를 의미 정확도로 쓰지 않으며 정답을 사후 변경하지 않는다.

후보 검색 fixture는 JSON v2의 대소문자 구분으로 처음에 0건을 처리했다. 해당 결과는 `candidates-empty-invalid.json`이며 유효하지 않다. 입력 필드 대응과 행 수 검사를 추가했다. `candidates-before-member-fix.json`은 포함 관계의 진부분집합 구성원 보완 전 자료다. 최종 다섯 채널 결과는 `candidates-semantic.json`이다.

과업 trace는 실제 모델 행동 선택·저장소 조회/확정과 실제 서버 작업자 apply를 사용했지만 한 개 합성 과업을 반복한 것이다. 일반 MCP 호스트의 인수나 모집단 효과로 해석하지 않는다. 서버의 판정 유형 범위가 기준선보다 넓다. 지연은 사건 생성·큐 등록 이후부터다. 사용량에 캐시 세부와 인프라 비용은 없으며 실제 청구를 확인하지 않았다.

별도 검토자는 위 정답·품질·전체 비용과 입력 출처 대응의 누락 때문에 기존 계획의 RINF-06 전체 완료 표시는 부적절하다고 판단했다. 이 자료는 실제 측정의 증거로 보존하며 자동 확정을 활성화하지 않는다.
